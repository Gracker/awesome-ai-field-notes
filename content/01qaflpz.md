## OpenClaw 极简安全实践指南

### 引言
🦞OpenClaw 极简安全实践指南是面向 OpenClaw 的黑手册。尝试了其他一些方式来试图加固 OpenClaw，包括 Skill 方式，但是发现还不如给 OpenClaw 植入一个安全"思想钢印"来的有意思。

### 核心理念
这个"思想钢印"形成一个 md 文档，包含安全事前、事中、事后需要做的策略，但这里有个前提：

- **尽量不影响 OpenClaw 的日常使用**：安全不要干扰用户体验，需要给这只🦞足够的自由
- **江湖险恶**：一只有 Root 权限且诞生才一个多月的🦞，安全不让人放心

### 指南特点
- 目前是 v2.7 版本，此前内测了许多版本，也踩了不少坑
- 公布出来，大家玩之前务必仔细看这份指南的 README
- 推荐了在 OpenClaw 场景下实测的聪明模型
- 如果有自己的感受，一定要反馈

### 使用提醒
⚠️最后，务必认真阅读 README，也务必肉眼扫描下你将喂给你🦞的"OpenClaw极简安全实践指南.md"，相信我，会非常有意思。

### 当前状态
一切都很新，一定有不完善的地方，请大家多指正！
