## English Summary

T3 Code is an MIT-licensed multi-harness orchestration control plane (bring-your-own subscription, not a bundled harness). Community measurement found the same workload burning Claude 5h quota roughly 1.6-1.7x faster than the direct TUI (issue #24649); v0.1.7 sets CLAUDE_CODE_ENTRYPOINT=t3-code to fix the metering entrypoint (#28410), bringing merged comparisons back to about 1x. @theo committed on Nov 11 to direct-connection parity - burning faster is a bug - with v0.1.9 as the stable release (Nov 11). Caveats: the FAQ on main still documents the old behavior (#31473 open), and parallel/multi-session usage legitimately raises absolute consumption, which should be attributed separately from metering bugs.
