**Summary (zh):** Google 把 MCP 思路搬到 Android 端：@AppFunction 注解经 KSP 编译期生成 XML schema，平台维护全设备注册表供系统 Agent 发现与调用；KDoc 即 tool description，注释质量直接决定调用准确度；被标注函数默认跑在 UI 线程，需显式切到 IO 线程；Android 17 上可用 adb shell cmd app_function 列出注册函数并以 JSON 直接执行验证。作者给出的选型标准是「一句话能干完」的操作才值得做成 AppFunction。

## 摘要（Android-Internal-Wiki intake 消化）

Google 把 MCP 思路搬到端上：@AppFunction 注解经 KSP 编译成 XML schema，平台维护全设备注册表供系统 Agent 发现调用；KDoc 即 tool description，注释质量决定调用准确度；函数默认跑 UI 线程需显式切 IO；Android 17 可用 adb shell cmd app_function 列表与 JSON 执行验证。选型标准是「一句话能干完」。
