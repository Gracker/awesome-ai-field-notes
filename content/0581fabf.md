## 中文导读

Coding agent 在交互中会把 chain-of-thought 作为独立消息展示给用户，但它在软件工程场景里作为可解释 AI（XAI）机制是否有效此前缺乏实证。这项研究用问卷加半结构化访谈调查 36 名软件工程师，对回答与访谈记录做主题分析：CoT 消息在透明性、可审查性和对 agent 的信任上不可或缺；但过度冗长、技术细节与读者专业不匹配、以及被感知为 agent 在自言自语而脱离当前会话的实例，会导致理解困难、选择性使用甚至弃用。论文据此综合出匹配工程师解释需求的 CoT 消息设计建议。

## 为什么值得关注

把冗长推理轨迹当作免费透明度是不少 coding agent 产品的默认做法，这项 36 人的实证研究给出了反证：CoT 的价值取决于呈现设计——冗长、细节错位、自言自语感都会把用户推向弃用。做 agent 交互设计或开发者体验的人可以把它当作 CoT 展示层设计的直接依据。

## English Summary

Coding agents increasingly display their chain-of-thought as a separate message to provide transparency and explainability, yet its effectiveness as an explainable-AI mechanism for end users in software engineering had not been established. This study surveys 36 software engineers and follows up with semi-structured interviews, thematically analyzing responses and transcripts. CoT messages prove indispensable for transparency, scrutability and trust toward the agent, but overly verbose messages, technical content mismatched to the reader's expertise, and messages perceived as detached from the conversation because the agent is talking to itself cause comprehension difficulties and selective use or abandonment. The authors synthesize design implications for CoT messages that match engineers' explainability needs.
