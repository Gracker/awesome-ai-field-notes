Google 发布 EmbeddingGemma 2：把文本、代码、图像、视频、音频统一映射进一个共享嵌入空间，定位隐私优先的端侧多模态嵌入。基于 Gemma 4 架构，740M 参数，Apache 2.0 商用许可，与 Gemini Embedding 系列同源技术。上一代专注轻量文本嵌入（下载量 2000 万+），这一代把"轻量 + 多模态 + 端侧"叠在一起：sub-1B 多模态嵌入里 MTEB Code 与 MAEB 同规模领先，代码性能 MTEB Code 从 68.76 提升到 78.68（+9.92），适合本地代码库索引、语义代码搜索与编码 agent 检索。模块化设计：纯文本负载最小只需 270M 参数，可选视觉（170M）与音频（300M）编码器补齐全模态。Matryoshka 表示学习（MRL）支持把输出向量从 768 维动态截断到 512/256/128 维，本地向量库存储最高省 6 倍。量化后在 Pixel 11 Pro 上纯文本权重约 191MB 激活内存、全多模态约 567MB。8K token 上下文（上一代 4 倍），单次可处理约 5.5 分钟音频、29 张图或 58 帧视频及其交错组合，全部在本地硬件完成。

## English Summary

EmbeddingGemma 2 is a 740M-parameter, Apache 2.0 multimodal embedding model built on Gemma 4 that maps text, code, images, video, and audio into a unified embedding space. Modular design: 270M for text-only workloads with optional 170M vision and 300M audio encoders. MRL lets vectors truncate from 768 to 512/256/128 dimensions (up to 6x storage savings); quantized, it needs ~191MB active RAM (text-only) or ~567MB (full multimodal) on a Pixel 11 Pro. MTEB Code improves 68.76 → 78.68; the 8K context handles ~5.5 minutes of audio, 29 images, or 58 video frames on-device.
