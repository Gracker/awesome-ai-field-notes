## English Abstract / Summary

Simon Willison introduces wrapture, Graham Dumpleton's new project that extends the wrapt-style monkeypatching idea to combined test and tracing scenarios, exporting OpenTelemetry by default and accepting pure TOML configuration for retrofitting tracing into legacy Python projects. The piece draws attention to Dumpleton's own statement that every line was produced under his direction but the project is not "vibe coding" because vibe coding requires the driver to lack the judgment to evaluate outputs. Dumpleton's mental model of the Python corner he has worked in for decades is the source of design; AI is the production mechanism.
