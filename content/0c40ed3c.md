## English Summary

DeepSeek officially released the V4-Flash API into public beta on July 31, 2026. The model keeps the same architecture and size as V4-Flash-Preview but was re-post-trained, with agent capabilities significantly surpassing V4-Pro-Preview. Key benchmarks: Terminal Bench 2.1 = 82.7, NL2Repo = 54.2, Cybergym = 76.7, DeepSWE = 54.4, Toolathlon Verified = 70.3, Agent Last Exam = 25.2. Natively supports the Responses API format and is specifically adapted for Codex. The official V4-Pro release will follow soon.
