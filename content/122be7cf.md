## 中文导读

Anthropic 报告 Claude 解决了两个黑洞/量子引力公开问题。其一：完成物理学家 20 多年前搭建、一直没人算完的计算，证明 Hawking-Page 型有限温相变在弱耦合端仍是突变——在时空不再有确定形状的理论描述里，同一套理论却仍经历从粒子气体到黑洞的突然切换，说明黑洞形成不只是广义相对论的特征，而是写在底层量子理论里。其二：找到 3D 引力中最简版 modular bootstrap 黑洞质量上限的精确极限——自 2009 年起物理学家用这个方法给最轻黑洞的质量设上限，Claude 找到了大中心荷下支配 modular bootstrap 行为的谱曲线（谱曲线此前从未用于该问题），并用它证明这个上限无法再压低，是 bootstrap 方法首次在黑洞起作用的量子引力区间得到精确结果之一；两个结果于 9 月在 Lean 中形式化验证。过程本身同样值得注意：8 月研究者 Hongbin Chen 让 Claude 列出 22 个候选公开问题、每个开一个后台 agent，互相读进度、无特殊设置地跑了约六周；Hawking-Page 的解完成几周后，一位独立用 Claude 攻同一问题的物理学家分享了结果，两边才发现殊途同归；modular bootstrap 一半证明沿用 OpenAI 模型球堆积证明的策略，此前一个 Claude agent 曾以 61 次并行尝试失败，另有两个 agent 独立得到同一答案。

## 为什么值得关注

这不是"模型做了一道难题"的故事，而是研究自动化的一个完整样本：22 个后台 agent 各领一个公开问题跑六周、互相读进度、跨问题借用方法（一个做球堆积的 agent 把谱曲线方法带进了 bootstrap 问题），独立 agent 重复验证同一结果，最后用 Lean 形式化兜底。对关注 multi-agent 研究工作流的人，页面给出的工程细节（候选问题生成、并行失败 61 次后靠跨域方法迁移破局、独立副本互校）比结论本身更有参考价值。

## English Summary

Anthropic reports Claude solved two open problems in theoretical physics concerning black holes and quantum gravity. First, it completed a calculation set up more than 20 years ago: the Hawking-Page-type finite-temperature transition stays abrupt even on the weak-coupling side, where the gravitational description loses a definite spacetime shape. Second, Claude found the spectral curve governing the modular bootstrap at large central charge and used it to prove the exact limit of the simplest-version ceiling on the lightest black hole's mass in 3D gravity; results were formally verified in Lean in September, and half the proof follows an OpenAI proof strategy. Neither came from a single prompt: 22 background agents on candidate problems ran about six weeks with no special setup, an earlier agent had failed the bootstrap problem in 61 parallel attempts, two other agents independently arrived at the same answer, and a physicist independently using Claude reached the same Hawking-Page solution weeks later.
