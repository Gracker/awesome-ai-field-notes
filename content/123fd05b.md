## 中文导读

Simon Willison 用 OmniDiskSweeper 翻 `~/.cache/` 时发现：OpenAI Codex 桌面应用（现已更名为 ChatGPT 桌面应用）在 `codex-primary-runtime` 目录里放了 1.7GB 的运行时，内含完整的 Python、完整的 Node.js，以及 Poppler、git 的原生二进制，甚至整套 LibreOffice（2010 年从 OpenOffice.org fork 的开源办公套件）——其中 libreoffice-headless 就占 429.7MB。

更关键的一处在 `plugins/documents` 技能目录：里面放着教 Codex 如何找到并使用这些二进制的 skills。也就是说这不只是打包了工具，而是把"文档处理能力"作为技能接进了 agent 运行时。

## 为什么值得关注

这是桌面 agent 竞争的一个具体信号：OpenAI 在给桌面 agent 自带一整套离线工具链（文档解析、PDF、版本控制），而不是依赖用户机器的环境。对做 agent 基础设施的人，值得跟踪"agent 运行时自带 runtime + 技能化工具发现"这个形态——它决定了桌面 agent 能开箱做什么。
