## 中文导读

anthropics/claude-code 正式版从 2.1.319 升到 2.1.321（2026-11-09）：默认 Fable 模型换成 Claude Fable 5.2（1M 上下文，$8/$40 per Mtok，cache 读 $0.20）；remote-control 新增 --settings 可给每个会话套用同一份 settings 文件，变更后需重启生效。同批修了多处安全问题：MCP OAuth 重定向时把 refresh token 等密钥发到错误主机、只读 Bash 未进沙箱就执行、cp/mv 写入目录时 deny 规则没盖到目标文件。

## 为什么值得关注

一次升级同时动默认模型与权限面：换默认档意味着所有未显式指定模型的会话行为当天就变，而 OAuth 密钥外发、沙箱外执行、deny 规则漏覆盖这三类修复直接关系本机安全边界。本机还在 319 的应优先升到 321，升级后核对默认模型名与敏感路径上的确认行为。

## 关键信息

- 默认 Fable 模型改为 claude-fable-5-2：1M 上下文，$8/$40 per Mtok，cache 读 $0.20/Mtok
- claude remote-control 新增 --settings <file>：对启动的每个会话应用同一份 settings，文件变更后不重启不生效
- 修复 MCP OAuth 在服务器重定向时把 refresh token 等密钥发到另一主机
- 修复只读 Bash 命令在沙箱外执行且无权限确认、cp/mv 进目录写入时 deny 规则未盖到目标文件
- 修复 Enterprise 座位切 Fable 后误显 usage credits 扣减、fallback 模型拒答等问题

## English Summary

anthropics/claude-code shipped v2.1.321 (Nov 9, 2026), promoting Claude Fable 5.2 (claude-fable-5-2) to the default Fable model with 1M context at $8/$40 per Mtok and $0.20 cache reads. claude remote-control gains --settings to apply one settings file to every session it starts (changes require a restart). Security-relevant fixes in the same release: MCP OAuth no longer sends refresh tokens and other secrets to a different host on redirect; a read-only Bash command that previously ran outside the sandbox without a permission prompt is fixed; deny rules and protected-file prompts now cover files written by cp/mv into a directory; plus fixes for a misleading usage-credits note on Enterprise Fable seats and fallback-model edge cases.
