# Hermes Agent 接入 Codex GPT-Image-2 生图配置教程

来源：[X/Twitter @AI产品黄叔](https://x.com/PMbackttfuture/status/2047562135987741009)
发布日期：2026-04-24

## 背景

Hermes Agent 接入 Codex 后已经很好用了，但默认情况下还无法直接使用 GPT-Image-2 进行图像生成。

## 配置步骤

1. 在终端执行 `hermes tools`
2. 选择 **"Reconfigure an existing tool's provider or API key"**
3. 选择 **"Image Generation"**
4. 继续选择：**OpenAI (Codex auth) [free] — gpt-image-2 via ChatGPT/Codex OAuth — no API key required**

配置完成后重启 Hermes Agent，即可使用 GPT-Image-2 生图能力。

## 注意事项

- 此配置不需要 API key，利用 Codex OAuth 认证
- 走的是 ChatGPT/Codex OAuth 免费通道
- 确保 Hermes Agent 版本支持 Image Generation 模块
