# Claude Code 从 Pro 版移除引发信任危机，Anthropic 仅靠一条推文回应

## 事件经过

2026 年 4 月 21 日，Anthropic 悄然将 Claude Code 从其 $20/月的 Pro 订阅计划中移除，访问门槛升至 $100/月的 Max 计划。

用户很快发现 Anthropic 官网的定价页已更新，明确显示 Claude Code 不再属于 Pro 计划范围。愤怒的开发者涌向 Reddit 和 X 平台表达不满。

## Anthropic 的回应

Anthropic 增长负责人 Amol Avasare 在 X 上发推澄清：这是针对约 **2% 新用户**的小范围测试，并解释了背后的逻辑：

> 当我们一年前推出 Max 时，Claude Code 还不存在，Cowork 还没有上线，长时间运行的智能体也不是日常使用场景。Max 是为重度聊天用户设计的，仅此而已。
>
> 但从那以后发生了太多变化：我们把 Claude Code 捆绑进了 Max 并且反响热烈；Cowork 上线了；长时间异步智能体成了日常工作流。人们使用 Claude 订阅的方式已经发生了根本性改变——每用户 engagement 大幅上升。
>
> 我们一直在做小幅调整（周限额、峰值时段更严格的限制），但使用场景变化巨大，现有套餐已经无法很好地适应。所以我们正在研究不同方案，以持续为用户提供出色的体验。

Avasare 还承诺：**"当我们最终确定任何影响现有订阅者的方案时，你会提前收到大量通知。你会从我们这里听到消息，而不是从 X 或 Reddit 的截图上。"**

## 用户不满的核心

尽管 Anthropic 试图将此次变动定性为"小范围测试"，但用户愤怒的焦点在于：

1. **公共文档已同步更新**——如果只是 2% 的测试，为何官方定价页直接反映这一变化？
2. **缺乏透明沟通**——用户对其工作流所依赖的工具突然失去访问权感到不安
3. **Claude 使用量暴涨的背景**——许多人正是为了 Claude Code 才选择 Pro，突然的变动让依赖它的日常工作流面临风险

## 更广泛的问题

Anthropic 近期因高需求管理而备受压力，包括在高峰时段引入新限制等。Claude Code 作为驱动大量高消耗使用场景的工具，从相对便宜的套餐中移除虽然可以理解，但用户已经围绕它构建了日常工作流程，这种剧烈变动会引发信任危机。
