## English Summary

Claude Code v2.1.332 (released 2026-11-25T01:32Z) makes MCP server skills a beta feature: skills mounted by MCP servers appear in the slash menu as server:skill entries. A new PreSkillShellCommand hook can block inline shell commands before a skill's injected command runs (matcher: Bash/PowerShell); naming this event in settings on 2.1.331 or older triggers a migration dialog. Cross-session suspended messages gain Always deliver. The release also fixes a batch of Code Mode and stability issues: input lists over 4096 silently skipped, slow commands backgrounded without notice, stopped commands still waiting minutes, subagent scripts over ten minutes hitting Agent stalled, resumes dropping the last reply, auth failures reporting success. Skill distribution plus load-time permission gating is the release's main axis.
