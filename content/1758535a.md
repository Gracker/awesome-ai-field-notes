## 中文导读

OpenAI 10 月 26 日发布 GPT-6.1 Terra，定位是快、便宜、能干活的中间档：视觉推理、精确电脑操作加自然写作。官方页面给出的关键数字：标准 API 定价每百万输入 $1、输出 $5、缓存输入 $0.05，比 GPT-5.6 Terra 与 GPT-6.1 Sol 低一半；Agents' Last Exam 中等推理档比 GPT-5.6 Terra 高 15 个百分点、成本约三分之一，与 GPT-6 Astra 持平但价格仅十分之一，任务完成速度快 3 倍以上；易错提示内部错误率低推理档从 53.6% 降到 16.7%，max 档 4.3%；Terminal-Bench 4.0 max 档 50.3%，约为上代 21.5% 的两倍多。API 型号 gpt-6.1-terra，约 105 万 token 上下文，ChatGPT Work 与 Codex 的 Plus/Pro/Enterprise/Edu 用户可用。

## 为什么值得关注

中档模型的价格战正式开打：computer use 能力下放到半价档位，读发票、填表单、界面操作这类高流量 agent 工作流的成本曲线被重写；对应用层来说，50% 降价会直接改变『自建小模型还是直接调 API』的算账。

## English Summary

OpenAI introduced GPT-6.1 Terra, a fast, efficient model pairing detailed visual reasoning with precise computer use and clearer, more natural writing. Standard API pricing is $1/M input, $0.05/M cached input and $5/M output - 50% below GPT-5.6 Terra and GPT-6.1 Sol. OpenAI reports +15 percentage points over GPT-5.6 Terra on Agents' Last Exam at medium reasoning effort (~1/3 the cost), parity with GPT-6 Astra at one-tenth the price, over 3x faster task completion, and ~9x lower cost per task vs Claude Opus 5.5 at max effort; error rates on internal error-inducing prompts fell from 53.6% to 16.7% at low effort (4.3% at max); Terminal-Bench 4.0 reaches 50.3% vs 21.5% for GPT-5.6 Terra. Available in ChatGPT Work and Codex for Plus/Pro/Enterprise/Edu, and via the API as gpt-6.1-terra with a ~1M-token context window.
