## 中文导读

Serverless LLM 推理为提高利用率把多个实例挤进同一块 GPU，每实例各自维护权重与运行时状态，重复显存成为首要瓶颈。gKSM 把 CPU 侧成熟的 KSM 去重搬到 GPU 显存：哈希计算下放为 GPU kernel，模型权重在传输前完成零拷贝去重，写隔离靠跨特权缺页处理（轻量内核 hook 加用户态 CUDA VMM remap）补上 GPU 没有原生 COW 的缺口，另配稳定页扫描与集群侧复用感知放置。数字：相对 ServerlessLLM 显存占用降 59.8%；内存受限负载聚合吞吐提升 2.15 倍、单卡并发 5 实例；集群仿真服务率 99.97%（SLInfer 78.2%、ServerlessLLM 26.9%）。已获 SIGOPS ATC 2026 接收。

## 为什么值得关注

它把 KSM 的三个组件——扫描、去重、缺页处理——逐个按 GPU 语义重做了一遍；熟悉 KSM/USS 的移动内存经验可以直接用来判断哪些能跨到显存、哪些不能。

## English Summary

gKSM ports CPU-side KSM deduplication to GPU memory for serverless LLM inference: hashing becomes a GPU kernel, weights are deduplicated zero-copy before transfer, and write isolation uses cross-privilege page-fault handling (a lightweight kernel hook plus userspace CUDA VMM remap) to compensate for GPUs lacking native COW, with stable-page scanning and reuse-aware cluster placement. Results: 59.8% less GPU memory than ServerlessLLM, 2.15x aggregate throughput for memory-constrained workloads (5 instances per GPU), and 99.97% service rate in cluster simulation vs SLInfer 78.2% / ServerlessLLM 26.9%. Accepted at SIGOPS ATC 2026.
