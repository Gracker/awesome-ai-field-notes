Boris Cherny 是 Anthropic 内部 Claude Code 的创建者，从一个三人小团队的孵化项目做起，把"在 IDE 里按 Tab 自动补全一行代码"这件事彻底升级成"让 Agent 把整个项目写完"。Claude Code 在 2026 年初已经超过十亿美元年化营收，被 Anthropic 自己称为"史上从研究预览到十亿美元产品最快的一次"。

这次访谈来自 Sequoia 2026 年的 AI Ascent 大会，主持人是红杉合伙人 Lauren Reeder。

原始视频：https://www.youtube.com/watch?v=SlGRN8jh2RI

核心要点：
- Boris 整个 2026 年没写过一行代码，每天合并几十个 PR，单日记录是 150 个
- Claude Code 早期半年没有 PMF，是 Opus 4 在 2025 年 5 月发布之后才开始指数增长
- Boris 现在大部分工作从手机完成，Claude App 里常驻 5 到 10 个 session、几百个 Agent
- Anthropic 内部已经没有手写代码：所有 SQL、所有产品代码都由模型生成
- 关于"SaaS 的终结"：切换成本和流程效力会被 AI 抹平，但网络效应、规模经济、独占资源不变
- 历史类比是印刷术：软件构建会像识字一样普及
- Anthropic 的真正领先不在技术，在组织流程

## Claude Code 是怎么从一个三人孵化项目做出来的

2024 年底 Boris 加入 Anthropic Labs 孵化器，团队只有几个人，一开始的产物就是 Claude Code、MCP 和 Claude Desktop App。Boris 描述当时用的是"product overhang"——模型已经能做一堆事情，但还没有任何产品把这些能力展现出来。

做出来之后前六个月几乎没什么人用。真正的爆发点是 2025 年 5 月 Opus 4 发布，之后每一代新模型都让曲线再往上拐一次。

## "编程已经被解决"

对 Boris 自己来说，比例是 100%。Claude Code 的代码库就是 TypeScript 和 React，选这两个的原因是在模型训练数据里非常常见。团队在 2024 年 10-11 月就过了临界点：模型开始写 100% 的代码。

但这条结论并不普世：还有很大很复杂的代码库、还有模型不擅长的小众语言。

## 手机里跑着几百个 Agent

Boris 现在大多数工作从手机完成。Claude App 左侧有 code 标签，常驻 5 到 10 个 session，每个 session 里又开着一堆 Agent。最常用的是一种叫 Loop 的简单模式：让 Claude 用 cron 起一个定时任务。

"Loop 是未来。"

## 通才崛起

"通才会比今天多得多"——工程经理、产品经理、设计师、数据科学家、财务、用户研究员，每一个人都在写代码了。当写代码的边际成本接近于零，分工的边界自然会模糊。

## SaaS 的终结

AI 会抹平两种护城河：切换成本和流程效力。但网络效应、规模经济、独占资源依旧成立。

"接下来 10 年里，能颠覆原有市场的初创公司数量大概会比过去 10 年多 10 倍。"

## 软件大众化：从印刷术到发短信

Boris 认为软件构建会变成"我会发短信"那种级别的技能。最懂业务的人比最会写代码的人更适合做软件——比如写会计软件最合适的人是会计师而不是工程师。

## 真正的内部领先在组织流程

Anthropic 内部已经把 Claude 用到一切环节。员工的 Claude 之间通过 Slack 互相沟通。"我们整个公司没有任何手写代码了。所有 SQL 都是模型写的。"

领先的关键在组织怎么改造自己，技术大家都能拿到。
