# Self-Guided Test-Time Training for Long-Context LLMs

## 摘要 (Summary)

论文提出自引导测试时训练（Self-Guided TTT）以解决长上下文 LLM 的关键痛点：简单扩展上下文窗口并不能保证有效利用长输入，随着输入变长准确率反而下降现有测试时训练（TTT）方法对整段长上下文做适配成本极高，而对随机子片段做适配又因大多数片段与问题无关而引入严重噪声，甚至可能损害基座模型能力自引导 TTT 通过让 LLM 自身判定哪些片段与问题相关并以问题为条件采样训练子集，从而把测试时参数适配限定在高信噪比的证据片段上在多个长上下文基准上，自引导 TTT 比随机片段训练和全上下文训练都取得显著提升，且对噪声片段具有鲁棒性，为长上下文 LLM 利用提供了一条可扩展的实例自适应路径

## English Abstract / Excerpt

Long-context processing has become increasingly important for large language models (LLMs), but simply extending the context window does not guarantee effective utilization of long inputs. As input length grows, accuracy often degrades, indicating that models still struggle to identify and use the evidence most relevant to a question. A promising way to improve long-context utilization is test-time training (TTT), which treats the test context as a training example for instance-specific parameter adaptation. However, applying TTT to the entire long context is prohibitively expensive, while adapting on randomly sampled spans introduces severe noise. Because most spans in a long context are irrelevant to the specific question, training on them may even degrade the base model's performance....

## One-Liner

Self-Guided TTT 让 LLM 自己挑出相关片段做测试时训练，把长上下文利用限制在高信噪比证据上，显著优于随机/全上下文 TTT
