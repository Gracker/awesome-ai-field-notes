## English Summary

Uses mitmproxy during VS Code launch to capture Copilot's full request matrix: OAuth token exchange, model + SWE-agent capability discovery, intent router, MCP registry fetches, and repo-context collection. In Auto mode every keystroke first hits a models session intent endpoint that scores prompts across code-gen / debugging / reasoning / tool-use before picking a model. Bootstrap already issues six request families: auth, config, policy, MCP registry, repo context, model discovery, recent repos. Stale Extension Host processes skip the proxy entirely and require Developer: Restart Extension Host. Article ships the full sequence diagram, an Extension Host restart script, and mitmweb walkthrough, and frames context-as-product as the harness-engineering takeaway.
