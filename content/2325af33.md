## English Summary

Cerebras explains how trillion-parameter models run on wafer-scale hardware: a single WSE-3T wafer carries 44 GB of on-chip memory while trillion-parameter weights need terabytes, so models are split across wafers connected in a pipeline. Using open-source Kimi K3 (~3T parameters: 69 linear-attention layers, 24 dense layers) with 4-bit weights, an 8-bit KV cache and a 256k assumed average request, each layer is ~16 GB; dense layers reserve SRAM for their KV cache (one per wafer) while linear-attention layers keep only a small fixed per-request state (two per wafer), totaling 35 + 24 = 59 wafers. The compiler maps layers onto wafers, only activations cross wafers, and concurrent requests stream through the pipeline instead of batching; K3-scale models serve 1000-2000+ tokens per second, and the same recipe scales to bigger models by adding wafers.
