# 中文原文

## Glean 推出 Waldo：首个 Agentic 搜索模型，NVIDIA Nemotron 3 Nano 驱动

NVIDIA 宣布 Glean 推出其首个 **Agentic 搜索模型 Waldo**，基于 NVIDIA Nemotron 3 Nano 构建，并针对搜索规划进行了后训练。

### 核心特性

Waldo 的核心能力在于**自主分解查询、选择工具、判断需要读取什么、以及何时有足够证据进行交接**。

具体来说：
- **查询分解**：将复杂用户查询拆分为可执行的子步骤
- **工具选择**：判断需要调用哪些工具来获取答案
- **动态读取**：根据中间结果决定下一步读取什么
- **证据充分性判断**：确定何时已收集足够证据可以交办

### 性能提升

集成到 Glean 的企业搜索框架后，Waldo 实现了：
- **延迟降低约 50%**
- **Token 消耗减少约 25%**
- **质量无退化**

这是一个强化学习训练的 Agentic 搜索模型，运行在调用前沿模型之前——它的职责是搜索，完成后交办给下游的前沿模型进行检索和推理。

# English Original

## Glean Launches Waldo: First Agentic Search Model, Powered by NVIDIA Nemotron 3 Nano

NVIDIA announced that Glean has launched its first **agentic search model Waldo**, built on NVIDIA Nemotron 3 Nano and post-trained for search planning.

### Core Capabilities

Waldo's core ability lies in **autonomously decomposing queries, selecting tools, determining what to read next, and when it has enough evidence to hand off**.

Specifically:
- **Query Decomposition**: Breaking complex user queries into executable sub-steps
- **Tool Selection**: Determining which tools to invoke for answers
- **Dynamic Reading**: Deciding what to read next based on intermediate results
- **Evidence Sufficiency**: Knowing when enough evidence has been gathered to hand off

### Performance Gains

Integrated into Glean's enterprise search framework, Waldo delivers:
- **~50% lower latency**
- **~25% fewer tokens**
- **No quality regression**

This is a reinforcement learning-trained agentic search model that runs before a frontier model is used — its job is to search, and once finished, Waldo hands off to a downstream frontier model for retrieval and reasoning.
