## 中文导读

openai/codex rust-v0.153.2（2026-09-03 23:53 UTC，121.3k stars）的实质功能集中在 v0.153.0：Vim 模式支持 `u` 撤销与 `Ctrl+R` 重做并保留粘贴/附件；`codex plugin` CLI 支持远程 marketplace 列表/安装/卸载；新增 `tui.auto_recap = false` 关闭自动 recap 但保留手动 `/recap`；TUI 历史展示完整 patch、后台终端输入与每条已完成命令；Plus/Team 用户在约五小时使用窗口内余量不到一半时收到提前警告；TUI 断线后自动重连 app-server 并保留草稿/不确定提交；Guardian 历史跨 compact/restart/fork；MCP 审批按账户隔离；可选 `features.context_management.experimental_mode`。v0.153.1 在 API 侧提供 GPT-6-Astra 目录但不改默认/不进 picker；v0.153.2 把 Astra Fast 文案从 1.5× 改为 2×，仅显示文本变化。Pre-release 已发 0.154.0-alpha.3。

## 为什么值得关注

0.153 系列把 Codex 的工程重心放到三处：插件生态（TUI 之外的 marketplace）、可靠性（TUI 断线重连保留草稿、Guardian 历史跨 compact/restart/fork 保留、确认类动作跳过 Guardian）与可见性（plus/team 五小时窗口余量提前警告、history 展示完整 patch）。最后 0.153.2 单纯把 GPT-6-Astra Fast 文案从 1.5× 改为 2× 是版本控制的小补丁，但 0.153.1 已经把 Astra 暴露到 API 表面。这与今天 OpenAI Devs 把 GPT-6-Astra 完整价目放出来的时间线一致。
