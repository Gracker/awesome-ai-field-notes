## English Abstract

Automating printed circuit board (PCB) routing requires coordinating board-level connectivity decisions with geometric execution under strict design rules. Although recent agents can interact with native routing tools, reliable routing on complex boards remains challenging. We present PCBRouteAgent, a multimodal PCB routing agent inspired by how human engineers coordinate global strategy with local execution. A Global Routing Planner combines board images and structured electrical and geometric information to specify connection topology, routing order, corridors, and layer transitions. A Detailed Routing Executor realizes these guides through KiCad's native routing engine and performs bounded iterative refinement.

## English Summary

PCB routing requires coordinating board-level connectivity decisions with geometric execution under strict design rules. PCBRouteAgent mirrors how human engineers pair global strategy with local execution: a Global Routing Planner combines board images with structured electrical and geometric data to specify connection topology, routing order, corridors, and layer transitions; a Detailed Routing Executor realizes these through KiCad's native routing engine with bounded iterative refinement. The paper also measures how close LLM agents are to routing engineers. A concrete layered template for EDA automation and embodied engineering agents: semantic planning to the model, geometric execution to domain tools.
