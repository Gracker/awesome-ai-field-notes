## English

"In the 1950s, we met users at a bank. In the 70s, an ATM. In the 90s and 2000s, a website and a mobile app. Today, it's APIs and MCPs." Here's my new episode with @rywiggs (Mercury's VP of Product) where he shares: How to build great APIs + MCPs for agents, How to create a Claude Code second brain to 2x your productivity at work, What @mercury's data reveals about OpenAI and Anthropic's race for the enterprise. Some quotes from Ryan: "Don't start with the MCP. Start with the foundation. Build great APIs first." "I pulled 5M words from my last 5 years of PM work into Claude Code (using QMD search). That's the base of my second brain." "After meetings, Claude tells me when I did something from my performance review. It keeps me accountable daily." 

## 中文

「20 世纪 50 年代，我们在银行与用户见面。70 年代，有了 ATM。90 年代和 2000 年代，有了网站和移动应用。今天，是 APIs 和 MCPs。」这是我和 @rywiggs（Mercury 产品副总裁）的新一期节目，他分享了：如何为 AI 代理构建出色的 APIs + MCPs、如何创建 Claude Code 第二大脑让工作效率翻倍、@mercury 的数据揭示了 OpenAI 和 Anthropic 在企业市场的竞争态势。Ryan 的几句原话："不要从 MCP 入手。先打好基础。先构建出色的 APIs。""我把过去 5 年产品工作积累的 500 万字内容导入了 Claude Code（使用 QMD 搜索）。这是我第二大脑的基础。""每次会议后，Claude 会提醒我完成绩效评估中的某项事项。它让我每天都有责任感。"
