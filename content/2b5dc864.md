## 要点

- **MiniMax M2.7** 开源（官方后更正为"open weight"），在 SWE-Pro 达到 56.22%、Terminal Bench 2 达到 57.0% 的 SOTA 性能
- 参数量约 10B（Q4_K_M 约 140GB），性价比极高
- **许可证争议**：社区广泛批评其许可证限制商业使用，被指"虚假开源宣传"
- MiniMax 随后更正术语，改为"open weight"而非"open source"
- 已可在 Hugging Face 下载，也有 API 和 Ollama 云端部署选项
