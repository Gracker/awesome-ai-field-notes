## English Summary

Omnigent is an open-source meta-harness: a common orchestration layer over Claude Code, Codex, Cursor, OpenCode, Goose, Antigravity, GitHub Copilot, Devin, Kiro, Qwen Code, Kimi Code, Grok Build, Jcode, Hermes, Pi and custom YAML-defined agents — swap or combine harnesses without rewriting, enforce policies and sandboxing uniformly, and keep sessions in sync across terminal, browser, and phone with live sharing and forking. Apache-2.0 licensed Python project with 11.6k stars, created June 2026 and actively developed (last push 2026-11-27); the README self-labels alpha status. For one-person-many-tools workflows, its value is policy, sandboxing, and multi-device continuity without locking into a single harness.
