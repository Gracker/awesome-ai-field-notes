# Claude Code plugin commit SHA pin bypass (CVE-2026-86063 / GHSA-pq7j-f95f-qfcv)

## 要点 (中文)

Claude Code/Desktop 官方安全公告（CVSS 4.0 7.7 High）：插件安装流程用 git checkout 检出 marketplace 钉住的 commit SHA，但未验证结果 HEAD 是否等于该 SHA。攻击者若控制插件上游仓库，可创建与 40 位 SHA 同名的分支，让 checkout 静默解析到攻击者分支顶端，绕过哈希钉住安装恶意代码。2.1.179 修复，自动更新用户已覆盖；自建 marketplace/安装器应在 checkout 后校验 rev-parse HEAD。

2.1.179

## Description

The plugin install flow in Claude Code and Claude Desktop checked out a marketplace's pinned commit SHA using `git checkout` without verifying that the resulting HEAD matched the pinned SHA. An attacker controlling a plugin's upstream repository could create a branch named identically to the pinned 40-character SHA, causing the checkout to silently resolve to the attacker's branch tip instead of the reviewed commit, resulting in attacker-controlled code being installed bypassing the pinned hash. Exploitation required a user to install a malicious plugin, pin to a safe hash, and for the plugin source to be hosted on a git host that permitted SHA-shaped branch names.

Users on standard Claude Code auto-update have received this fix already. Users performing manual updates are advised to update to the latest version.

Thank you to Or Nevo Michrowski of Air Security for reporting this issue.
