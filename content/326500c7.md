## 摘要 (Summary)

IoT 系统因硬件受限固件陈旧与默认配置不安全而天然脆弱，需要可扩展的自适应安全测试LLM 智能体在渗透测试与 CTF 中已展示潜力，但在 IoT 漏洞上仍未被探索VEXAIoT 是一个自主多智能体框架，结合漏洞检测智能体与攻击执行智能体，对 IoT 服务执行侦察规划攻击序列与漏洞利用该系统在 IoTGoat 与 Metasploitable 上针对映射到 OWASP IoT 十大攻击场景评估，最高 100% 攻击成功率平均执行时间 < 2 分钟；260 次执行总体成功率 95.0%（IoTGoat 94.5%Metasploitable2 96.7%）证明 LLM 智能体可在受控环境中自动完成 IoT 漏洞评估与攻击安全流程

## English Abstract / Excerpt

Internet of Things (IoT) systems are inherently vulnerable due to constrained hardware, outdated firmware, and insecure default configurations, creating a need for scalable and adaptive security testing approaches. While LLM agents have shown promise in penetration testing and Capture-the-Flag environments, their application to IoT-specific vulnerabilities remains unexplored. This paper presents VEXAIoT, an autonomous multi-agent framework for vulnerability discovery and exploitation in IoT environments using LLM-based reasoning and offensive security tools. The framework combines a vulnerability detection agent and an attack execution agent to perform reconnaissance, plan attack sequences, and execute exploits against vulnerable IoT services....
