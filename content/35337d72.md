## 中文导读

一份 10 月初中国 LLM 闭门讨论纪要（11-06 经公众号流出）：反蒸馏使蒸馏成本上升 5-10 倍乃至 20 倍，算力被认作最大瓶颈，中美差距预期从 3-4 个月拉长到约 12 个月，若海外实现 RSI 或达 18-24 个月；智谱靠蒸馏 Opus 与押注 coding API 抢到先发但 Q4 被小米/字节/千问围剿，字节坚持自研不蒸馏；闭源降价（每代 GPU token 输出约为上一代 3-4 倍）打破国产「提价」逻辑，价格预期向中间收敛；下一场景押注 AIDD 但医药同行相当悲观；智谱/Kimi 上架 Bedrock take rate 约 10-15%。

## 为什么值得关注

一份把算力、蒸馏成本、格局与 AIDD 全串起来的买方纪要：国内追赶的时间窗正被反蒸馏压缩

单条里最有信息量的是成本结构：蒸馏年开销可到十几亿至几十亿美金量级（对照前三家总融资约 100-150 亿美金），以及「每代 GPU token 输出约为上一代 3-4 倍」对闭源降价空间的解释——这两条把中美两条价格曲线接上了。

## 关键信息

- 反蒸馏：短期蒸馏成本上升 5-10 倍、多则 20 倍；订阅与非定向 API 均有反蒸馏措施；有厂商一天蒸馏约 30 万美金 token（年化约 1 亿美金）
- 差距：中美差距预期 3-4 个月 → 约 12 个月；若海外明年实现 RSI 或达 18-24 个月；海外单个 AI lab 训练算力明年或达 4-6GW
- 格局：智谱先发（坚定蒸馏 Opus 4.5/4.6 + 押注 coding API）Q4 被围剿；字节自研不蒸馏；国内毛利率 20% 多 vs 海外约 45%
- 价格：闭源每代 GPU token 输出约为上一代 3-4 倍，降价不影响利润；价格预期从「向上收敛」改为「向中间收敛」；有用户实测 Codex 比国产 flash 更划算
- AIDD：药企研发费用约中几千亿美金、20-30% 投 AI 即千亿美金场景；但医药同行悲观——瓶颈转到实验、入组、实验猴等物理环节，价值更可能在 CXO/CDMO
- 渠道：智谱、Kimi 已上架 Bedrock，take rate 约 10-15%；Bedrock 约 90% 调用量来自前沿模型，upside 有限
