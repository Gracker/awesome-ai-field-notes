## English Summary

oh-my-pi shipped v18.18.3-6 (Nov 8-9, 2026): v18.18.3 is a breaking change - the ask tool now takes one HTML form ({ html }) instead of questions[], with the model writing the form controls, preselecting its recommendation, and receiving submitted form data as JSON; scripts still passing questions[] break. v18.18.5 added Claude Fable 5.2 and Mythos 5.2 ($8/$40 per MTok, $0.20 cache reads, 1M context) to the catalog the same day Anthropic released them, fixing the new models showing as text-only, non-reasoning, and mispriced, plus a Mythos 5.1 thinking prefix-binding fix; v18.18.6 makes LiteLLM list only models the configured key can call (authenticated /v1/models), listing nothing instead of everything when it fails (#18601). Catalog day-of follow-through decides whether multi-router tools can switch to a new model on release day.
