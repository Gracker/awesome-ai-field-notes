Parameter 披露 ChatGPT 分享页账户接管链，OpenAI 10-26 修复（P1，赏金 $5,000）：分享页 HTML Preview 本应隔离在独立域，但图表组件加载的 MathLive 库在主页面注册了不校验 origin 的 postMessage 监听器；Preview 借它把虚拟键盘布局换成攻击者 HTML，经 innerHTML 进入主页面，再靠无 sandbox 的 srcdoc iframe 拿到 chatgpt.com 本域身份，枚举对话、外传未分享私聊，受害者只需点开链接。第三方库的 postMessage 监听器要算进攻击面，origin 校验不能省。

## English Summary

Parameter's team disclosed an account-takeover chain against ChatGPT shared links, fixed by OpenAI on October 26, rated P1, $5,000 bounty. HTML Previews in shared sessions run on an isolated origin, but the MathLive library loaded by the chart component registered a postMessage listener without origin validation on the main page: the preview swapped the virtual keyboard layout for attacker HTML, which entered the main page via innerHTML and then reached chatgpt.com's own origin through a non-sandboxed srcdoc iframe, with JSONP smuggled via the CSP allowlist's YouTube oEmbed. From there the attacker could enumerate conversation lists and exfiltrate unshared private chats; the victim's only action was opening a link. For iframe/postMessage reviews: listeners registered by third-party libraries are part of the attack surface, and origin allowlisting is not optional.

## 关键信息

- 攻击链：隔离域 Preview → MathLive 无校验 postMessage 监听 → innerHTML → 无 sandbox srcdoc iframe → chatgpt.com 本域身份
- 影响：枚举对话列表、读未分享私聊并外传；受害者动作仅为点开链接
- 事实面经 DevRadar 2026-11-01 与内容选题编排 2026-11-01 P2 双源核对
