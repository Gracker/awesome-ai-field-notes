If you have an expression in _n_ Boolean variables, how long does it take to find out whether some assignment of values to the variables makes the expression true? There is an obvious upper bound: you can find out in 2_n_ steps by exhaustive search, trying all possible ways of setting each variable to true or false.

You can often do better than exhaustive search for a particular problem, but can you _always_ do better, even in the worst case? The Monien–Speckenmeyer branching algorithm, published in 1985, is more efficient than exhaustive search, but it still takes exponential time.

## 3-SAT

The Boolean satisfiability problem (SAT) asks whether a Boolean expression in conjunctive normal form ([CNF](https://www.johndcook.com/blog/seven-normal-forms-in-logic/)) can be satisfied by some assignment of values to the variables. The _k_\-SAT problem is the special case of SAT in which no clause contains more than _k_ variables. The 2-SAT problem can be solved in polynomial time, but the case of the 3-SAT problem is unknown.

The 3-SAT problem is NP-complete, and so if there is a polynomial-time algorithm for solving 3-SAT, every NP problem, including the full SAT problem, can be solved in polynomial time, i.e. P = NP.

The Monien–Speckenmeyer algorithm mentioned above can solve a 3-SAT problem in

_O_( |_F_| φ_n_ )

time, where |_F_| is the length of the input formula and φ is the golden ratio. Now φ < 2, and so this is better than exhaustive search, but the run time is still exponential in the number of variables _n_.

## ETH

The exponential time hypothesis (ETH) claims that 3-SAT requires exponential time, which would imply P ≠ NP. [Anthropic](https://hexagonmath.org/2610.00577v1) and [OpenAI](https://github.com/openai/math/blob/main/preprints/The-Exponential-Time-Hypothesis-is-False-October-25-2026/paper.pdf) have both published proofs that ETH is false. The status of P = NP is still unknown: while 3-SAT does not take exponential time, it still takes more than polynomial time as far as anyone knows.

Yesterday Shiva Kintali posted [A simplified proof of ETH is false](https://shivakintali.github.io/papers/ETH.pdf). The abstract of the paper says

For every fixed ε > 0, we give a deterministic 3-SAT algorithm on _n_ variables and _m_ clauses using

_C__ε_(_n_ + _m_ + 1)_c__ε_ 2_εn_

bit operations, refuting ETH. Our simplified exposition of OpenAI’s proof combines sparsification, bounded occurrences, spectral replacement, and rational interpolation.
