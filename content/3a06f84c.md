## 原文摘录（openai.com, 2026-11-04）

Today we're announcing that OpenAI will acquire Pierre Computer Company, Inc. ("Pierre"), the company behind Code Storage and a family of standout open-source developer tools. If you've browsed files or reviewed a change in the Codex app, you've already used Pierre's Trees and Diffs libraries. We're excited to work with the Pierre team to build on the Git workflows that developers already rely on and adapt them to how teams work with coding agents.

We've seen in our own engineering work how the systems around Git need to evolve as more of that work happens in parallel. Earlier this week, we shared how we're scaling Git at OpenAI with Pando, our in-house source control backend for engineers and agents. With the Pierre team, we wish to set the standard for modern software development: from the first branch an agent creates to that magic moment when code is deployed to the world.

Diffs' Edit mode lets a reviewer fix a line of code right where they spot the problem. Pierre recently released Highlights, an extremely fast syntax highlighter that updates as a developer types or an agent streams code.

Pierre's open-source projects will remain open-source, and we'll continue to contribute to them. Customers can continue using Code Storage after the acquisition closes while we work to bring its features and functionality into Codex.

The closing of the acquisition is subject to customary closing conditions, including receipt of regulatory approvals.
