## 官方博客要点（经搜索摘要核对；直取遇重定向循环，字句以官方原文为准）

- "Android Studio Rabbit 2 is stable today, letting you choose your preferred coding agent, such as Claude Agent, Codex, Antigravity, or any of over 40 ACP-compliant agents, directly in Android Studio to harness its full suite of developer tools."
- Profiling: "Captures production-grade system traces (Perfetto) to debug cold startup latency, UI jank, and background wakeups."
- "New Android skills: We have 30+ skills that cover 20+ areas to give your agents the expertise for complex Android tasks, such as permissions security, Glance widget layouts, Compose performance optimizations, and more."
- "Official Android agent plugins: ... We've also launched official plugins for Claude Code and Codex by OpenAI."（Antigravity 插件新增 Compose 预览查看与真机交互）

## 交叉核对

- heise（10-29）：Dev Summit 10-28/29 于 Mountain View 举行；BYOA 经 ACP 接入 Claude、Codex、Junie、Antigravity，agent 可用模拟器、构建系统、Logcat 与 Android skills；CLI 可作为 Antigravity/Claude/Codex 插件。
- dev.to（10-31）：BYOA 入口在 Settings > Tools > AI > Agents；Change Review 可从 pending agent changes 或 Git changes 窗口发起，/review 命令生成问题报告；Android CLI 插件仓库 android/android-cli-plugin（Apache-2.0），Claude Code 用 `claude plugin install android-cli@android-cli-plugin`，Codex 用 `codex plugin add`。
- The New Stack / Digital Trends：agent 并发继承 IDE 项目上下文；Google 自测 Claude Opus 5.5 借 CLI 在 45 条 user journeys 上找内存泄漏 46 分钟 vs 88 分钟（单次运行，非定论）。
- DevRadar 10-31 补充：Android MCP + AppFunctions、A2UI for Compose alpha、Connected Apps Platform preview；同日 AGP 9.5.0、Rabbit 3 Canary 2。
