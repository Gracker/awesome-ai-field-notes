## 中文摘要

科学机器学习论文通常给出可计算的断言，如相对 MSE 小于 5%、95% 预测区间覆盖测试集等。让 Coding Agent 仅凭论文材料复现这些断言是检验其科研能力的天然基准。本文系统化地让 Agent 跑完论文全流程：复现代码、运行实验、检查数值证据是否真支持论文断言。关键贡献是一个轻量 harness，强制把「生成的代码 / 跑出的数值 / 论文断言」三方挂钩，避免 Agent 在迭代中丢失进度或凭印象判断「差不多对了」。结果显示现有 Coding Agent 在论文复现上的成功率仍偏低，主要瓶颈在于证据追踪与中间结果一致性。

## English Abstract

Scientific machine learning papers typically make computational claims, e.g., that the relative mean square error is less than 5% or that the 95% predictive credible interval covers the test data. A coding agent can be prompted to replicate those claims from paper materials alone, but the prompt does not by itself reliably preserve progress or check whether generated evidence supports the paper&#39;s claims. We introduce Paper-replication, a workflow that makes each selected paper claim a target with recorded evidence, and implement it as a coding-agent skill. The workflow makes the agent record those targets, reconstruct the paper&#39;s method, run computational experiments, link generated outputs to provenance and comparisons with the paper&#39;s claims, record where matched evidence appears in the replication report, and pass validation checks before completion....
