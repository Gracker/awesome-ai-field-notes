## English Abstract

Large language models (LLMs) increasingly run on edge devices alongside tasks that continuously process sensor data. In many applications, these foreground tasks prepare observations as inputs to the LLM, whose outputs guide subsequent processing or actions. The observations must be processed by foreground deadlines, and LLM feedback must arrive while its source observations remain useful. Yet the CPU and accelerators share a unified-memory system, so LLM inference can delay foreground processing through memory-bandwidth contention even when compute resources remain available. We present EdgePace, a bandwidth-aware runtime that protects foreground deadlines while sustaining timely LLM feedback. EdgePace creates safe suspension points across prefill and decode, monitors foreground memory demand and stalls at low cost, and schedules inference according to contention risk, deadline slack, and output freshness. We evaluate EdgePace on a OnePlus 13 and three NVIDIA Jetson platforms using multi-camera processing and robotic target tracking. Relative to unmanaged inference, it reduces foreground deadline misses by 24.1%--96.1% while retaining 64.9%--98.5% of LLM throughput. All measured LLM outputs arrive within their task-defined freshness windows. On OnePlus 13, for example, camera deadline misses fall by 91.3% while 90.4% of LLM throughput is retained.

## English Summary

EdgePace targets edge scenarios where LLM inference shares unified memory with foreground tasks like camera and sensor pipelines: compute is not saturated but memory bandwidth is, and foreground frame processing misses deadlines. The scheduler inserts safe pause points into prefill and decode, monitors foreground memory demand and stalls at low overhead, and schedules inference by contention risk, deadline slack and output freshness. On a OnePlus 13 and three NVIDIA Jetson boards running multi-camera processing and robotic object tracking: foreground deadline misses drop 24.1%-96.1%, LLM throughput is preserved at 64.9%-98.5%, and all outputs land within task-defined freshness windows; on the OnePlus 13 camera deadline misses fall 91.3% with 90.4% of LLM throughput retained.
