## English Abstract

NVlabs arXiv:2609.20519 introduces SoL-Pi, a recursive auto-research harness layer wrapped around the Pi coding agent. Four mechanisms all off by default, all gated on a sol-pi.json config address distinct waste categories: Action Fusion collapses edit/write followed by test/build/run into a single tool request, saving a model round; Online Context Compact decides whether to compress context after a subtask finishes, only acting when expected savings exceed the rewrite cost; ObservationPack archives large outputs locally and forwards only handle / size / short excerpt, paging back raw text when needed; Evidence-Preserving Reducer lets a cheap model read long build/test logs first but requires compact-receipt references to match the archived log line by line....
