## Search API

POST https://api.deepseek.com/v1/tools/search - Bearer auth with the DeepSeek API key, JSON body, base URL https://api.deepseek.com.

Request fields: query (string, required, 1-128 Unicode characters, supports operators); count (integer, default 10, range 1-50); ori_question (optional, the user's original question that triggered the search, 1-128 chars); localization (optional IP address used to localize results); need_content (boolean, default false - whether to return page content in `content`).

Query operators: site: / -site: (restrict or exclude sites, multiple sites OR-joined), - (exclude terms), -"..." (exclude exact phrases), "..." (exact phrase), lang: (comma-separated language codes), after: / before: (date bounds, YYYY or YYYY-MM-DD).

Response items include: rerank_score (0-3 relevance combining relevance/authority/freshness; >=1.5 considered high-quality), title, url, snippet (~100-200 chars, for UI display), summary (~600-800 chars, intended to be read by a model), content (empty unless need_content), site_name, site_icon, date (RFC 3339 UTC or null), authority (0-4 tier, >=3 highly authoritative, -1 unknown).

## Fetch API

POST https://api.deepseek.com/v1/tools/fetch - takes a single `url` field (HTTP/HTTPS, max 8192 chars, no username/password); returns { title, content } where content is the page as Markdown text. Subject to the target site's availability and access policies (HTTP 404 when no usable page content can be extracted; 403 for security-policy rejections).

## Billing

Billed per successful request, not by tokens or result count: Search $0.75 per 1,000 successful requests; Fetch $0.75 per 1,000 successful requests. A request is billable only when it returns HTTP 200 and produces a result (Search: non-empty results array; Fetch: page content). Failed requests, empty search results, and timeouts are not billed; `count` does not affect the per-request price.

Per the docs: when you use the DeepSeek API through DeepSeek Harness, Claude Code, or Codex, server-side tool calls already hit the Search and Fetch APIs and are currently free of charge; per-request billing starts at 00:00 Beijing time on November 1, 2026.

## Rate Limits

For each account, Search and Fetch are limited independently at 5 QPS each, separate from model concurrency limits; requests above the account-level limit receive HTTP 429. Fetch is additionally subject to a per-domain QPS limit. Errors follow the OpenAI-compatible error format (400 invalid request, 401 auth, 402 insufficient balance, 403 security policy, 404 unusable content, 408/504 timeouts, 429 QPS, 5xx internal).
