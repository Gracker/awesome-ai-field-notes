## 英文原文

Peter Steinberger releases gogcli v0.14.0, a command-line tool for managing all Google data operations:

- Local encrypted Git backups
- Resumable Gmail and Drive exports
- Markdown Gmail mirrors
- vCard contact exports
- Slides text/template editing
- Auth and keyring diagnostics

All data is processed locally without third-party involvement, ensuring privacy and security. Ideal for technical users who want full control over their personal cloud data.

Key features:
- End-to-end encrypted local backups
- Resumable transfers for large datasets
- Markdown conversion for email archiving
- Zero third-party cloud dependency
