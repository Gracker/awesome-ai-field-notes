# 中文原文

## gogcli 0.14.0：命令行管理 Google 数据全套工具，含加密备份和 Gmail 镜像

gogcli 0.14.0 发布！这是 Google 数据管理全套命令行工具，主要新功能：

### 0.14.0 新特性

- **🔐 加密备份**：支持导出为 age 加密的 Git 分片（`gog backup`）
- **📬 Gmail + Drive 可恢复导出**：支持断点续传
- **📝 Markdown Gmail 镜像**：将 Gmail 导出为 Markdown 格式
- **📇 vCard 联系人导出**：完整联系人数据导出
- **🎞️ Slides 文本/模板编辑**：支持修改 Google Slides 内容
- **🩺 Auth + Keyring Doctor**：认证和密钥链诊断工具

### 完整功能覆盖

gogcli 是 Gmail、Calendar、Chat、Classroom、Drive、Docs、Slides、Sheets、Forms、Apps Script、Contacts、Tasks、People、Admin、Groups（Workspace）和 Keep（Workspace 专属）的快速脚本化 CLI。JSON 优先输出，多账户支持，灵活认证。

# English Original

## gogcli 0.14.0: Command-line Google Data Management Suite with Encrypted Backups and Gmail Mirroring

gogcli 0.14.0 is out! A fast, script-friendly CLI for Google data. Major new features in 0.14.0:

### 0.14.0 New Features

- **🔐 Encrypted Backups**: Export to age-encrypted Git shards (`gog backup`)
- **📬 Resumable Gmail + Drive Export**: Download with resume support
- **📝 Markdown Gmail Mirrors**: Export Gmail as Markdown
- **📇 vCard Contacts Export**: Full contact data export
- **🎞️ Slides Text/Template Editing**: Modify Google Slides content
- **🩺 Auth + Keyring Doctor**: Auth and keyring diagnostics

### Full Feature Coverage

gogcli is a fast, script-friendly CLI for Gmail, Calendar, Chat, Classroom, Drive, Docs, Slides, Sheets, Forms, Apps Script, Contacts, Tasks, People, Admin, Groups (Workspace), and Keep (Workspace-only). JSON-first output, multiple accounts, flexible auth built in.
