## 中文导读

Anthropic 发布 Claude Haiku 5.5：迄今最便宜、最快、最能干的小模型，定位高吞吐成本敏感任务（摘要、压缩、数据库查询、分类请求），可作 Opus 5.5 与 Sonnet 5.5 之下编码工作的子代理，也因速度适合实时客服与浏览器使用。均价较 Haiku 4.5 低约 75%；同步把 Sonnet 5.5 缓存读价格减半（多数 agentic 工作约便宜 20%），并为 Max/Team 订户新增月度 API credit。基准跨代提升：OSWorld 2.1 offline 72.4%（Haiku 4.5 为 15.7%，GPT-6 Luna 48.9%）、Terminal-Bench 4.0 39.2%（4.5 为 0%）、HLE 无工具 45.9%（带工具 57.4%）、FrontierCode 1.1 Main 46.4%、Chartography 46.4%；GDPval-AA v2.1 得分 1620（4.5 为 735，Sonnet 5.5 参考 1840）。这是首个带可调 effort 档位的 Haiku 级模型，用户可在成本与智能之间选择。客户实测：Asana 任务完成延迟降超 30%、每轮推理最快 2.5 倍；HubSpot 模拟 CRM 门户套件 92.8% 创其测试过的最佳纪录；AlphaSense 每周 800 万次 Ask in Document 调用中，400 条查询上 0.84 vs 0.76。

## 为什么值得关注

小模型的代际跳变幅度已经触及上代能力的水平线：Terminal-Bench 从 0 到 39.2%、OSWorld 从 15.7% 到 72.4%，价格再降 75%。子代理经济学继续改写——高频低难度环节的模型选型空间被重新定价，effort 档位进一步把"这一步要多少智能"变成显式参数。

## English Summary

Anthropic releases Claude Haiku 5.5, its cheapest, fastest, and most capable small model, priced ~75% below Haiku 4.5 on average and aimed at high-volume, cost-sensitive workloads, subagent coding under Opus/Sonnet 5.5, and speed-sensitive uses like browser control. Benchmarks: OSWorld 2.1 offline 72.4% (vs 15.7%), Terminal-Bench 4.0 39.2% (vs 0.0%), HLE 45.9% no-tools / 57.4% with tools, FrontierCode 1.1 Main 46.4%, GDPval-AA 1620 vs 735. First Haiku-class model with an adjustable effort setting. Sonnet 5.5 cache reads halved. Customers: Asana -30% task latency and up to 2.5x faster per-turn inference; HubSpot 92.8% on its CRM suite; AlphaSense 0.84 vs 0.76 across ~8M weekly doc-QA calls.
