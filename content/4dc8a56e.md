## 中文导读

Simon Willison 公开他 vibe coded 即时战略游戏 Battle Drones 的完整过程：7 月的 v1 原型做到 v12，12 次大迭代、321 个提交，主要由 Claude Code 完成，他本人几乎没读过代码，用的还是他不熟的 TypeScript。转折点是给 Opus 5.5 一句「这个游戏还不够好玩，让它好玩得多」，并开 Ultracode 模式（一段 JS 同时调度多个子 agent）跑通宵拿到能玩的版本。Claude 写的 release notes 显示：1200 场 AI 对 AI 测试局里 25 分钟未分胜负比例从 14% 降到 0.9%，落后 800 点资源一方翻盘率从 24% 升到 46%。全部配乐由代码生成、无音频文件；为让两台设备回放状态一致，把 Math.sin/cos 换成自定义实现消除 Chrome/Safari 浮点末位差异；联机从音频消息同步改为 Fly.io 无状态 WebSocket 中继，缩容到零后月成本封顶 2.19 美元。

## English Summary

Simon Willison documents building Battle Drones: twelve major iterations and 321 commits from July's v1 to v12, built mostly by Claude Code while he barely read the code. A single prompt ('make it much more fun') plus an overnight multi-agent Ultracode run produced the playable version: across 1,200 AI-vs-AI test matches, stalemate rate fell from 14% to 0.9% and comeback wins from an 800-point deficit rose from 24% to 46%. All music is code-generated, Math.sin/cos were replaced with custom implementations for cross-browser replay determinism, and multiplayer moved to a stateless WebSocket relay on Fly.io capped at $2.19/month scaled to zero.
