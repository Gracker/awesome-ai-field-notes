## 中文导读

GLM-5.4 是智谱首个基于 Loop Transformer 的旗舰模型：把 GLM-5 基座的 28 层权重共享循环执行两次，750B 参数规模下声称达到 2T-3T 稠密模型的智能水平。为了在循环化后控制部署成本，做了三处改造：逐迭代门控渐进写入残差流、跨循环 KV 共享加滑动窗口（1M 上下文下额外一轮只多一个窗口的 KV）、稀疏注意力索引直接复用。30B 等参数对照实验里，仅多约 10% 训练算力，数学、科学推理与长上下文任务明显提升，思考输出长度还降了 10-14%。推理端错峰最高 200 tokens/s，高峰保持 70-80。定位是"广义编码"：用代码生成视频、游戏、3D 场景与机械 CAD。权重计划在安全加固后开源，API 即将上线。已知局限是容易陷入过长的"马拉松思考"。

## English Summary

GLM-5.4 is Z.ai's first flagship model built on a Loop Transformer: 28 layers of the GLM-5 base run for two weight-shared iterations at 750B scale, claimed to reach intelligence comparable to 2T-3T parameter models. Three changes make looping deployable: per-iteration gated progressive updates, a hybrid KV cache that reuses cross-loop KV plus a local sliding window (an extra loop costs one window rather than a full context cache at 1M lengths), and sparse attention index reuse with zero indexing overhead. A controlled iso-parameter ablation on a 30B model with ~10% more total training compute shows the largest gains in math, scientific reasoning, and long-context tasks, with average output length dropping 10-14% as part of the reasoning shifts into implicit loop depth. Inference reaches up to 200 tokens/s off-peak and maintains 70-80 tokens/s at peak. Z.ai frames this as the start of Generalized Coding: code as the foundation for generating videos, games, 3D scenes, and engineering-grade CAD. Model weights are planned to be open-sourced after safety hardening. Known limitation: the model can get caught in overly long marathon-thinking loops, though the prolonged reflection consistently improves accuracy beyond its parameter count.
