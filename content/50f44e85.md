## ARIS — Auto-Research-In-Sleep

### What Is ARIS?

ARIS is a **lightweight, Markdown-only skill system** for autonomous ML research. It runs in the background — you sleep, it researches. Wake up to find your paper scored, weaknesses identified, experiments run, and narrative rewritten.

**Core philosophy**: Zero dependencies, zero lock-in. Every skill is a plain Markdown file readable by any LLM agent. Works with Claude Code, Codex CLI, OpenClaw, Cursor, Trae, or any LLM agent.

### How It Works

ARIS implements a **5-step adversarial loop**:

1. **Plan** — Define research direction
2. **Draft** — Initial writeup
3. **Adversarial Review** — External LLM critiques the draft
4. **Iterate** — Improve based on critique
5. **Persist** — Save to knowledge base

The key insight: using **two different models** (one executor, one reviewer) avoids self-play blind spots. Single-model self-review is like stochastic bandits — predictable reward noise. Cross-model review is adversarial — the reviewer actively probes weaknesses the executor didn't anticipate.

### Key Features

**Speed × Rigor**: Claude Code for fast execution; Codex (GPT-5.4 xhigh) for deliberate, rigorous critique.

**Standalone CLI**: ARIS-Code v0.4.5–v0.4.11 offers a full-featured command-line interface with:
- Multi-provider support (DeepSeek V4 Pro, Xiaomi MiMo, Qwen 3.6, Doubao, custom OpenAI-compatible)
- First-class reasoning model support with thinking content blocks
- Stream + MCP reliability improvements
- 74 bundled skills, 49 helper resources

**Research Wiki**: Persistent knowledge base for papers, ideas, experiments, and claims with relationship graphs.

**Self-Evolution**: `/meta-optimize` analyzes logs to propose SKILL.md patches.

**ARIS-Anything**: The 5-step loop framework extends beyond academic research to investment due diligence, legal research, market research, self-driven learning, investigative journalism, and engineering retrospectives.

### Recent Updates (v0.4.5–v0.4.11)

- New providers: DeepSeek V4 Pro, Xiaomi MiMo, Qwen 3.6, Doubao, Custom OpenAI-compatible, DashScope
- Reasoning + tool-use first-class (xhigh on the wire, reasoning_content replay, thinking blocks end-to-end)

## ARIS：睡眠中自动搞 ML 研究的开源框架，9 页 ICLR 论文一键生成

### ARIS 是什么？

ARIS 是一个**轻量级、纯 Markdown 的技能系统**，用于自动化机器学习研究。它在后台运行——你睡觉，它研究。醒来时发现论文已被评分、弱点已识别、实验已运行、叙事已重写。

**核心理念**：零依赖、零锁定。每个技能都是纯 Markdown 文件，任何 LLM agent 都能读取。支持 Claude Code、Codex CLI、OpenClaw、Cursor、Trae 或任何 LLM agent。

### 工作原理

ARIS 实现了**五步对抗循环**：

1. **Plan** — 确定研究方向
2. **Draft** — 初步撰写
3. **Adversarial Review** — 外部 LLM 批评草稿
4. **Iterate** — 根据批评改进
5. **Persist** — 保存到知识库

核心洞察：使用**两个不同的模型**（一个执行器、一个评审）可以避免自玩的盲点。单模型自审查就像随机老虎机——可预测的奖励噪声。跨模型审查是对抗性的——评审者主动探查执行者未预料到的弱点。

### 核心特性

**速度 × 严谨性**：Claude Code 负责快速执行；Codex（GPT-5.4 xhigh）负责深思熟虑、严谨的批评。

**独立 CLI**：ARIS-Code v0.4.5–v0.4.11 提供功能完整的命令行界面：
- 多 provider 支持（DeepSeek V4 Pro、Xiaomi MiMo、Qwen 3.6、Doubao、自定义 OpenAI 兼容、DashScope）
- 一级推理模型支持，thinking 内容块端到端处理
- 流式 + MCP 可靠性改进
- 74 个捆绑技能，49 个辅助资源

**Research Wiki**：持久的知识库，用于存储论文、想法、实验和主张，以及关系图。

**Self-Evolution**：`/meta-optimize` 分析日志，提出 SKILL.md 补丁建议。

**ARIS-Anything**：五步循环框架扩展到学术研究之外的应用——投资尽调、法律研究、市场研究、自驱学习、调查新闻、工程复盘。

### 最新更新（v0.4.5–v0.4.11）
