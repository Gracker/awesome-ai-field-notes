## English Summary

Apiiro research: Claude Code's 'Yes, and don't ask again' saves the exact approved command, secrets included, as an allow rule in .claude/settings.local.json, which then gets committed like any project file. Of 104,185 public copies on GitHub, 1,122 (1.1%) hold real secrets - 1,379 distinct, including 379 database passwords, 122 Supabase service-role keys, 43 SSH logins, 23 AWS keys; counting git history, shared settings, and agent transcripts, 2,539 secrets across 1,994 repositories at 63 organizations, one key confirmed live. gitleaks flagged 564 of the 1,122 files, TruffleHog 643, leaving 215 missed by both - typically passwords typed inside commands. Guidance: rotate before cleanup, untrack the file, treat agent folders like .env, approve patterns not literal commands.
