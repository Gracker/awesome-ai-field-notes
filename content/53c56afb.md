## 中文导读

OpenAI 11-05 发布 GPT-6 Cyber：GPT-6 Astra 的网络安全专用变体，面向授权漏洞挖掘、exploit 开发与 web 渗透。Preparedness 网络安全档升到 Critical；ExploitGym 利用率 48.5%（前代 32.1%），Honeypot 越界率约 0.07%（对照 5.51%）。实战自述含 Linux 948 个可用 LPE、Firefox 81 个 high 新问题。调用走 API/Codex，先向获批 Daybreak Red 组织开放，要求 SSO/MFA/IP 白名单。

## 关键信息

- 发布：2026-11-05，产品文 + system card（deploymentsafety.openai.com/gpt-6-cyber）

## 原文摘录（system card, Published November 5, 2026）

> GPT-6 Cyber is a cyber-specialized variant of GPT-6 Astra designed for authorized security work, including tasks such as vulnerability discovery, exploit development, and web pentesting.
>
> Under our Preparedness Framework, we give GPT-6 Cyber the same capability designations as GPT-6 Astra: Critical in Cybersecurity, High in the Biological and Chemical domain, and below High in AI Self-Improvement.
>
> Access to GPT-6 Cyber is restricted through Daybreak Red, with identity verification, use restrictions, and organizational security requirements including single sign-on, multi-factor authentication, and API IP allowlisting. API customers using Zero Data Retention generally require Private Safety Processing for automated safety review.
