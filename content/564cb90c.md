## 中文导读

dots-studio 开源 dots3-note-prev（Apache-2.0，gated=false 可直接拉）：280B 总参 / 16B 激活的多模态 MoE，上下文 512K，输入 text/image/video/audio、输出 text。架构字段（README 表）：256 routed + 1 shared 专家、top-8 路由；1 dense + 45 MoE 层；视觉 MoE ViT 7B total / 1.2B active，音频 Dense 800M；精度 BF16/FP8。官方任务列表明确写工具使用与多步 agent、需要探索/记忆更新/适应的交互任务——这是模型卡层"agentic"声明。部署建议单机 8 GPU FP8 + SGLang/vLLM（另有 fp8 仓 dots3-note-prev-fp8）；Transformers PR #47844、SGLang PR #33829 审查中，可用 PR revision。chat template 含 `enable_thinking` / `clear_thinking` 开关。OpenRouter 有 free 端点（dots-studio/dots-3-note-preview:free）。注意：X 主帖宣传的 TEMPO（self-critiquing + test-time value 长程 RL）与 Vibe*Bench 未在 HF README 正文坐实，属 social_announcement 层，方法细节待 tech blog（studio.dots.ai 本轮页面偏壳）。

## 为什么值得关注

开源权重里少见的"长上下文 + 多模态 + agent 任务声明"组合：512K 上下文按 active 16B 估算成本，与 Qwen3.8-27B dense 单卡量化冒烟是两条并行路线，显存/serving 形态不同勿直接套表。对自演化 L0–L4 框架：模型卡只提供 L0 实验原料与场景覆盖，验收权仍在 harness，不因换底座自动升级。TEMPO 方法若后续在 blog/论文落地，再单开方法条目。
