## 背景

Claude Code 是 Anthropic 推出的 AI 编程工具，运行在终端中，能够直接操控本地文件、运行测试、管理 Git 工作流。截至 2026 年，Claude Code 已成为最受开发者喜爱和使用最广泛的 AI 编程工具。

然而，Claude Code 的 API 费用对于部分用户来说过于昂贵。通过配置环境变量，将 Claude Code 的底层模型替换为国产大模型，可以显著降低成本，同时保持 Claude Code 工作流的体验。

---

## 快速配置教程

### 方案一：DeepSeek V4（推荐）

DeepSeek V4 是当前全球性价比最高的开源推理引擎，能够真正与 GPT-4o、Claude 3.5 等闭源巨头抗衡。

**配置步骤：**

1. 访问 DeepSeek Open Platform（platform.deepseek.com）注册并充值
2. 生成 API Key
3. 在终端运行：
```bash
ANTHROPIC_BASE_URL=https://api.deepseek.com/anthropic ANTHROPIC_AUTH_TOKEN=你的API密钥 ANTHROPIC_MODEL=deepseek-v4-flash claude
```

注意：命令中的空格不能缺少，建议先复制到文本编辑器中检查。

### 方案二：智谱 GLM-4 系列

智谱是国内最早实现 Claude 协议兼容接口的大模型厂商之一，配置方法类似。

### 方案三：Qwen（阿里通义千问）

Qwen 3.6-Plus 是阿里巴巴最新的旗舰模型，拥有 100 万上下文窗口，Agent 编程能力强。

### 方案四：Kimi（月之暗面）

Kimi K2.6 在长上下文理解方面具有优势，适合处理大型代码库。

## 实际使用体验

以 LC03 项目为例，向 Claude Code 发送指令："创建一个 LC03 的介绍页面，要求：白色主题、极简高科技审美、针对桌面体验优化。完成后自动在浏览器中打开 HTML。"

Claude Code 将自动：
1. 规划文件结构
2. 编写代码
3. 处理权限
4. 打开浏览器预览

用户只需要做高层架构决策。

---

## 为什么选择国产模型？

1. **降低成本**：API 价格远低于 Claude/ GPT 系列
2. **合规性**：无需魔法上网，数据留在国内
3. **保持控制**：减少对外部黑盒的依赖，核心业务逻辑更可控
4. **性价比**：DeepSeek V4 等模型在代码任务上已接近顶级闭源模型
