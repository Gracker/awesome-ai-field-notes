OpenAI has introduced a new memory system for ChatGPT called "Dreaming." The system periodically consolidates a user's historical interactions during idle periods, extracting long-term preferences, recurring topics, and stylistic cues, so that the model can remember each user's working style, key project context, and personal habits across sessions. The result is a more coherent and personalized experience.

## What is "Dreaming"?

Dreaming is a background consolidation process that runs while the user is not actively chatting. It reads past conversations, distills them into stable memory facts, and re-injects them into the model's context as long-lived memory entries.

## How it differs from existing memory

Compared to the original ChatGPT Memory (rolled out in 2024), Dreaming goes further by:
- Continuously refreshing memory rather than only on explicit prompts.
- Maintaining richer structured context (projects, contacts, recurring tasks).
- Respecting a per-topic decay model so old, unused signals fade.

## Privacy and controls

Users retain full control over what is remembered. Dreaming-derived facts can be inspected, edited, and deleted from the Memory settings page. OpenAI has stated that no memory is shared across accounts and that users can opt out entirely.

## 什么是 "Dreaming"？

Dreaming 是一种在用户未与 ChatGPT 交互时于后台运行的过程。它会读取过往对话，将其提炼为稳定的"记忆事实"，并以"长寿命记忆条目"的形式再次注入到模型的上下文中。

## 与已有 Memory 的区别

相比 2024 年上线的初代 ChatGPT Memory，Dreaming 走得更远：
- **持续刷新**：不再仅在被显式提示时更新，而是持续不断地刷新记忆；
- **结构更丰富**：维护更结构化的上下文（项目、联系人、反复出现的任务等）；
- **按主题衰减**：引入"按主题遗忘"机制，长期不活跃的信号会自然淡出。

## 隐私与控制
