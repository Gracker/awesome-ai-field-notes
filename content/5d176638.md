## 中文导读

Cursor 11-05 changelog 推出 Live Apps：cloud agent 从描述直接搭出可分享的在线应用——脚手架 Web、按需起 Postgres、认证挂 Cursor SSO、自动托管，发布时选域名拿活链接。发布前四项硬检查永远开启（密钥/凭证/.env/source map 一律拦截），叠加 deterministic + agentic 审查；分享分邀请/Team/Public 三档，Teams/Enterprise 默认关 public；secrets 对 agent 不可见。仅限已开通 cloud agents 的付费计划，本地 agent 不支持。

## 为什么值得关注

把「写完就死在 localhost」的内部工具直接变成可分享应用，四项发布硬检查是同类平台值得抄的作业

云 agent 只会提 PR 的分层就此多了一档：直接产出托管应用。发布门、三档分享与 agent 不可见 secrets 的设计，比「一键部署」口号更值得记录。

## 关键信息

- 入口：启动 cloud agent 并明确说要做 app；本地 agent 不支持；资格=已开通 cloud agents 的付费计划
- 流程：脚手架 Web → 需要时 Postgres → Cursor SSO 认证 → 托管；连数仓等再要 secrets
- 发布门四项永远开启：拦应用文件内 secrets / 凭证文件 / .env / source map；AI security review 可加规则不可去内置
- 管理员：看全部 app/secret、加审查规则、放行被拦发布（恶意代码/硬编码 secrets 不可放行）、下架任意 app、变更进 audit log
- 分享三档：邀请 / Team（需登录）/ Public；Teams/Enterprise 默认关 public；每 app 隔离托管账户
- 仓库：Cursor Origin 或 GitHub，GitLab 等稍后；放量中（部分账号 dashboard 尚无 publish tray，官方称 rollout）

## 原文摘录（changelog 2026-11-05）

> Agents have lowered the cost of writing code, but most apps and tools that users build never make it off of localhost. Now, you can build live apps directly in Cursor and share them with a link.

> When you publish an app, Cursor will run deterministic and agentic security checks to catch common issues, like secrets written in app files or exposed credentials. If a check fails, the agent tells you what it needs to fix. Nothing goes live until the checks pass and you explicitly publish the app.

## English Summary

Cursor's Nov 5, 2026 changelog ships Live Apps: describe an app and a cloud agent scaffolds the web app, spins up Postgres if needed, puts auth behind Cursor SSO, and provisions hosting; publishing picks a unique domain and returns a live link. Four publish gates are always on (blocking secrets written in app files, credential files, .env files, and source maps), with deterministic and agentic security review layered on top; nothing goes live until checks pass and you explicitly publish. Team admins can see every app and secret, add custom rules, approve blocked publishes, and unpublish any app. Sharing has three tiers (invite / team / public), public off by default on Teams and Enterprise; agent-facing secrets stay invisible to the agent, and automation uses a x-cursor-app-token API key header. Cloud-agent-only on paid plans; local agents unsupported.
