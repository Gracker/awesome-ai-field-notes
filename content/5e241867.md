## 中文导读

Cloudflare 与 VoidZero 同 Owner.com 的 Max Schwenk 合作把 TypeScript 编译器移植到 Rust（tsrs），孵化在 Oxc 工具链里，强调不 fork 语言、设计与方向仍归 TypeScript 团队，并将与 Theo Browne 的 tsc-rs 合并以补齐全类型检查特性与 LSP。基准：相同 type check worker 数下比 TypeScript 7.0 快最多 8 倍、内存省约 70%；文中同时给出保守参照——TypeScript 7.1 beta 本身已比 7.0 快最多 2.5 倍（部分优化从 tsrs 上游回灌），基准配置与 TypeScript 团队对齐。选 Rust 落在 Wasm：Go 编译到 Wasm 要把 GC 一起编进去，Rust 的内存模型让 Wasm guest/host 直接内存交互，配合 Workers 的 wasm-bindgen Emscripten target，完整类型检查工具链可进 Worker、浏览器与嵌入式设备；npm install tsrs 已可试。维护照搬 Vinext 的 agent 流水线：每天 agent 拉上游 diff 开 tracking issue，每晚重跑兼容矩阵，发现行为差异由 agent 定位跨仓库改动、构造复现、移植测试并提修复；性能优化回馈微软的 TypeScript Go 代码库。「为什么是现在」的观察：frontier 模型几天内就能独立完成大规模移植，于是同时出现 slopfork、忠实移植与彻底重新架构三个流派——重写成本塌了之后，真正的约束变成能不能持续跟住上游。

## English Summary

Cloudflare and VoidZero, working with Max Schwenk (Owner.com), are porting the TypeScript compiler to Rust as tsrs, incubated in the Oxc toolchain — explicitly not a fork, with plans to merge Theo Browne's tsc-rs for full type-checking and LSP support. Benchmarks: up to 8x faster than TypeScript 7.0 with ~70% less memory at equal type-check workers, with the honest caveat that TS 7.1 beta is already up to 2.5x faster than 7.0 (partly from tsrs backports), measured on aligned configs. Rust is chosen for Wasm: no GC payload, direct guest/host memory interaction, and Workers' wasm-bindgen Emscripten target put a full type-checking toolchain in Workers, browsers and embedded devices (npm install tsrs). Maintenance copies the Vinext agent pipeline: daily upstream-diff triage issues, nightly compatibility matrix reruns, and agents that locate cross-repo changes, build repros and propose fixes.
