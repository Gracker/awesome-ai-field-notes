**Claude Code 做私人教练：AI 会议复盘系统**

"AI 作为教练的效果，真的令人惊讶。"

@rywiggs（Mercury VP）构建了一套 Claude Code 系统，可以从 @meetgranola 提取会议记录，并与他的绩效评估和教练反馈进行交叉比对。

"它告诉我：嘿，在这次会议里，你做的正是你绩效评估里的某个具体事项。它以一种比其他任何系统都快的频率让我保持诚实。"
