## English Abstract

Multimodal GUI agents read an interface through two redundant channels: the rendered pixels of a screenshot and a serialized structure such as a DOM or accessibility tree. Before acting, an agent forms a belief about the current interface state, but existing benchmarks score task success, element grounding, or attack resistance and do not ask whether that belief is drawn from the pixels. We formalize visual state reliance and measure it with paired single-channel interventions over 310 real web, mobile, and desktop probes. Across five models from three vendors, textual state beliefs defer to structure while image-only accuracy stays near ceiling, and Perception-Fusion Gap is positive for every model. A white-box ablation traces the effect to a single copied structural value, and in two live environments the conflict drives wrong actions and real task failure.
