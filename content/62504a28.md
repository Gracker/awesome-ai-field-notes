## 中文导读

AWS 11 月 11 日放出 AWS Emulator：装在本地就能跑的 AWS 服务模拟器，代码全部由 agent 写出（github.com/aws/aws-emulator）。机制是把公开 Smithy API 模型当行为规格：agent 先编端到端客户场景、在真实 AWS 上跑通以记录真实行为，再照测试写模拟器，失败处即缺口清单；已覆盖 400+ API 模型、200+ 服务，前三周 29,684 次提交。Vogels 复述 Kiro 重写 Alf 复制引擎：给足规格与测试环境后，四个月的手工工作约两小时完成，瓶颈从写代码挪到可验证性。

## English Summary

AWS released AWS Emulator on Nov 11, 2026: a local simulator whose code was written entirely by agents (github.com/aws/aws-emulator). The fidelity loop treats public Smithy API models as behavioral specs: agents generate end-to-end customer scenarios, run them against real AWS to record actual behavior, then write the emulator against those tests, with remaining failures forming the gap list. It covers 400+ API models and 200+ services, with 29,684 commits in the first three weeks (32,502 total by Nov 14). Vogels frames the engineering shift via his Alf replication-engine story: four months of hand-built work in 2004 was rewritten with Kiro in roughly two hours once specs and a test environment were supplied - the bottleneck has moved from writing code to verifiability.
