## English Summary

Endor Labs' Agent Security League is an open, continuously updated benchmark tracking both the functional and the security correctness of popular AI coding agent harnesses (Claude Code, Codex, Cursor, SWE-Agent) across 33 agent+model combinations on real-world tasks. The headline finding is the gap between the two axes: the best functional correctness score is 87.2% (Claude Code with Claude Fable 5.1), while the best security correctness for that same top combo is only 37.4% - code that works is routinely insecure. The public leaderboard is sorted by security correctness and dated per combo as new commercial agents and models ship (top entries 2026-06 through 2026-10). Methodology extends CMU's SusVibes: 200 tasks drawn from 108 open-source Python projects spanning 77 CWE vulnerability classes, FuncPass (generated code passes the functional test suite) vs SecPass (also passes security tests), with prompt hardening, workspace sanitization, and automated cheating detection.
