## English Abstract

Cursor's 2026-09-02 blog post introduces Self-Hosted Machines: the agent loop and inference still run in Cursor's cloud, but agent execution lands on worker machines managed by the customer. Workers join via agent worker start and egress over HTTPS. Tool output and transcripts still flow back to Cursor's cloud orchestration, which is distinct from 'fully self-hosted'; the subscription/orchestration and execution location split into two separate planes.
