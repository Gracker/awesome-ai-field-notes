## Abstract（节选原文）

> We present WeLM-Image, a unified image foundation model that integrates multimodal understanding into text-to-image generation, instruction-guided editing, and multi-reference synthesis. Designed for single-GPU deployment in WeChat's large-scale consumer applications, the model processes text, reference images, and target latents as one interleaved sequence. A Mixture-of-Transformers (MoT) backbone combines shared attention with independent understanding and generation parameters to limit optimization interference. Equipping each path with Mixture-of-Experts (MoE) modules provides sparse capacity, with 31.7B stored parameters and approximately 5.4B generation parameters activated per target latent token.

## 中文摘要

WeLM-Image 把多模态理解并入文生图、指令编辑与多参考合成：文本、参考图与目标 latent 拼成一条交错序列；Mixture-of-Transformers 骨干共享注意力、分离理解与生成参数以减少优化干扰；各路径配 MoE 稀疏容量——存储 31.7B、每个目标 latent token 约激活 5.4B。数据引擎结合知识接地视觉词表与大规模视觉聚类，双语标注与经验证的编辑监督。面向微信消费级场景单卡部署：Turbo 版报告单张 NVIDIA H20 上 8 步生成 1024×1024 图像耗时 4.98 秒（"单卡"指 H20，不是移动端）。
