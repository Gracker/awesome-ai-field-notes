# OpenClaw 2026.5.2：插件安装更稳、Agent 热路径更轻

Peter Steinberger 转发 OpenClaw 2026.5.2 发布，重点是修复通过 npm 安装时的依赖问题和慢安装问题。OpenClaw 在该版本中将大部分能力迁入 extensions，让包体更轻，也让插件安装和更新流程更稳。

这次发布还提到 Gateway 与 agent hot path 的瘦身，以及 Discord、Slack、Telegram、WhatsApp、TTS、Realtime、web search、voice-call 等集成修复。整体不是新功能堆叠，而是围绕稳定性、安装体验和运行路径的工程清理。

## English Summary

Peter Steinberger highlighted OpenClaw 2026.5.2, a release focused on fixing npm dependency and install-speed issues, moving most plugin functionality into extensions, and making plugin install/update paths sturdier. The release also trims Gateway and agent hot paths and includes fixes across messaging, voice, realtime, and web search integrations.
