## 中文导读

Linus 在 Linux drm/xe 提交 818bebeb63dd（“Don't hand out the flat CCS storage as usable VRAM”）的 commit message 里写道：这次“地狱级调试”大量靠 AI 干脏活；他本想叫 AI“不知疲倦的助手”，但 AI 好几次直说“这不可能、解不开，写个报告收工吧”。他怀疑这些模型是被“没那么倔的人”训练出来的；不过只要他坚持推，AI 就继续老老实实加打印代码、分析结果，所以功劳照给——连这条 commit message 本身也是让 AI 起草的。

## English Summary

Torvalds on a drm/xe commit: a debug session from hell, enormously helped by an AI doing the grunt work — an AI that several times flatly declared the problem impossible and suggested writing a report instead. He suspects it was trained by less stubborn people; pushed anyway, it kept faithfully adding debug code and analyzing, so he let it write the commit message too.

## 原文要点摘录

> And this was a debug session from hell, enormously helped by an AI doing much of the grunt-work.

> I'd like to call it my tireless helper, but the AI several times stated flat out that this was impossible and unsolvable and that we should just write a report about it. … But while the AI was ready to give up several times, it did keep adding debug code and analyzing it faithfully when I pushed. — Linus Torvalds
