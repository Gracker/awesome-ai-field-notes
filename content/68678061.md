## 中文概要

SpaceXAI 工程师 Lingxi Li 把自己用 Grok Bot 跑迷你工程组织的实战摊开。5 个工程师 Bot 分管 iOS、Desktop+CICD、基础设施、Android、harness，外加 1 个运营 Bot Jenny；每个 Bot 能拉 Cursor cloud agent、带 skill 写详尽 prompt、盯 transcript、用多模态核对截图证据。突破单 agent 上下文上限的关键是共享 Notion 数据库做状态同步：每 30 分钟复盘每个 PR、标 Working / Ready for Review / 自动 code review、低风险 PR 直接合并。手管上限 15 个 cloud agent，舰队化后能同时盯 200+。夜审（凌晨 3 点清代码 / 包体 / 加载速度）和 P0 紧急流程（每 5 分钟纠偏）是两套加值。对个人 / 小团队推 agent 的杠杆动作：共享状态机 + 定时复盘，把监督频率从人驱动改成 timer 驱动。

## English Summary

SpaceXAI engineer Lingxi Li runs a 5-engineer-bot fleet (iOS, Desktop+CICD, infra, Android, harness) plus one ops Bot Jenny. Each Bot launches Cursor cloud agents, loads skills, watches transcripts, and verifies screenshots via multimodality. Breakthrough: a shared Notion database with 30-min PR reviews (Bugbot/CI/conflict), auto-review on 'Ready for Review', auto-merge on low-risk PRs. Solo cap went from 15 to 200+ concurrent cloud agents. Two add-ons: 3am nightly audits (code/package/load time) and P0 emergency flow (5-min transcript checks with active nudging).
