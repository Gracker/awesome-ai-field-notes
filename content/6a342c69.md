# GPT-2 规模模型训练干预实验：学习率是最大变量，Dropout 反而有害

Source: Giles Thomas | 2026-04-23
URL: https://www.gilesthomas.com/2026/04/llm-from-scratch-32m-interventions-conclusion

## Summary (Chinese)
Giles Thomas 在自己训练 GPT-2 规模模型（163M 参数，44 小时本地训练）过程中系统性测试了多种干预手段。按效果排序：学习率调整（最大收益）+ 调度；Weight decay（有效）；QKV bias（微小帮助）；Gradient clipping（效果有限）；PyTorch AMP（训练速度翻倍但 loss 轻微变差）；Weight tying（反而让 loss 变差）；Dropout（移除后明显提升，单 epoch 训练场景不适合）。关键发现：两个 loss 相近的模型指令微调后表现差异极大——其中一个几乎追上 GPT-2 small，另一个远落后。这说明 loss 曲面和指令微调曲面并非完全相关。

## Summary (English)
Giles Thomas systematically tested training interventions on a GPT-2-scale (163M, 44hr local training) model. Ranked by effectiveness: learning rate + scheduling (largest gain), weight decay (effective), QKV bias (marginal), gradient clipping (limited), AMP (2x speed but slightly worse loss), weight tying (worse), dropout (removing it improved performance in single-epoch regime). Key finding: two models with nearly identical loss showed vastly different instruction-tuning performance.
