## English Excerpt

From February 2027, Google's terms require AI agents to reach Gmail, Drive and the rest of Workspace through Google's own MCP servers. What the rule says, what the servers can and can't do, and what to change before the deadline.

On 24 November, Google made its eight Workspace MCP servers generally available and published a new clause in its API terms. From 1 February 2027, any tool that "is or is driven by an AI Agent" must reach Gmail, Drive, Calendar and the rest of Workspace through those servers.

Read the Gmail server's tool list and you'll find that it can search your mail, read threads, create a draft and file things under labels. It can't send a message, reply, forward, or change a draft after creating it. Those tools exist, but Google's quota page says they "require partner access and aren't generally available". ... The addendum also adds data rules that matter to anyone building an agent with memory: ... Google can cap retention of what it calls "Google Technical Information" at 30 days. Its definition includes vector embeddings, memory indexes, user profiles and organisational graphs built from Workspace data. Training, fine-tuning, evals and distillation on the data are banned, as is using it to build a competing Workspace product.

## English Summary

On 2026-11-24 Google made its eight Workspace MCP servers generally available and added a terms clause: from 2027-02-01, any tool that is or is driven by an AI agent, harness, or AI model must reach Gmail, Drive, Calendar, and the rest of Workspace through those MCP servers; disguising an agent to dodge classification risks access restriction or suspension. From the same date, agents calling REST directly breach terms and are rate-limited; non-AI tooling is unaffected. The Gmail MCP server can search, read threads, create drafts, and label, but send/reply/forward/draft-editing stay partner-only, breaking draft-feedback-revise loops; Drive cannot move or share files. Data rules matter for agent memory: Workspace data only for active user-authorized tasks, deleted on disconnect; embeddings and memory indexes capped at 30-day retention; training, fine-tuning, evals, and distillation banned.
