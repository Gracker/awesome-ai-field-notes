## Source Excerpt
# Introducing Kitesurf

Cloudflare says browser engines like Chromium were built for humans, not agents, and consume memory and compute that AI models often do not need. Kitesurf runs entirely on Workers and is designed for agentic tasks such as screenshots and HTML extraction.

Design details include Web Platform Tests, Rust/Wasm, exception handling, component isolation, stateless components, Dynamic Workers, SandboxOutbound as the only network egress path, CDP compatibility, PageScript and PageRenderer. Cloudflare reports around 215,000+ WPT tests passed; on a 14-URL Browser Run corpus Kitesurf used 3.1-3.8x less CPU and 4.7-7.0x less memory than Chromium, while wall time was about 1.7-1.8x slower.
