# X推文流量监控插件和Markdown复制功能

## 原文信息
- **项目名称**：x-viral-monitor
- **作者**：Icy-Cat
- **平台**：GitHub
- **类型**：Chrome 扩展 + 油猴脚本

---

## 核心功能

### 1. 实时流速徽章
在每条推文旁显示每小时浏览量（impression/h），两种样式可选：
- **胶囊实底**：彩色背景
- **经典行内**：纯文字

颜色标签区分流量等级：
| 图标 | 颜色 | 流速 | 含义 |
|------|------|------|------|
| 🌱 | 绿色 | < 1,000/h | 正常 |
| 🚀 | 橙色 | 1,000 - 10,000/h | 有热度 |
| 🔥 | 红色 | ≥ 10,000/h | 爆帖 |

### 2. 爆帖指数（悬浮弹窗）
综合评分 0-100，基于四个加权维度计算，在悬浮弹窗中展示详细数据：
- 浏览量
- 点赞数
- 转发数
- 回复数
- 收藏数

### 3. 流速排行榜
浮动面板——把当前页面可见推文按流速排序的可拖拽面板，可自定义显示列。

### 4. AI 评论生成（Grok）
在任意推文回复框右下会出现 **✦ AI 生成** 按钮，点击：
- 4 套提示词模板（默认 / 中文短评 / 犀利观点 / 贴吧老哥）
- 候选评论流式渲染
- **完全不需要 API key** —— 借用浏览器里 X 已登录会话的 Grok 内置入口

### 5. Markdown 复制与分享
- 在分享菜单将任意推文复制为 Markdown
- 为任意推文生成「感谢星图」—— 把所有转推与引用用户做成动画粒子可视化

## 安装方式

### Chrome 扩展（推荐）
[Chrome Web Store](https://chromewebstore.google.com/detail/x-viral-monitor/dkplofpecmjgbhgjgleeflcnfgfkdfpd)

### 手动安装
1. 从 Releases 页面下载最新版本 zip
2. 解压 → 打开 `chrome://extensions/` → 开启**开发者模式** → **加载已解压的扩展程序**

### 油猴脚本（精简版）
1. 安装 [Tampermonkey](https://www.tampermonkey.net/)
2. 打开 [`userscript/x-viral-monitor.user.js`](https://github.com/Icy-Cat/x-viral-monitor/blob/main/userscript/x-viral-monitor.user.js)，点击"Raw"安装

---

## 工作原理

扩展通过拦截 X 前端的 GraphQL API 响应，提取每条推文的指标数据（浏览量、点赞、转发、回复、收藏、发布时间）。计算平均流速（`总浏览量 / 发布至今小时数`），在推文的操作按钮旁渲染内联标签。

对于未被初始拦截捕获的推文，会通过 TweetDetail API 逐条补充获取数据。
