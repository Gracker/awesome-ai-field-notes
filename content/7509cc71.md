## English Summary

Hacker News top story (~629 points, 433 comments): choosing 'Yes, and don't ask again' in Claude Code stores the entire shell command - including plaintext secrets - as an allow rule in .claude/settings.local.json. Apiiro's public scan found about 104,000 copies of that file visible on GitHub, roughly 1,122 containing real credentials. Claude Code's Boris Cherny (u/bcherny) responded that the file is intended to stay local, is gitignored at creation, and secret scrubbing is being evaluated; commenters stress the actual exposure chain is committing an allow rule that embeds a key, not the button itself. Practical response: keep secrets in environment variables or password-manager CLIs, gitignore the path globally, and audit public repos for committed copies.
