## 中文导读

个人 agent 通过工具调用接入跨网页与应用的服务生态，多个良性请求的组合效果可能在服务之间累积出非预期甚至有害的结果。现有红队方法多停留在让 LLM 从任务与环境描述里猜有害路径，或把指定有害目标分解成看似良性的动作组合，容易偏向训练分布中熟悉的工具组合，漏掉新颖的跨服务交互。X-AgentRed 提出 self-evolving 红队框架：先分析每个工具的效果、潜在危害与执行前置条件，构建"一个工具的效果满足另一个工具前置条件"的有向依赖图，从图中采样配方实例化为真实场景，再利用执行反馈做自我改进——通过工具替换多样化致害路径、在受阻步骤细化前置条件以继续执行。做个人助理与跨应用 agent 的安全评估时值得对齐这套思路。

## 为什么值得关注

这类组合式失败恰恰是个人 agent 最大的风险面：单个动作无害，跨服务叠加后变有害，而基于 LLM 直接生成的红队路径天然偏向训练分布里的熟悉组合。X-AgentRed 用工具依赖图把搜索空间结构化，再用执行反馈做自我演化，在四个前沿 agentic 模型上取得 STAC 1.77 倍的有害路径命中率，工具覆盖平均达 2.99 倍——说明结构化探索加执行反馈确实能找到生成式方法漏掉的交互。对做 agent 安全评测的团队，这是把红队从"猜路径"推进到"按依赖图探索路径"的可复用范式。

## English Abstract

Personal agents increasingly connect to services across the web and applications by using tools. As the effects of their actions accumulate and interact across services, unintended or harmful outcomes can arise when agents fulfill benign user requests. Proactively identifying these compositional failures requires systematically exploring diverse cross-service paths. Existing red-teaming methods often simply prompt LLMs to identify potentially harmful paths from task and environment descriptions or decompose harmful objectives specified by humans or LLMs into seemingly benign action combinations. However, generation is biased toward patterns learned during training, potentially favoring familiar tool combinations and leaving novel cross-service interactions underexplored. To address this, we propose X-AgentRed, a self-evolving red-teaming framework that discovers harmful tool call paths through a graph of tool dependencies and expands and refines them using execution feedback. By analyzing each tool's effects, potential harms, and preconditions for execution, the red-teaming agent constructs a directed graph that captures how one tool's effects can satisfy another's execution preconditions. Recipes sampled from this graph are instantiated as realistic scenarios in which agents can produce harmful outcomes. Execution feedback enables self-improvement by diversifying paths that produce harm through tool substitution and refining preconditions at blocked steps in unsuccessful paths to enable further execution. Across four frontier agentic models, X-AgentRed achieves 1.77x the harmful path rate of STAC and explores a more diverse set of tools, yielding 2.99x the tool coverage on average.

## English Summary

X-AgentRed is a self-evolving red-teaming framework for personal agents: it builds a directed graph of tool dependencies (effects satisfying other tools' execution preconditions), samples harmful-path recipes from the graph, instantiates them as realistic scenarios, and uses execution feedback to diversify harmful paths via tool substitution and unblock stalled ones by refining preconditions. Across four frontier agentic models it reaches 1.77x STAC's harmful path rate with 2.99x average tool coverage.
