## 英文原文

Greg Brockman, President of OpenAI, personally tested and found that GPT-5.5 combined with GPT-Image-2 is the most powerful combination for application development currently available.

This combination has been integrated into the Build Web Apps plugin, where Codex can independently complete the entire process from design to application. DKundel provided a detailed breakdown of why this combination is so efficient — the deep integration of image generation and code generation significantly shortens the path from design to implementation.

For developers, this is the most worthwhile AI development workflow to try right now. The key insight is that visual design generation and code implementation can work in a tight loop, eliminating the traditional friction between designers and developers.
