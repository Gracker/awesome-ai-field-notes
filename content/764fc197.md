## 中文导读

两人实验室 Linum 以 2.1 万美元算力把像素空间文生图模型 Pyramid-JiT 训练到 6.6 亿样本，并以 Apache 2.0 开源模型代码与权重，作为通往视频模型的中间验证P-JiT 不用独立 VAE 压缩：让扩散模型学习为自己用途定制的潜空间，采用 3232 token 缩减（Linum v2/FLUX-2 等 Wan VAE+DiT 为 1616），用原先表示 256 图的 token 预算表示 512 图，注意力窗口缩减 4 倍，收敛样本减少 11 倍文中公开训练设置249 张样图与模型局限，是小团队低成本训练生成模型的一个透明成本/质量数据点

## English Source Excerpts

**Architecture claim**

"In our last blog, we iterated towards a new architecture that we called the Pyramid-JiT (P-JiT). It's a pixel-space model that converges in 11x fewer samples than Linum v2 with 4x more aggressive token reduction (i.e., we represent a 512^2 image in the same number of tokens we used to represent a 256^2 image). Linum v2 is a fairly standard Wan VAE + DiT diffusion model. Linum v2 used a 16x16 token reduction like most models (e.g. FLUX-2). P-JiT enables 32x32 token reduction. This implies a 4x reduction in attention context-window."

**Motivation for dropping the VAE**

"Instead of using another model's latent space, the diffusion model should learn a latent space purpose-built for its use case. In turn, we should be able to squeeze more juice out of this compression."

**Cost breakdown**

"The whole release cost about $21K of compute - Pretraining $20,348 (8,139 H100-hours x $2.50; 610M samples at 512^2, then 50M at 1024^2); Post-training $690 (276 H100-hours x $2.50; FDFO with JEV-Image and human-in-the-loop judges); Total $21,038, 8,415 H100-hours, pretraining on 64 H100s, priced at $2.50 per H100-hour."

**Release and gallery**

"Research release - Apache 2.0 - Model code - Model weights - 249 samples - 2B Pyramid-JiT"

**Stated limitations**

"This model was not trained with images of rendered text (no infographics, PDFs, pages of books, PowerPoint slides), so it cannot write text or generate posters. ... This is a small model (2B-parameter DiT, 4B text encoder), and accordingly there are a few areas where the model struggles: full body, many entities (e.g. 6 cars, crowds), multi-person interactions, and world knowledge."

## English Summary

Two-person lab Linum trains its Pyramid-JiT pixel-space text-to-image model for 660M samples at $21K total compute and releases model code and weights under Apache 2.0 as a stepping stone toward its next video model. P-JiT drops the separate VAE compressor: the diffusion model learns a latent space purpose-built for its own use case, with 32x32 token reduction (vs the 16x16 of Wan VAE + DiT setups like Linum v2 and FLUX-2), representing 512x512 images in the token budget previously used for 256x256 - a 4x smaller attention context window - and converging with 11x fewer training samples. The post documents the training regime, pressure testing with a gallery of 249 outputs, and stated model limitations: a transparent cost/quality data point for small-team generative model training.
