## 中文导读

DeepSeek 把支撑自家大规模生产服务的推理框架 DeepInfer 开源，本 release 面向离线推理，官方支持模型为 DeepSeek-V4.1-Flash。特性清单：FlashMLA、DeepGEMM、DeepEP、TileKernels、DeepSelect 与自研 TileLang 内核；Attention DP / 均衡 CP 与 MoE EP + EPLB 并行；DSpark 置信度调度草稿 token 验证（MTP，默认草稿长度 5）；decoder SWA 有界重放（默认保留后缀 140 token）；默认开启的零开销异步批调度；批不变推理与确定性采样（仅 NVIDIA）；regex / JSON schema / EBNF 结构化输出。硬件支持 NVIDIA SM100 与华为昇腾 950。KV cache 系统、Prefill/Decode 分离的完整服务组件与跨 DP 副本负载均衡不在本 release 内（大部分引擎功能已实现）；框架主要基于 vLLM 构建，Apache 2.0 许可。

## 为什么值得关注

生产级推理栈直接开源：优化内核、并行策略、置信度调度验证、批不变与确定性采样一整套，且 SM100 / 昇腾 950 双硬件线，是部署 DeepSeek 系模型最接近官方生产配置的参考实现。

## 关键信息

- 支持模型：DeepSeek-V4.1-Flash（默认 checkpoint DeepSeek-V4.1-Flash-1017）
- 内核：FlashMLA、DeepGEMM、DeepEP、TileKernels、DeepSelect、自研 TileLang 内核
- 关键开关：DEEPINFER_ENABLE_MTP_VARLEN（草稿验证）、DEEPINFER_YOCO_PREFILL_KEEP_TOKENS=140（SWA 有界重放）、DEEPINFER_BATCH_INVARIANT（批不变/确定性采样，NVIDIA）
- 硬件：NVIDIA SM100 GPU、华为昇腾 950 NPU（基准：prefill 4×SM100、decode 64×SM100）
- 不含：KV cache 系统、完整 VE/Prefill/Decode 分离服务、跨 DP 副本负载均衡
- 依赖：Linux、Python 3.12、GCC≥13、CUDA 13（NVIDIA）/ CANN 9.2（昇腾）；基于 vLLM，Apache 2.0

## English Summary

DeepSeek open-sourced DeepInfer, the high-performance inference framework behind its large-scale production services. This release provides offline inference for DeepSeek-V4.1-Flash with optimized kernels (FlashMLA, DeepGEMM, DeepEP, TileKernels, DeepSelect), Attention DP / balanced CP and MoE EP + EPLB parallelism, DSpark confidence-scheduled draft-token verification, decoder SWA bounded replay, a zero-overhead asynchronous batch scheduler, batch-invariant and deterministic sampling, and regex/JSON-schema/EBNF structured outputs, running on NVIDIA SM100 GPUs and Huawei Ascend 950 NPUs. The framework is built primarily on vLLM and released under Apache 2.0.
