## 中文导读

Reflection AI 发布首个开放权重模型 Beam：稀疏 MoE，总参数 501B、激活 23B，面向 coding / reasoning / agentic 工作流。预训练用 23.8T tokens（web + 专有授权数据），官方称匹配或超过同尺寸开放基座模型。RL 侧是这篇公告最重的部分：10.5K 块 NVIDIA GB300 跑 4 周，产出超过 1 亿条 rollout（最长 256K 上下文），训练与评分用了约 13 亿个 sandbox，环境来自 100 万个精选 coding/agentic/STEM 环境；官方称这是开放实验室迄今最大规模的 RL 运行之一，且 RL 计算拉满仍无平台期。

工程上两个值得注意的点：

- **异步 RL 的稳定性**：全异步策略梯度下，长期 rollout 的样本会严重滞后。Beam 的算法在一天级 stale（落后当前策略 107 个权重版本）时仍保持数值稳定；
- **推理效率**：可控长度惩罚 + reasoning-effort 参数管理 token 成本。在进阶推理基准上拿到与 GLM-5.2 相当的分数，推理计算省 3-4 倍；官方明确承认 Kimi K3 等前沿开放模型在裸能力上仍领先，Beam 的差异化在推理时效率。

成绩：SWEBench Verified 80.9、SWE Bench Pro v1 65.5、Terminal Bench v2.1 80.1、AIME 2026 97.8、MCP Atlas 78.7、GPQA Diamond 90.5。RL 泛化也有证据：RL 配比里没有 browsing 任务，browsing 能力却随训练一致提升；接上 web 后自发学会搜索并查询其他 LLM、调用 OCR API 读文档。权重、技术报告与 model card 本月晚些放出，早鸟注册已开。

## English Summary

Reflection AI introduces Beam, its first open-weight model: a sparse MoE with 501B total / 23B active parameters for coding, reasoning, and agentic workloads, pretrained on 23.8T tokens. Its high-compute RL campaign ran 10.5K NVIDIA GB300 GPUs for 4 weeks, generating >100M rollouts at up to 256K context, using ~1.3B sandboxes and 1M curated coding/agentic/STEM environments — claimed among the largest open-lab RL runs, with capabilities still improving at max RL compute (no plateau). Fully asynchronous RL stays numerically stable at one-day staleness (107 weight versions behind the current policy). A controllable length penalty plus a reasoning-effort parameter manage token cost; on advanced reasoning benchmarks Beam matches GLM-5.2-class scores with 3-4x less inference compute, while the company concedes frontier open models like Kimi K3 remain ahead on raw capability. Scores: SWEBench Verified 80.9, SWE Bench Pro v1 65.5, Terminal Bench v2.1 80.1, AIME 2026 97.8, MCP Atlas 78.7. Weights, tech report, and model card promised later this month; early access open.
