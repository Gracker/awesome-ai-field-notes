## 中文导读

Claude Code 在约两天冻结后从 v2.1.330 升到 v2.1.331（约 11-23 21:34 UTC）。主要变化：终端会话在 Amazon Bedrock、Google Cloud Agent Platform、Microsoft Foundry 和 Claude Platform on AWS 上支持 Code Mode；claude doctor 新增 API 连通性一节，直接给出 HTTP 状态或错误原因；修复本地与 WebSocket MCP 畸形回复导致工具调用最长挂起约 30 分钟的问题——这是本版最值得升级的理由；插件清单支持 optionalDependencies；trace span 补充 gen_ai.usage 等字段。另有窄终端、/diff、/compact 摘要丢段、Remote Control 顺序、Windows 权限等一批修复。说明里预告约 11 月 30 日起 managed extraKnownMarketplaces 默认自动更新，要关可设 autoUpdate:false。

## 为什么值得关注

本版两条对运维有实际影响：一是 MCP 畸形回复挂 30 分钟的修复，属于"升级后少排一夜查"的类别；二是 Code Mode 扩到 Bedrock/Foundry 等云终端，云上跑 CC 的工作流多了官方路径。extraKnownMarketplaces 自动更新默认值变化需要管理员留意。

## English Summary

Claude Code moves from v2.1.330 to v2.1.331 after a two-day freeze. Headline changes: terminal sessions now support Code Mode on Amazon Bedrock, Google Cloud Agent Platform, Microsoft Foundry, and Claude Platform on AWS; claude doctor adds an API connectivity section that reports HTTP status or the error cause; and a fix addresses tool calls hanging for up to about 30 minutes when a local or WebSocket MCP server returns malformed replies - the strongest reason to upgrade this version. Plugin manifests gain optionalDependencies support, and trace spans add gen_ai.usage fields. A batch of narrower fixes covers narrow terminals, /diff, /compact summary truncation, Remote Control ordering, and Windows permissions. The release also announces that managed extraKnownMarketplaces will auto-update by default from around November 30, disable with autoUpdate:false.
