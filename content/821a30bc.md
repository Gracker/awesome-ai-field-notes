## 中文摘要

Claude Code v2.1.234（2026-08-17 发布）把「额度墙」从异常中断升级成可恢复状态：claude.ai 用量限制重置后自动继续当前会话，可在 /config 关闭「Continue automatically at usage limit」。同包还有：内置 claude-api skill 上下文从约 200k+ 压到约 25k（按需加载参考文档）；/permissions 可在工作中打开且改动作用于当前 turn 余下部分（回应规则漂移）；/goal 在不可恢复错误时自清、后台任务卡住 30+ 分钟会 check-in。边界要分清：自动续跑解决「墙倒了要不要人回来点一下」，不解决「墙倒之前上下文已经失控」——跨任务仍应 clear/compact/handoff。与 Hermes v0.20.3 的 session handoff 防丢同属「会话生命周期产品化」一条线。

## English Summary

Claude Code v2.1.234 (released 2026-08-17) turns the usage-limit wall into a recoverable state: sessions continue automatically when a claude.ai usage limit resets, toggleable in /config ("Continue automatically at usage limit"). The same release cuts the bundled claude-api skill's context footprint from ~200k+ to ~25k tokens by loading reference docs on demand; lets /permissions open mid-run with changes applying to the rest of the current turn (an answer to rules-drift complaints); and makes /goal self-clear on unrecoverable errors with a check-in when background tasks stall 30+ minutes. Boundary worth repeating: auto-continue removes the human click after the wall falls, not the dirty context before it — clear/compact/handoff discipline still applies. Sits on the same "session lifecycle productization" line as Hermes v0.20.3's session handoff.
