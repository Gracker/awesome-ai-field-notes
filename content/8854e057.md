# Googlebook Linux Terminal Preview: VM-backed sandbox for agentic development

> 原文链接: https://android-developers.googleblog.com/2026/10/googlebook-linux-terminal-preview-vm.html

## 要点 (中文)

Google 为 Googlebook 推出 Linux Terminal Preview（10 月 12 日），把终端定位成 agent 工作流的入口：所有命令都跑在 Linux VM 沙箱内，用户可以放心给 Antigravity 等 agentic AI 工具 sudo 权限，VM 边界保护宿主 OS 和未挂载文件，每个目录都要用户显式授权才挂载进 VM，一键重置 VM 时宿主文件系统上的文件保留。Debian 环境自带 apt/git/ssh 与 Node/Python/Ruby/Go/Rust 运行时，localhost 端口自动转发到宿主浏览器，VM 内存可调。路线图包括 USB passthrough 与 ADB over USB、动态内存与存储扩容、GPU/NPU 硬件加速、VM 持久化以支持长时间运行的 agent 任务。

## Key claims (English)

Google's Googlebook Linux Terminal Preview puts all terminal commands inside a Debian VM sandbox, so users can grant sudo to agentic AI tools like Antigravity while the VM boundary protects the host OS; directories mount only after explicit permission, and one-click VM reset preserves host files. Roadmap: USB/ADB passthrough, dynamic memory scaling, GPU/NPU acceleration, and VM persistence for long-running agent workloads.

### Introducing the Googlebook Linux Terminal Preview (Android Developers Blog, 12 Oct 2026)

```markdown
## Entry point for agentic development

AI agents use the terminal to install packages, write files, automate tasks, and create apps based on prompts written in plain language. For Googlebook to be the perfect companion for building and working at the frontier of agentic AI, the terminal needed to be easily accessible.

We understand AI comes with risks. Googlebook OS has been architected with defense-in-depth as a core principle. All terminal commands run entirely inside the Linux VM, creating an isolated sandbox. This design allows users to grant `sudo` (administrator) privileges to AI tools like Antigravity and other agentic AI platforms, that make heavy use of command-line tools, while limiting opportunities for system corruption or unauthorized access to your private files. The VM boundary helps protect the host OS and unmounted files; each directory made available to the Linux VM is only mounted after the user's explicit permission. Best of all, a one-click VM reset makes experimentation stress free because users can easily retain their files on the host file system when they reset the VM.

## Linux VM benefits

With a Debian Linux environment, users benefit from the mature ecosystem familiar to Linux developers. This means that they have access to the latest CLI tools and common developer workflows like `apt`, `git`, `ssh`, and common compilers and runtimes. Out of the box, our preview of the terminal on Googlebook has been optimized for rapid prototyping, web development, scripting, and agentic workflows via CLI. There is automatic localhost port forwarding to the host browser, and support for modern runtimes (e.g., Node.js, Python, Ruby, Go, Rust). Users can adjust the amount of memory made available to the VM to best suit their workloads.

## Looking ahead

- In addition to the existing network passthrough and wireless ADB, USB passthrough and support for ADB over USB are coming, enabling local device debugging and more from our Linux VM and Antigravity.
- We are adding dynamic memory and storage scaling for the VM.
- We will be adding GPU/NPU hardware acceleration for heavier local workloads.
- VM persistence and separation from the terminal window will better support long-running processes, when you want to take on more demanding agentic workloads.

```
