## 原文摘录 / Evidence Excerpts

We're moving MCP specification releases to a regular six-month schedule. Two releases a year — we'll generally publish specification releases on the last Tuesday of March and September. For the next release, we're targeting March 30, 2027 - expect MCP version 2027-03-30 to land then.

To keep that schedule predictable, a proposal that isn't ready will move to a later release rather than delay the whole spec.

This changes how we prepare a release, not MCP messages or version negotiation, so there's nothing you need to change in an existing client or server because of this announcement.

The Core Maintainers worked through these questions together at MCPCon Europe, and Kurtis Van Gent recently wrote up the process in SEP-3398: Release Cycle Updates - this is our de facto release guidance moving forward. ... Luca Chang will join David and myself as a Release Manager for the next specification cycle.
