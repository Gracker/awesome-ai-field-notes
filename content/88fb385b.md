### Karpathy 的 LLM Wiki 工作流

Andrej Karpathy 不再只是写代码，而是开始构建"知识库"（Knowledge Bases）。这是一种全新的个人知识管理范式——用 LLM 将原始文档转化为结构化的 Markdown 知识库，让 AI 可以直接查询和推理。

**核心工作流：**

1. **收集（Collect）**：将原始文章、论文、图片保存到一个文件夹
2. **索引（Index）**：LLM 读取并理解这些内容，构建内部索引
3. **查询（Query）**：用自然语言向知识库提问，获得精准回答
4. **迭代（Iterate）**：持续添加新内容，知识库自动扩展

**与传统笔记工具的区别：**

- 不是简单的标签和分类，而是让 LLM 真正理解知识之间的关系
- 可以处理多模态内容（文字、图表、代码）
- 支持跨文档推理，而不只是关键词匹配
- 用 Claude Code 等工具可以 5 分钟快速搭建

Karpathy 强调，这种方法特别适合科研工作者：可以快速消化大量论文，同时保持对关键概念的理解和追溯。

**技术实现：**

- 基于 Obsidian 作为本地存储层
- Claude Code 作为查询和推理引擎
- 通过 LLM 将非结构化文档自动转化为带语义的 markdown
- 支持双向链接和知识图谱构建

这是一种从"笔记软件"到"可推理知识系统"的范式跃迁。
