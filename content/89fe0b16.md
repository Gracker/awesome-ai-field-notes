## 中文导读

这条推是 Anthropic 官方 Opus 5.5 Playbook 的中文实操整理。作者先给出体验判断（文字表达、逻辑深度与速度恢复到“曾经超牛逼的 Opus”），随后整理三点新特性：能独立工作更长时间、用直白的话汇报进度、回复前自动思考（思考多少由模型自定）。

用法改法覆盖三块：提问——一条消息写清“完成定义”（如“所有测试通过”“所有接口迁移完”）和停止条件让它自己跑；删掉“仔细想想”“一步步思考”类提示（它本来就在做）；任务运行中直接补要求；设计需求点名不想要的具体样式（米白背景、标题斜体强调、01/02/03 编号、胶囊按钮），“不要太普通”这类笼统要求无效。Claude Code 长任务——CLAUDE.md 写明何时停何时继续、破坏性命令权限提示保持开启；大任务拆 subagent 并行（审计、迁移、代码库级审查），子代理交回结果先核实证据再汇总成表；任务清单放 TASKS.md 边做边勾（上下文被压缩后清单仍在）。检查结果——先看它需要你做什么（未定决策、待批准改动）再看总结；人工审查前先让它自审，早期测试者称最低 effort 找到的 bug 比 Opus 5 高 effort 还多、误报更少；研究分析让它标出未能确认的内容并说明查过哪些地方。
