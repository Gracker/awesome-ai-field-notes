# Claude Code 2026: New Features and Agentic Capabilities

> 发布时间: 2026-04-24
> 作者: Anthropic Team

---

**摘要 / Summary:**

Claude Code 在 2026 年迎来重大更新，第一季度发布了多个重要功能：Remote Control（远程控制）、Dispatch（后台工作流）、Channels（频道）、Computer Use（计算机控制）、Auto Mode（自动模式）和 AutoDream。Sonnet 5 "Fennec" 作为 Claude 5 代的第一个模型，拥有 100 万 token 上下文窗口，并引入 Dev Team 多智能体协作模式。界面重新设计集成了终端、文件编辑、HTML/PDF 预览功能。新增的 auto-plan 改善代码生成前的规划，auto-memory 允许 Claude 从过去交互中学习，voice mode 优化了语音输入体验。Claude Code Security 也在 2 月推出，用于审查代码库漏洞。总体趋势是从开发者终端工具扩展到更广泛的应用场景。

**English:** Claude Code received significant updates in Q1 2026 including Remote Control, Dispatch, Channels, Computer Use, Auto Mode, and AutoDream. Sonnet 5 'Fennec' features 1M token context window and Dev Team multi-agent collaboration. UI redesign integrates terminal, file editing, HTML/PDF preview. New features include auto-plan, auto-memory learning, and improved voice mode. Claude Code Security launched for vulnerability review. Expanding from developer terminal to broader automation scenarios.
