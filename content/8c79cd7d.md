# What Would a Serious AI Product Look Like?

## 摘要

Glyph Lefkowitz 9 月 27 日长文,把当前主流 AI 产品当作不严肃的 chatbot 逐项拆开,给出七节清单:把「检查错误」列为 first-class feature;引用必须把原文 quotation 摆在比 AI 总结更显眼的位置;研究/编程工具禁止使用第一人称与道歉;自然语言 UI 应被任务专用 UI 替代;机械 API 返回值与 hallucinated data 在 UI 上必须能区分;温度/reproducibility 应默认可见;context 占用与 compaction 影响必须显式;agentic 沙箱必须能拦住破坏性动作。每节都点名具体厂商的现行做法(ChatGPT/Claude/Gemini 的免责声明,Anthropic CI test-impact-analysis 博文,Cursor/Claude Code 数据丢失事故)。文章给出的 checklist 可直接拿去评审产品需求。

## English Summary

Glyph Lefkowitz's September 27 essay dissects current AI products as unserious chatbots, listing seven features a serious research/development tool would have: first-class mistake checking, prominent quoted sources, no first-person/apology framing, task-specific UI over NL UI, distinguishable mechanical vs hallucinated data, visible temperature/reproducibility, visible context usage and compaction effects, and a real agentic sandbox that blocks destructive actions. Each section names a specific vendor pattern (ChatGPT/Claude/Gemini disclaimers, Anthropic's own CI test-impact-analysis post, Cursor/Claude Code data-loss incidents). The piece reads as a direct product-review checklist. The single most leveraged insight is that every modern AI product violates at least one of these rules in its core UI, not just its documentation.
