# CogniConsole: Externalizing Inference-Time Control as a Formal Abstraction for Reliable LLM Interactions

## 摘要 (Summary)

CogniConsole 提出将推理时控制（inference-time control）作为 LLM 系统可靠性的第一类抽象，挑战'可靠性等于模型能力'的传统假设通过可控性导向的探针（N=489）在多步交互环境中测量，论文证明：在固定模型架构下，从非结构化到完全结构化的脚手架（scaffolding）能系统性降低输出方差与失败率许多被归因于'模型不够强'的失效（context drift约束不一致）实际上源自控制层欠规范该工作为'超越规模化'设计 LLM 系统提供了实证基础，把 harness / 控制流从隐式调参变成可分析的一层接口

## English Abstract / Excerpt

Reliability in LLM systems is typically framed as a function of model capability. We challenge this by showing that reliability is significantly influenced by inference-time control, the computational layer governing task framing and context selection. We introduce CogniConsole, an architectural instantiation that externalizes this control into a structured interface combining programmatic coordination with bounded prompt-based reasoning. Through controllability-oriented probes (N=489) in a multi-step interactive environment, we show that increasing structural scaffolding, from unstructured to fully scaffolded, systematically reduces output variance and failure rates under a fixed model architecture. Many observed failure modes (context drift, inconsistent constraint adherence) arise from under-specified control rather than insufficient capability....
