## English Summary

Permission explanations accompanying mobile app permission requests often fall short of regulatory expectations, and there has been no systematic evaluation mechanism. An empirical study of 600 mainstream apps finds 15% of permission requests provide no explanation, others use vague language or jargon, and many omit third-party SDK data access even when those components actively use granted permissions. SCOPE is an automated multi-agent framework with four specialized agents - multimodal LLM explanation extraction, few-shot linguistic analysis, dynamic API purpose inference, adaptive report generation - achieving 98% extraction accuracy, 93.5% compliance-analysis consistency, and 92% purpose-inference accuracy. A 30-participant user study shows 84.6% prefer SCOPE-optimized explanations.

## Source Excerpts

### Abstract (opencli arxiv paper, 2026-11-26)

Through an empirical study of 600 mainstream mobile apps, we reveal widespread deficiencies: 15% of permission requests provide no explanation, others use vague language or technical jargon, and critically, many fail to disclose third-party SDK data access despite these components actively using granted permissions. SCOPE employs four specialized agents: multimodal LLM-based explanation extraction, few-shot learning-based linguistic analysis, dynamic API-based purpose inference, and adaptive report generation - achieving 98% accuracy in explanation extraction, 93.5% consistency in compliance analysis, and 92% accuracy in purpose inference. A user study with 30 participants shows 84.6% preference for SCOPE-optimized explanations.
