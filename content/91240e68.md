## 关键信息

- 论文：arXiv 2602.20426，2026-02-23 提交、2026-04-29 更新，cs.AI；作者 Ruocheng Guo / Kaiwen Dong / Xiang Gao / Kamalika Das（方法名 Trace-Free+）
- 问题：多数工作在改 agent（更大模型、更好提示、微调），性能却在工具接口质量处平台化；工具描述为人类开发者而写，带有 agent 无法消解的歧义，候选工具越多越严重
- 既有方法两个瓶颈：每个新 API 要重跑多阶段流水线（合成查询 → 执行 agent 采轨迹 → 标注 → 多次调用强 LLM）；逐工具独立优化，限制对未见工具的扩展与泛化
- 方法：Trace-Free+ 课程学习框架，把 trace-rich 场景学到的"什么使工具描述有效"的监督渐进迁移到 trace-free 部署；配套从真实 API 出发的数据合成流程，构建大规模高质量工具接口数据集
- 结果：StableToolBench 上候选工具扩到 150+ 时，scaling 实验中精度退化降低 29.23%、平均查询级成功率提升 60.89%；跨域免重训练泛化；与 agent 微调收益互补

## English Summary

Guo, Dong, Gao, and Das (arXiv 2602.20426, Feb 2026): LLM-agent performance plateaus on tool-interface quality - descriptions written for human developers tolerate ambiguity agents cannot resolve, as catalogs grow. Existing fixes re-run a multi-stage pipeline (query synthesis, trajectory collection, annotation, repeated strong-LLM prompting) per API and optimize tools independently. Trace-Free+ is a curriculum-learning framework that progressively transfers supervision from trace-rich settings to trace-free deployment, internalizing reusable patterns of what makes a description effective, with a dataset synthesized from real-world APIs. On StableToolBench, scaling to 150+ candidate tools cuts accuracy degradation by 29.23% and improves average query-level success by 60.89%; generalizes across domains without retraining and complements agent fine-tuning.
