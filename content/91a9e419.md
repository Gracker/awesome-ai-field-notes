## 中文摘要

个性化会让模型对用户说的话不同，论文进一步指出它也会改变模型用来论证结论的推理轨迹。现代 LLM 通常先把用户属性、偏好与历史背景存到记忆里，再注入到后续 prompt 中。本文研究这种记忆是否会影响开放问题（无标准答案）的推理路径：用 DRIFTLENS 在多轮个性化对话上做时间序列切片，追踪同一个推理任务在「无记忆 / 有记忆但少用户上下文 / 完整个性化记忆」三种条件下答案与解释轨迹的偏移。结果发现即使最终答案正确，推理步骤也会随记忆累积发生漂移，提示个性化系统的评估不能只看准确率。

## English Abstract

Personalization changes what a model says to a user; we show that it can also change the reasoning trajectory used to justify the response. Modern LLMs personalize interactions by storing user attributes, preferences, and prior context, then injecting this information into future prompts. We study whether such memory reshapes reasoning on open-ended questions where no single ground-truth answer exists. To quantify this effect, we introduce DRIFTLENS, a ground-truth-free framework that maps each expressed reasoning step to a value category and measures divergence between a question&#39;s no-memory trajectory and its trajectory under injected user-attribute memory.
