## English Summary

HN discussion (943 points, submitted 2026-10-18) of the OpenCode security incident announced on X. The breach hit OpenCode Console — a hosted, OpenRouter-like inference gateway where users store bring-your-own API keys — not the open-source OpenCode CLI/agent. Commenters clarify only Console users were affected, OpenCode emailed affected users, and some report drained Anthropic/OpenAI credits. OpenCode attributed the incident to a large-scale distillation attack; the thread debates that claim heavily, notes no detailed RCA exists yet, and asks for an open dataset of attacker queries for independent verification. The discussion also surfaces product-naming confusion (Console vs CLI vs Zen vs Go vs Black) and mitigation ideas such as an invalidate_api_key endpoint and GitHub secret-scanning auto-revocation.
