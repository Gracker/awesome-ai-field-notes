## 中文摘要

## English Abstract

Linear attention and state-space models compress the prefix into a fixed-size recurrent state and pay for O(1) memory with lossy exact recall: when many key-value associations compete, earlier facts are overwritten and needle recall degrades. Inspired by Complementary Learning Systems, the authors add a hippocampal complement called HOLA: the usual delta-rule state behaves as compressive memory and a bounded exact KV cache acts as a semiparametric test-time memory. Writes to the cache are gated by the prediction residual beta*||e|| without a learned eviction module, and a decoupled RMSNorm-gamma read turns exact KV pairs into sharp retrieval. At 340M parameters trained on 15B SlimPajama tokens, HOLA lowers Wikitext perplexity from 27.32 to 22.92 (-16.1%), below full-attention Transformer++ (26.88), and improves LAMBADA perplexity from 30.95 to 30.26....
