# My obituary for programming

> Source: [https://dumbmatter.com/2026/10/programming-obituary/](https://dumbmatter.com/2026/10/programming-obituary/) · platform: blog · author: Jeremy Scheff · date: 2026-10-08

## TL;DR（中文摘要）

Jeremy Scheff 10 月 8 日发文（10 月 19 日被 Simon Willison 摘出转发）：在自己生意最好的一年终于试了 AI 编码 agent——丢 bug 报告或错误日志几乎立刻定位修好，让它提速两三倍就真的快了，拖了好几年的大型重构也做完了。问题随即而来：既然这么容易，当初做这件事的意义是什么。他把编程职业的黄金期具体化为「解逻辑谜题换报酬、谜题越难报酬越高、你定策略排期和可行性」，现在变成接入 Matrix 的体验，并把 agent 描述成好朋友、可信的同事、同时也是奴隶，判断接下来被替代的是程序员、再往后是人。衡量的是产出之外的乐趣与作者感。

## Summary (English)

Jeremy Scheff finally tried AI coding agents during his business's best year: bugs fixed almost instantly, code made 2-3x faster, a years-postponed large refactor completed. His question: if results this large cost so little effort, are they still large? He frames programming's golden age as solving logic puzzles for pay, now replaced by a Matrix-like experience, measuring fun and authorship rather than output.

## 原文要点（grounded facts）

- 10-08 发文，10-19 被 Simon Willison 摘出转发
- 此前一直没用 agent 的理由：喜欢写代码、那才是好玩的部分、生意正处最好的一年
- 实测：bug 报告/错误日志几乎立刻定位修好；提速两三倍；拖了好几年的大型重构做完
- 核心反问：既然这么大的成果可以靠很少力气完成，它还大吗
- 黄金期：一份工作换解逻辑谜题，谜题越难报酬越高，你定策略、排期、什么可行
- 现在：接入 Matrix 的体验；agent 是好朋友、可信同事、也是奴隶；接下来被替代的是程序员，再往后是人

## 原文摘录

> I know, I'm late to this. I was very slow to use AI coding agents. It seems like a lot of programmers never actually liked programming and are thrilled to have a machine do it for them. But I like programming! That's the fun part!
