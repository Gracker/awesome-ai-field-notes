# Charts built for Chat: dbt Charts open-sources a declarative dashboard language for agent-built dashboards

> Source: https://dbtcharts.com/blog/charts-built-for-chat/
> Author: Dave Fowler
> Published: 2026-09-14
> Platform: blog

## 中文概要

dbt Labs 开源 "dbt Charts"——一种面向"智能体通过聊天生成仪表盘"场景的声明式仪表盘语言。当前痛点：智能体生成的仪表盘膨胀成 HTML/CSS/JS、多套图表库外加 React 或 Streamlit 应用，难以审计且每次迭代消耗大量 token；BI 工具则把 Copilot 嫁接到 UI 优先的应用上，受 UI 暴露面限制。dbt Charts 给出第三条路：单一声明式规格，对智能体与人同时友好且可治理。

## English Summary

dbt Labs open-sources 'dbt Charts', a declarative language for dashboards targeted at the world where agents build dashboards by chat. Today: agent-generated dashboards explode into HTML/CSS/JS plus multiple chart libraries and a React or Streamlit app — slow to audit and expensive per iteration. BI tools bolted copilots onto UI-first apps, narrow but governed. dbt Charts offers a third option: a single declarative spec that stays auditable and is friendly to both agents and humans.
