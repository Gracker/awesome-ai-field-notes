## 中文摘要

Skills 正在成为 LLM Agent 的可复用操作层，封装 SOP、领域规则、工具工作流与验证例程。现实 skill 库存在大量重叠 skill，导致 Agent 难以稳定选择。仅看最终验证是否通过太粗：Agent 可能靠 trial-and-error 撞对，也可能完全跳过必选 skill。SkillCoach 引入 self-evolving rubrics：rubric 本身随 Agent 表现迭代，把「该用 skill 而未用 / 用了 distractor / 顺序错乱」等模式编码进评分，既能更细粒度评估 skill-use 能力，也能用作训练信号增强 Agent 的 skill 选择与调用顺序。

## English Abstract

Skills are becoming a reusable operational layer for LLM agents, encoding SOPs, domain rules, tool workflows, scripts, and validation routines. In realistic skill repositories, overlapping skills make reliable skill-use difficult. Final verifier success is too coarse for both evaluation and training, since an agent may pass through trial and error while selecting distractor skills, skipping required steps, composing workflows incorrectly or omitting final checks. We introduce SkillCoach, a self-evolving rubric framework for evaluating and enhancing agentic skill-use. SkillCoach derives skill-grounded process rubrics from real rollouts and evaluates trajectories along four dimensions: skill selection, skill following, skill composition, and skill-grounded reflection....
