## English

## Claude Code System Prompts — Fully Exposed

### What Is This?

Piebald AI has released a complete repository containing **all of Claude Code's system prompts**, extracted directly from the npm package. This includes:

- **27 builtin tool descriptions** (Write, Bash, TodoWrite, etc.)
- **Sub-agent prompts** for Explore, Plan, Task, and other built-in agents
- **Utility prompts** for CLAUDE.md generation, conversation compaction, session title generation, and more
- **~40 system reminders** added as of January 2026

### Key Highlights

**1. Claude Code Has 110+ Separate System Prompt Strings**

Claude Code doesn't use a single monolithic system prompt. Instead, it conditionally assembles different portions based on environment, configuration, and context. This means the actual token count varies per session — but typically within ±20 tokens of the stated counts.

**2. Sub-agents Have Their Own Prompts**

- **Explore agent** (575 tokens): For exploring codebases
- **Plan mode** (715 tokens): Enhanced planning subagent
- **Agent creation architect** (1,110 tokens): For creating custom AI agents
- **CLAUDE.md creation** (384 tokens): Analyzes codebases to generate documentation
- **/code-review** variants (152–315 tokens each): Multiple effort levels for code review

**3. Slash Command Prompts**

Claude Code's slash commands (`/batch`, `/code-review`, `/review-pr`, `/schedule`, `/security-review`, etc.) each have detailed, purpose-built system prompts.

**4. Security Monitor**

Two-part security monitor (3,370 + 4,227 tokens) that evaluates autonomous agent actions against block/allow rules to prevent prompt injection and scope creep.

**5. API Reference Templates**

Claude Code embeds reference documentation for all major SDKs:
- Python, TypeScript, Java, C#, Go, PHP, Ruby, cURL
- Anthropic CLI, Files API, GitHub Actions workflow
- Claude Platform on AWS reference

### How They Extract It

The team reverse-engineers Claude Code's compiled JavaScript to extract exact prompt strings. Since these are pulled directly from the source, they're guaranteed to match what Claude Code actually uses.

### Want to Modify It?

Use **tweakcc** (by the same team) to customize individual prompt pieces as markdown files and patch your Claude Code installation. It also provides diffing and conflict management.

## 中文

## Claude Code 系统提示词完全公开：27 个工具描述 + 子 agent 提示词全泄露

### 这是什么？

Piebald AI 发布了一个完整仓库，包含了 **Claude Code 的所有系统提示词**，直接从 npm 包中提取。包括：

- **27 个内置工具描述**（Write、Bash、TodoWrite 等）
- **子 agent 提示词**（Explore、Plan、Task 等内置 agent）
- **工具提示词**：CLAUDE.md 生成、对话压缩、会话标题生成等
- **约 40 个系统提醒**（2026 年 1 月新增）

### 核心亮点

**1. Claude Code 有 110+ 个独立的系统提示字符串**

Claude Code 并非使用单一的整体系统提示词，而是根据环境、配置和上下文动态组合不同部分。这意味着每个会话的实际 token 数量会有差异——但通常在标注值的 ±20 tokens 范围内。

**2. 子 agent 各有专属提示词**

- **Explore agent**（575 tokens）：用于探索代码库
- **Plan mode**（715 tokens）：增强型规划子 agent
- **Agent creation architect**（1,110 tokens）：用于创建自定义 AI agent
- **CLAUDE.md creation**（384 tokens）：分析代码库并生成文档
- **/code-review 变体**（152–315 tokens 各版本）：多种不同力度的代码审查

**3. 斜杠命令提示词**

Claude Code 的斜杠命令（`/batch`、`/code-review`、`/review-pr`、`/schedule`、`/security-review` 等）每个都有专门构建的系统提示词。

**4. 安全监控**

两部分组成的安全监控（3,370 + 4,227 tokens），用于评估自主 agent 操作，防止提示词注入和范围蔓延。

**5. API 参考模板**

Claude Code 内嵌了所有主流 SDK 的参考文档：
- Python、TypeScript、Java、C#、Go、PHP、Ruby、cURL
- Anthropic CLI、Files API、GitHub Actions 工作流
- AWS 上的 Claude Platform 参考

### 提取原理

团队通过逆向工程 Claude Code 的编译后 JavaScript 来提取精确的提示词字符串。由于直接拉取自源代码，这些内容保证与 Claude Code 实际使用的完全一致。

### 想自定义提示词？

使用 **tweakcc**（同一团队开发）将各个提示词片段作为 markdown 文件进行自定义，然后补丁到 Claude Code 安装中。它还提供差异对比和冲突管理功能。
