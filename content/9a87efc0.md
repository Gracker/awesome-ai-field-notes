## 中文导读

callstack 开源的 agent-device 给 AI 编码 agent 加真机手：一个 CLI、MCP server 和带类型的 Node.js API，用来操控真机或模拟器上的手机、Web、TV 与桌面应用，本地或云端均可。定位是让 agent 不停在 shell 层，而是能驱动设备 UI 完成自动化，支持多 agent 并行占用设备；MIT 授权，TypeScript 实现，约 5.4k stars，仓库仍在活跃推送。对 Android/iOS 性能与 UI 自动化交叉场景，可作为 mobile-mcp 与自建 adb bridge 之外的对照方案。

## 为什么值得关注

给 agent 真机的工程化入口，与 mobile-mcp/自建 adb bridge 的取舍值得实测。
