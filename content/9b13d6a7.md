## English Source (Model Card)

**DeepSeek-V4.1-Flash-1017** is a minor update to **DeepSeek-V4.1-Flash**, delivering substantial improvements across reasoning, coding, agentic tasks, and visual benchmarks. Alongside these gains, the model reduces task execution time and output length, enabling users to complete tasks faster and at lower cost and advancing the performance-cost Pareto frontier across multiple agent harnesses.

Selected benchmarks (DS-V4.1-Flash-1017 vs DS-V4.1-Flash): HLE w/o tools 42.6 vs 36.8; Terminal-Bench 4.0 42.3 vs 31.2; DeepSWE v1.1 77.0 vs 74.2; ProgramBench 29.1 vs 20.3; NL2Repo-Bench 68.2 vs 65.4; Automation-Bench v1.0.6 60.5 vs 54.8; Agents' Last Exam 35.4 vs 31.8; Apex Bench v1.1 72.1 vs 64.6; Chartography (w/tools) 83.0 vs 78.9; BabyVision (w/tools) 92.5 vs 89.6; ZeroBench-main (w/tools) 51.0 vs 49.0. Terminal-Bench 4.0 uses the Claude Code harness; DeepSWE v1.1 uses the Mini-SWE-V2 harness.

This release does not include a Jinja-format chat template. The `encoding` folder contains a self-contained Python reference implementation (`encoding.py`) with test cases for multi-turn conversations, tool calling, thinking mode, numeric reasoning effort, mid-conversation system messages, and interleaved image content. For production use, DeepSeek additionally releases deepseek-recipe, a set of Rust libraries with Python bindings that converts Messages, Chat Completions, and Responses API requests into the Conversation format, encodes them into DeepSeek V4 and V4.1 prompts or token IDs, and parses model output back into complete or streamed responses.
