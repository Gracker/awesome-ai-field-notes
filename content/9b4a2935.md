ChatGPT's plugin directory now lets one conversation connect personal / work / side-project accounts simultaneously, with existing plugins auto-adapted so no developer changes are required. As an enhancement hook, MCP servers can expose a profile tool so ChatGPT labels each account and avoids cross-context bleed between personal and work items. Same boundary shows up on two sides: enterprise plug-in tenant isolation and local agent tooling's 'current account' tagging. Try: connect two test accounts in the ChatGPT plug-in directory and add a profile tool to your MCP server.
