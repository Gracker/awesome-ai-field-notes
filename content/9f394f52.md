## 为什么值得关注

vibe-coding 平台把「无需技术背景」作为卖点，但 Lovable 条款把应用与数据安全责任留给客户；这份 15.9 万项目规模的扫描把这个落差变成了具体数字：首屏暴露数据库记录的站点中 30% 能被同一 API key 取回含邮箱记录，护照号、合同、内部通讯等高敏数据都有实例。对用 AI 平台快速搭应用并接数据库的团队，这是 RLS/访问控制必须自查的直接清单；对平台方，同构集成模式让一处误配可被批量利用，是规模化安全设计的警示。

## English Abstract

Security analysis of 159,041 Lovable projects by Crissy Field GmbH, in collaboration with Handelsblatt (reporting by Lina Knees, November 2, 2026). The study examined whether sensitive data in AI-built applications is accessible without logging in, focusing on Supabase as the most widely used database service among Lovable projects. Researchers separately inspected data exposed at first page load and additional content retrievable via further read-only requests with the same API key, and found many clear examples of sensitive data left unprotected.

## English Excerpts

> Using datasets from the open web archive Common Crawl, we identified and analyzed 159,041 Lovable projects from December 2025 to September 2026. Of these, 34,545 used Supabase. 24,664 websites sent database records from Supabase as soon as they loaded, without requiring a login or any other interaction. That alone is not a security issue: the data may be intended for public display. But by making additional read-only requests, we were able to retrieve more database content. We found records containing email addresses in 10,560 tables across 7,403 of the 24,664 websites (30%).

> In a particularly serious case, a service provider exposed more than 1,000 records containing identity document details, including passport numbers, expiration dates, and nationalities. ... In one case, 280,000 emails sent to a provider's customers were accessible. ... The 30% figure should therefore not be read as a confirmed data leak rate. It applies only to the 24,664 websites we examined more closely. Our sample, drawn from Common Crawl, is also not representative of all Lovable applications.

## English Summary

A security analysis of 159,041 Lovable projects by Crissy Field GmbH, in collaboration with Handelsblatt (reporting by Lina Knees, November 2, 2026), examined whether sensitive data in AI-built applications is accessible without logging in, focusing on Supabase as the most widely used database service among Lovable projects. Researchers separately inspected data exposed at first page load and additional content reachable via further read-only requests with the same API key, and found many clear examples of unprotected personal and confidential data. The report contrasts Lovable's no-code-required marketing with Terms & Conditions that place responsibility for application security and data handling on customers themselves.
