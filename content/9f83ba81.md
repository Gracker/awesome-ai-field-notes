## 中文导读

Clover 是 35B 总参、3B 激活的 MoE 扩散语言模型，支持 thinking-mode，把 Gated Delta Networks 适配到 block diffusion：历史上下文循环记忆与当前块内双向 attention 在同一 softmax 里竞争，另有可学习的块大小校准与零初始化右上下文卷积分支。代理指标全面领先：七个评测 agent 指标领先，SWE-bench Verified 73.6、Terminal-Bench 2.1 51.7，单卡 GB300 BF16 batch 1 标称生成 680 tokens/s。决策模型变体一次去噪并行回答相关问题，内部 500 组上单题准确率从 90.37% 提到 93.88%，全对组从 65.4% 提到 77.0%。评测围绕模型质量、草稿与验证成本、受限内存部署三个维度组织。

## 为什么值得关注

扩散语言模型此前多在小模型上验证，Clover 把它推到 35B MoE 规模并用 SWE-bench/Terminal-Bench 这类 agent 基准给出可对照数字，还标称了单卡 680 tokens/s 的生成速度。如果数字成立，block diffusion + Gated Delta Networks 是并行生成路线在 coding agent 场景的一次正经落地，值得与自回归 MoE 基线对照。

## English Summary

Clover-35B-A3B-Preview is a mixture-of-experts diffusion language model with 35B total and 3B activated parameters, supporting thinking-mode generation. It adapts Gated Delta Networks to block diffusion by combining recurrent memory of previously generated context with bidirectional softmax attention inside the current block: historical memory readout competes with current-block tokens in a shared softmax, with learnable block-size calibration and a separate zero-initialized right-context convolution branch. Clover leads all seven evaluated agent metrics, including 73.6 on SWE-bench Verified and 51.7 on Terminal-Bench 2.1, and reports 680 tokens/s generation on a single NVIDIA GB300 at BF16 precision with batch size one. A decision-model variant answers related questions in one denoising pass: on an internal 500-group set, joint prediction raises per-question accuracy from 90.37% to 93.88% and all-correct group accuracy from 65.4% to 77.0%. Evaluation is organized around model quality, drafting and verification costs, and deployment under constrained memory.
