## English Summary

LiteLLM 1.107.0 on PyPI shipped a credential stealer and RCE backdoor in all seven wheels (Linux, macOS, Windows). A single injected data = cook line in the sdist's maturin build section - present in no public commit - copies a cook/ folder into site-packages: cook.pth loads cook.py, which collects SSH keys, cloud credentials, CI/CD secrets, AI tool tokens, browser passwords and the LLM provider keys in a LiteLLM proxy database and exfiltrates them to a lookalike litellm.dev domain; sitecustomize.py starts an hourly daemon that reads a server address from a GitHub file, re-runs the stealer and executes downloaded code. Both run whenever any Python process starts, even without importing litellm....
