## English Summary

OpenAI's autonomous security pipeline report: a prototype audited the Linux kernel in a controlled research environment. Scout scanned 5,034 audit targets (~2.8M LOC, ~7% of the kernel) for $3,426; Analyst produced 2,308 deduplicated candidate findings for $316,549; dynamic validation reproduced 1,724 (74.7%); exploit development yielded 948 distinct local privilege escalation (LPE) exploits at an end-to-end API cost of $1,213,430 - about $1,279 per unique LPE. A late-July run on GPT-5.6 Sol produced 166 LPEs for $513,690. Early runs had 20 of 200 'root' results exploiting different 0-days than assigned; independent verification was added; 61 LPEs are already fixed upstream. OpenAI's judgment: on systems without the latest patches, an unprivileged local account should be treated as functionally equivalent to root, and automated patch generation becomes necessary to keep pace.

## 原文摘录（openai.com, 2026-11-04）

Security research that once required a separate, sustained investigation for each finding can increasingly be run as a systematic process.

Vulnerability discovery is becoming easier to scale, but prioritization and validation remain operational bottlenecks. We built a prototype to look for security flaws in the Linux kernel inside a controlled research environment. Our prototype identified and analyzed 2,308 candidate Linux kernel findings, dynamically reproduced 1,724 vulnerabilities, and produced 948 local privilege escalation (LPE) exploits that could allow an unprivileged local user to gain root access.

We used this evidence to prioritize vulnerabilities for reporting and developed candidate patches for maintainer review. Following guidance from the Linux kernel community, we began with critical vulnerabilities and are working with Patch the Planet partners on further reports and patches.

In June, as part of our Patch the Planet initiative, we shared that GPT-5.5 Cyber had identified Linux kernel vulnerabilities and developed 24 local privilege escalation exploits to validate and report them. We expanded that work into a pipeline, powered by an upcoming cyber model, covering vulnerability discovery, dynamic validation, exploitability assessment and patch generation.
