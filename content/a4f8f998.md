## English Summary

Anthropic's September 2025 engineering guide: when agents get stuck, the tool interface is more often the bottleneck than the model. Do not wrap existing APIs verbatim - list_contacts dumping a full contact list forces the agent to filter in-context; consolidate frequent flows into fewer composite tools (schedule_event checks availability and books; search_logs returns matching lines with limited context). Descriptions are prompts: after launching web search, Claude kept appending '2025' to queries until the description was fixed; precise refinements to tool descriptions let Sonnet 3.5 reach then-SOTA on SWE-bench Verified. Return actionable error messages, not bare codes - agents follow the error text. Size matters: the same Slack thread is 206 tokens detailed vs 72 concise; Claude Code caps tool responses at 25,000 tokens; descriptive fields beat uuid-style identifiers.
