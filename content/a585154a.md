## 中文导读

OpenAI Decisions API 公测（预计数周内 GA）：专用 `POST /v1/decisions` 端点，目前唯一模型 gpt-6-luna，评估文本、图像或两者，返回带类型的判定答案，比 Responses API 快约 10 倍。请求三段：`model`、`input`（共享证据：文本串或含图文的 user messages）、`questions`（每题的类型、指令、允许的选项或评分等级）；响应的 `answers` 数组按题目 `name` 回显。三种题型：`predicate` 返回条件为真的概率（0–1），如检测图片可见损伤、判断段落相关性；`choice` 从无序固定选项中选一个，如部门、内容分类；`score` 对有序等级评分，取等级索引的概率加权平均，可以落在两档之间，如问题严重度。`choice` 与 `score` 都返回离散选项上的概率分布。定位是内容分类、请求路由、优先级排序这类应用内判定环节；需要生成自定义 JSON 结构仍走 Structured Outputs + Responses API，工具调用走 function calling。SDK 最低版本：Python 3.26.0、JavaScript 7.30.0、Go 3.73.0、Ruby 0.101.0、Java 4.78.0；可在 Playground 先行试验。

## 为什么值得关注

## English Summary

The Decisions API (public beta, GA expected in weeks) evaluates text, images, or both via a dedicated `POST /v1/decisions` endpoint on `gpt-6-luna`, returning typed answers about 10x faster than the Responses API. Question types: `predicate` (probability a condition is true, 0-1), `choice` (one of unordered supplied options), and `score` (probability-weighted average over ordered level indices, able to fall between levels). Built for classification, request routing, and prioritization; custom JSON generation stays with Structured Outputs, tool requests with function calling.
