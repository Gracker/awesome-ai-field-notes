# Codex 0.157.1: Windows daemon 后台稳定性补丁

> 作者: openai (github-actions)
> 发布时间: 2026-09-26

## 摘要（AAIF 提取）

OpenAI Codex CLI 9 月 26 日发布 0.157.1 补丁版：0.157.0 到 0.157.1 仅 5 个 commits、10 个文件变更，是小步维护版。可考的变更集中在 Windows 本地 daemon/后台运行稳定性：其一，新增 Windows 回归测试，验证"被捕获的 launcher 输出在 detached 子进程仍存活时正确关闭，且子进程继续向配置的日志文件写入"——对应 Windows 上后台启动 Codex 时父进程句柄不释放、弹窗/挂起的日用摩擦；其二，给 MCP 启动宽限相关测试在慢 runner 上更多时间，同时保持 pending server 的启动超时大于 turn 超时，避免测试性超时误报。release 页本身未生成 highlights（PR 索引为空、tag compare 404），说明这是无功能面的修复版，与 0.157.0 当日发布 Sol/Luna 模型支持的功能版分开。对 Windows 用户的意义：升级 0.157.1 主要为验证 MCP server 启动与后台任务日志行为是否稳定，而非新功能。

## 为什么值得关注

Codex 在 Windows 的本地 daemon 路径（弹窗、job 对象、stdio 句柄）是 agent CLI 日用摩擦最集中的地方，0.157.1 的测试型修复直指这条路径，可当作 Windows 后台化稳定性的观察样本。

## 关键事实

- 5 commits / 10 files，纯维护版（release highlights 为空）
- Windows 回归测试：detached 子进程存活时 launcher 输出流正确关闭 + 日志续写
- MCP startup grace：慢 runner 放宽测试时限，pending server 启动超时 > turn 超时
