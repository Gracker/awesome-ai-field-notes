## 摘要 (Summary)

自主编码智能体在自动化测试生成上进展显著，但受困于'懒惰生成'现象：智能体会过早终止任务刻意回避复杂程序逻辑，导致代码覆盖率不足目前缓解此问题需要持续的人在环监督，重依赖人的直觉抵消了自动化收益论文提出 SCATE，一个面向编码智能体的自适应自动化监督框架，用上下文赌博机（contextual bandit）替代人在环监督，依据当前覆盖率与被测类特征选择最有效的下一步测试动作在覆盖率和成本两个维度上，SCATE 都显著优于纯人在环与无监督基线，为编码智能体的可扩展测试生成提供了实用方案

## English Abstract / Excerpt

While autonomous coding agents have significantly advanced automated test generation, they remain fundamentally limited by lazy generation, a phenomenon where agents prematurely terminate tasks and systematically avoid complex programmatic logic, resulting in inadequate code coverage. Currently, mitigating this premature termination requires continuous human-in-the-loop supervision. This heavy reliance on human intuition creates a bottleneck that negates the efficiency gains of automated generation. We propose SCATE, a framework for adaptive, automated supervision of coding agents that replaces human intervention during test generation. By formulating supervision as a contextual bandit problem, SCATE learns to select the most promising testing actions based on the current coverage and class under test....
