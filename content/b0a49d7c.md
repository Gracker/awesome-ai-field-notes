## 中文导读

现有 Tool-Integrated Reasoning（TIR）基准大多在理想 happy path 上评测，真实部署里工具失败才是常态。ToolMaze 把失败放进多工具依赖链（DAG 结构）里度量：一个维度是拓扑复杂度，另一个维度是 2×2 扰动分类——显式/隐式 × 瞬时/永久。显式失败（404、429、超时）至少会宣告自己的存在；隐式失败返回值格式完全合法、内容却是错的（如库存延迟更新返回负数），专门用来把“系统性重规划”与“盲试错”分开。

主要发现：扰动几乎压低所有模型；隐式语义失败最尖锐——模型系统性过度信任“能解析、字段全”的毒数据，Perturbation Recovery Rate 平均暴跌约 37%，扰动顺着调用链往下传污染后续推理；复杂拓扑把 agent 困在无效试错循环。最关键：容错能力随模型规模改善的速度比基础任务执行慢 3.66 倍——把 agent 从中档模型换到旗舰，任务成功率会涨，恢复能力基本原地踏步。动态重规划是规模与提示都没有解决的独立瓶颈。数据与代码开源。

## English Abstract

Existing benchmarks evaluate Tool-Integrated Reasoning (TIR) in LLMs on idealized 'happy paths', largely overlooking real-world tool failures. We introduce ToolMaze, a benchmark for dynamic path discovery and error recovery in TIR agents. To separate systematic replanning from blind trial-and-error, ToolMaze adopts a two-dimensional design: DAG-based topological complexity and a 2 x 2 taxonomy of tool perturbations (explicit/implicit, transient/permanent). Evaluations show that perturbations degrade performance across nearly all models, with the sharpest drops under implicit semantic failures. Driven by systemic over-trust in corrupted outputs, Perturbation Recovery Rate (PRR) plummets by around 37% in these scenarios, while complex topologies trap agents in futile trial-and-error loops. Crucially, agentic fault-tolerance improves with model scale 3.66x slower than basic task execution, highlighting dynamic replanning as a distinct bottleneck unaddressed by model scaling or prompting. Data and code are available at https://github.com/Zhudongsheng75/ToolMaze.
