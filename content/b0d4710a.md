## 中文导读

Andrew Nesbitt 记录为 CodeCommons plenary 演讲做的 SWH 归档与包标识打通工作。Software Heritage 自 2016 年由 Inria 启动，把 GitHub/GitLab/Bitbucket、小型 forge、包注册表与发行版源统一存进去重 Merkle DAG，现有约 300 亿源文件、230 亿目录、60 亿 commit、4.45 亿 origins；SWHID v1.2 上一年已发为 ISO/IEC 18670，是 intrinsic software identifier 第一个 ISO 标准，hash 直接复用 git 自有 hash，本地任何 checkout 都自带 SWHID。他梳理 SWHID（intrinsic、无注册机构）与 purl（可读、依赖 registry）在 Zooko 三角上的互补，并发布 swh-git remote helper（swh:: transport 克隆归档）、swhid gem、swhid-go（含 WASM 版）等工具；coverage 检查显示 critical 集约 71.3% 的 default-branch commit 已入档、89.9% 匹配 release tag。

## English Summary

Andrew Nesbitt documents tooling connecting ecosystem package identities to the Software Heritage archive: SWH's deduplicated Merkle DAG holds ~30B source files, 23B directories, 6B commits from 445M origins; SWHID v1.2 is now ISO/IEC 18670, hashes reuse git's own hashing, and SWHID (intrinsic, registry-free) complements purl (human-readable, registry-dependent) across Zooko's triangle. He ships swh-git (a git remote helper cloning via the swh:: transport against the Vault), swhid gem, swhid-go with a WASM build, and a coverage check finding 71.3% of critical packages' default-branch commits and 89.9% of release tags already archived.
