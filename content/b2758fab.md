## 中文翻译

Gemini CLI于2026年4月23日发布v0.39.0版本，带来多项重大改进。新版本引入了`/memory inbox`命令用于在代理会话期间审查和修补提取的技能；改进的透明度设计要求用户确认技能激活并允许检查生成计划；架构增强包括解耦的ContextManager架构，改进状态管理和会话弹性。这些更新使Gemini CLI能够更有效地管理复杂的开发任务，支持vim、git rebase -i等交互式命令的上下文内运行。

## English Original

Gemini CLI released v0.39.0 on April 23, 2026, featuring major improvements including a new `/memory inbox` command for reviewing and patching extracted skills during agent sessions; enhanced transparency requiring user confirmation for skill activation and plan inspection; architectural enhancements with decoupled ContextManager for improved state management and session resilience. Updates enable complex in-context command execution like vim and git rebase -i.
