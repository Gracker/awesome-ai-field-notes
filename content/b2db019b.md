## 中文导读

Agent skill 用可安装的指令和代码扩展 AI 助手，能碰用户的文件、账号和数据；即使只做分内事，也可能推断敏感属性、留下不必要的记录、或把数据送给预期外的接收方。SkillPrivus 是安装前静态审计框架：不执行 skill，直接从代码和自然语言指令里提取数据操作，锚定到源码证据，再用 Contextual Integrity 判断正当性。对公共市场 726 个真实 skill（563 个处理个人数据）的审计里，307 个（54.5%）被标出至少一处潜在违规，判断与三名盲评人类标注在可判定动作上一致率 83.2%。被标行为包括敏感推断、超出声明任务的信息使用、向意外接收方披露——隐私伤害可以来自普通功能，不必等到恶意 skill 出现。

## 为什么值得关注

Agent skills 生态正在爆发，而 skill 市场没有杀毒扫描这一层。SkillPrivus 的关键贡献是把"合规但越界"的隐私使用伤害形式化成静态可审计的数据操作，54.5% 的命中率和 83.2% 的人类一致率说明这不是危言耸听。对运营 skill 市场、审核第三方 skill 的团队，Contextual Integrity 锚定源码证据的审计思路可以直接落地。

## English Summary

Agent skills extend AI assistants through installable instructions and code that can access users' files, accounts, and data. Even when performing their advertised tasks, skills may infer sensitive attributes, retain unnecessary information, or disclose data to unexpected recipients. SkillPrivus is a static audit framework that analyzes skills before installation without executing them: it extracts data operations from code and natural-language instructions, grounds them in source evidence, and adapts Contextual Integrity to assess their appropriateness. Applied to 726 real skills from public marketplaces, 563 of which handle personal data, SkillPrivus flags at least one potential violation in 307 skills (54.5%), with judgments agreeing with three blind human annotators on 83.2% of resolvable moves. Flagged behaviors include sensitive inferences, information use beyond the stated task, and disclosures to unexpected recipients - privacy harms can arise from ordinary skill functionality, not only malicious ones.
