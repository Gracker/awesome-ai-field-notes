# acpx 0.6.0：Claude/Codex 智能体控制工具再更新
# acpx 0.6.0: Claude/Codex Agent Control Tool Update

## 中文原文 / Chinese Original

acpx（OpenClaw 出品的 Agent 控制工具）发布 0.6.0 版本，带来多项实用更新。

### 核心更新

1. **Claude system prompt 直接控制** — 可直接通过 acpx 配置 Claude 的 system prompt，无需手动粘贴
2. **Session pruning（自动削减上下文）** — 当上下文过长时自动压缩，避免溢出同时保留关键信息
3. **Embeddable turn handles** — 可嵌入到自定义 UI，方便在第三方应用中集成 Agent 能力
4. **--no-terminal 模式** — 无需终端即可运行，方便 CI/CD 集成
5. **Persistent session 修复** — session 持久化更稳定
6. **WSL cwd 路径转换** — Windows WSL 环境下路径处理更准确
7. **Queue 稳定性提升** — 任务队列更稳定
8. **更清晰的报错提示** — 错误信息更易读，调试更方便

### 最值得关注的功能

对于日常使用 Claude/Codex 进行自动化任务的同学：

- **Session pruning**：自动管理上下文长度，再也不用担心 token 溢出
- **System prompt 控制**：更精细地约束模型行为，实现更精准的 Agent 控制

### 开源信息

已在 GitHub 开源，有需求的开发者值得关注。

## English Translation

acpx (OpenClaw's agent control tool) releases 0.6.0 with multiple practical updates.

### Key Updates

1. **Direct Claude system prompt control** — configure Claude's system prompt via acpx directly, no manual pasting needed
2. **Session pruning (automatic context trimming)** — auto-compresses when context gets too long, preventing overflow while preserving key information
3. **Embeddable turn handles** — embed into custom UI, easy integration of agent capabilities into third-party apps
4. **--no-terminal mode** — run without terminal, convenient for CI/CD integration
5. **Persistent session fixes** — more stable session persistence
6. **WSL cwd path conversion** — more accurate path handling in Windows WSL environments
7. **Queue stability improvements** — more stable task queue
8. **Clearer error messages** — errors more readable, debugging easier

### Most Notable Features

For daily users of Claude/Codex for automation tasks:

- **Session pruning**: automatically manage context length, no more token overflow worries
- **System prompt control**: more precise model behavior constraints for better Agent control

Available on GitHub. Developers with needs in this area should take a look.
