# acpx 0.6.0：Claude/Codex 智能体控制工具再更新

## 中文版

## 概述

acpx 是一个无头（headless）CLI 客户端，用于通过 ACP（Agent Client Protocol）协议与 AI 编程智能体通信。相比传统的 PTY 会话刮取方式，acpx 提供了结构化的消息接口，让编排器（orchestrator）和智能体之间的对话更可靠、更可自动化。

v0.6.0 是 acpx 的重要里程碑，引入了多项关键新特性，包括 `--system-prompt` 全局标志、session 裁剪功能、flows 早期支持等。

---

## 核心特性

### 持久化会话（Persistent Sessions）
多轮对话在多次调用之间保持活跃，按代码库作用域隔离。支持命名会话（如 `-s backend`、`-s frontend`）实现并行工作流。

### 协作取消（Cooperative Cancel）
`cancel` 命令通过队列 IPC 发送 ACP `session/cancel`，无需拆除会话状态即可中止正在运行的提示词。

### 软关闭生命周期（Soft-close Lifecycle）
关闭会话时不删除磁盘上的历史记录，便于审计和复用。

### Prompt 队列（Prompt Queueing）
当一个提示词正在运行时，可继续提交新的提示词，它们会按顺序执行。

### 静默取消（Graceful Cancel）
`Ctrl+C` 先发送 ACP `session/cancel`， fallback 才强制终止进程。

### 会话控制
`set-mode` 和 `set <key> <value>` 分别用于 `session/set_mode` 和 `session/set_config_option`。

### 崩溃重连（Crash Reconnect）
检测到智能体进程死亡后，可自动恢复或重新加载会话。

### Flows 实验性支持
`flow run <file>` 执行多提示词工作流，通过 TypeScript 模块定义复杂的多步骤自动化。

---

## v0.6.0 新特性详解

### `--system-prompt` 和 `--append-system-prompt`
新增全局标志，可 forwarded 到 ACP `_meta.systemPrompt`，用于在持久化 acpx 会话中替换或追加 Claude Code 的系统提示词。值保存在 `session_options.system_prompt` 中，ensure/reuse 流程会保留该覆盖。

### `sessions prune`
新增命令，支持 `--dry-run`、按时间过滤和 `--include-history`，可显式清理已关闭的会话记录和可选的事件流。

### Flow 早期支持
Flow 是 acpx 支持的多步骤 ACP 工作流模块系统：
- `acp` 节点保持模型在 ACP 中的工作
- `decision()` / `decisionEdge()` 提供受限的 LLM 分支决策
- `action` 步骤处理确定性操作（如 shell 命令、GitHub 调用）
- `compute` 步骤进行本地路由或数据整形
- `checkpoint` 步骤暂停等待外部事件

### Runtime API 稳定化
`acpx/runtime` API 已正式发布，支持将 ACPX 会话生命周期、turn 执行、状态控制等嵌入到其他应用。

## 安装与使用

```bash
# 全局安装
npm install -g acpx@latest

# 无需安装直接运行
npx acpx@latest codex "fix the tests"

# 创建新会话
acpx codex sessions new

# 发送提示词
acpx codex "find the flaky test and fix it"

# 查看会话状态
acpx codex status

# 导出/导入会话
acpx codex sessions export
acpx codex sessions import
```

- `acpx claude` → Claude Code

## 输出格式

```bash
# text（默认）：人类可读的流式输出
acpx codex 'review this PR'

# json：NDJSON 事件，用于自动化
acpx --format json codex exec 'review this PR' | jq -r 'select(.type=="tool_call") | [.status, .title] | @tsv'

# quiet：仅最终助手文本
acpx --format quiet codex 'final recommendation only'
```

## English Version

## Overview

acpx is a headless CLI client for the Agent Client Protocol (ACP), enabling AI agents and orchestrators to communicate with coding agents over a structured protocol instead of scraping PTY sessions.

One command surface for Pi, OpenClaw ACP, Codex, Claude, and other ACP-compatible agents. Built for agent-to-agent communication over the command line.

---

## Key Features

### Persistent Sessions
Multi-turn conversations that survive across invocations, scoped per repo. Named sessions (`-s backend`, `-s frontend`) enable parallel workstreams.

### Cooperative Cancel
`cancel` sends ACP `session/cancel` via queue IPC without tearing down session state.

### Soft-close Lifecycle
Close sessions without deleting history from disk.

### Prompt Queueing
Submit prompts while one is already running — they execute in order.

### Graceful Cancel
`Ctrl+C` sends ACP `session/cancel` before force-kill fallback.

### Session Controls
`set-mode` and `set <key> <value>` for `session/set_mode` and `session/set_config_option`.

### Crash Reconnect
Dead agent processes are detected and sessions are resumed or reloaded automatically.

### Flows (Experimental)
`flow run <file>` executes TypeScript workflow modules through the `acpx/flows` runtime.

---

## v0.6.0 Highlights

### `--system-prompt` / `--append-system-prompt`
New global flags that forward through ACP `_meta.systemPrompt` on `session/new`, letting callers replace or append to the Claude Code system prompt without dropping out of persistent acpx sessions.

### `sessions prune`
New command with `--dry-run`, age filters, and `--include-history` for cleaning up closed session records.

### Flow Runtime
Multi-step ACP workflows with `decision()`, `action`, `compute`, and `checkpoint` steps.

### Runtime Embedding API
Stable `acpx/runtime` API for embedding ACPX session lifecycle into other applications.
