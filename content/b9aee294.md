## English Summary

The October 2026 Amplifying index attributes 166.7M units of agent-attributed output on public GitHub: Claude Code alone accounts for 80% (132.9M) and the top three agents (Claude Code, Cursor, Replit Agent) for 93%. Weekly flow: Claude Code 1.3M (+143% over four weeks) vs Codex 236K (+7%). Sampling the 1,999 most recent public PRs, 32.5% carry a public agent signal (Claude Code 29.8%). Across 268 merged PRs in significant repos, 44% had a human reviewer, with sharp splits: Cursor and the Copilot agent route nearly everything past review, while Codex and Devin self-merge the majority. The author cautions that units differ per agent (commits vs PRs vs checkpoints), so read it as a concentration signal, not a like-for-like ranking. Data as of 2026-09-28.
