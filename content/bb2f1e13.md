## 中文导读

DeepSeek 开源发布 Harness 开发者预览版（含源码），核心理念是"一切皆插件"：模型、工具、技能、会话、沙箱、存储、循环、调度、UI——agent 的每一项能力都是可替换、可重组的插件。底层基于 Cordis 内核管理插件的挂载、卸载与依赖，开发者通过配置即可选择、替换或扩展任意能力而不改 Harness 源码。口号"Agent = Model + Harness"：模型是 agent 的灵魂，harness 让 agent 理解环境、使用工具并在真实环境中持续工作。另一设计支柱是"每次运行可追溯"：模型看到的一切（系统提示、推理、工具调用与结果、子 agent 调度、每次上下文注入）都记录在 append-only 会话日志中，Trajectory 视图可按来源检视，resume/fork/search/replay 都在同一事件流上操作。提供四种运行模式（Standard 全工具集 / Code 模式用模型生成的代码编排多轮工具调用 / Minimal 仅 shell + 文件编辑器用于最小环境基准测试 / Creator 模式支持运行时检视与插件实验）。快速启动：`npx @deepseek-ai/dsh web`；社区插件以 GitHub topic `dsh-plugin` 汇聚。

## 为什么值得关注

把 agent harness 的"能力可分解性"推到极致的开源参照实现：模型、工具、会话、沙箱、UI 全部插件化 + 全量 append-only 事件流，等于同时给出可定制架构与可审计运行时两层答案。对自建 harness 或研究 agent 可观测性的人，这是可以直接拆开看的工程样本。

## 架构要点

- **Cordis 内核**：管理插件挂载/卸载与依赖；agent 能力全部住在插件里，Cordis services 与 events 让插件协作。
- **一切皆插件**：模型、工具、技能、会话、沙箱、存储、循环、调度、UI；用配置组合能力，不改源码。
- **一切可追溯**：append-only session log 记录模型所见的一切（system prompt、reasoning、tool calls/results、subagent 调度、context 注入）；Trajectory 视图按来源检视；resume/fork/search/replay 基于同一事件流。
- **四种运行模式**：
  - Standard：完整工具集（文件编辑、shell、文件/网页搜索、skills、planning、goals、subagents、workflows）。
  - Code：Standard 能力 + Code Mode SDK，让模型用一个 TypeScript 程序编排多步操作。
  - Minimal：仅 bash + str_replace_editor 两工具，用于最小环境下的模型基准测试。
  - Creator：面向自定义 agent preset，支持运行时检视、内存中测试 Cordis 插件、组合出新模式。
