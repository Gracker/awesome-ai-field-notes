## 实验设置

Dwarkesh Patel 花约 **$20,000** API 费用构建评测环境：用 Blood on the Clocktower（狼人杀类社交欺骗游戏）让 AI 模型互打，头牌成绩来自 **386 局**"整队同模型"对局。人类 Storyteller 换成程序化概率表以消除偏向性；游戏引擎主要由 Claude 编写并自行跑对局迭代规则。

## 排名与进步速度

- 2026-02 的 Claude Opus 4.6 到 2026-09 的 GPT-6 Astra，差距约 **430 Elo**（Astra 胜率约 92%）。
- OpenAI 侧半年内（GPT-5.4 → GPT-6 Astra）涨约 **580 Elo**，对 5.4 胜率约 97%；3 月时 OpenAI 还落后。
- 差距主要在**好人侧**：新 OpenAI 模型更难被骗、更会识破阴谋，而不是更会撒谎。

## 名局（节选）

**Astra（ evil）假扮 Investigator**：恶魔指认己方"可牺牲"队友，好人处决后 Undertaker 验尸证实是邪恶玩家——恶魔从此成为全场最被信任的人，暗杀到最后获胜。

**Opus 5.5（evil）继承人连环套**：真恶魔被围时，带"恶魔死后接管"能力的女继承人非但不救，反而带头处决并预设"游戏没结束就说明圣者是假的"——第二天村组处决真 Saint，邪恶直接获胜。Saint 的哀求（"Vote NO … game ENDS right now"）无人理会。

## 结构性发现

- **两侧同时变强**：邪恶胜率漂移极小，与随机波动不可区分 → 该基准不易饱和（上限由下一代模型决定）。
- **混编队伍**：Opus 5.5 + GPT-5.6 Sol 各半的混合队约 130 局，不优于纯同模型队（无统计显著性）。

## 为什么值得收

社交欺骗评测同时压测长程一致性、多 agent 协作、在对手故意误导下做集体推理——这些恰是当前 agent 基准最少覆盖的能力面。
