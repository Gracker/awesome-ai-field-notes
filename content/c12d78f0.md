## 数据与识别

- Jellyfish 专有数据：445M work events（GitHub 写码、Jira issue、部分 Calendar）
- 720,542 workers / 655 firms / 2021-01 至 2026-08
- 企业层采用时点差异识别；Assistants ≈ IDE 局部补全（约 2022 末起），Agents ≈ 多步半自主（约 2024 末起）

## 关键数字（agents，采用后约 12 个月）

- commits +36.0%（显著）；PR opened +35.7%（显著）；PR merged +26.0% → 新增 PR 合并率约 62.7%（基线 86.1%）
- LOC +44.0%（边际不显著）
- 审查：提交→合并 +1.99 天（+56.1%，基线 3.56 天）；backlog 等待 +1.67 天；每 PR 评论数 +0.629（+38.6%）
- 最终产出代理：Jira issues +13.7%／epics +18.0%（边际不显著；可排除 issues >30.7%）
- AI code review：79.1% 企业用过；AI 只贡献约 23.3% 审查评论
- 生产函数：coding productivity +73.7%，review −7.0%；劳动再配置 coding −22.7%／review +43.4%
- 就业：无显著编制削减信号；长期模拟属条件预测而非已实现事实

## 中文摘要

哈佛 Chen & Stratton JMP 2026-11-07 修订版：Jellyfish 平台 445M 事件、720,542 工程师、655 家企业，按企业层采用时点识别效应。agents 采用约 12 个月后 commits +36.0%、PR opened +35.7% 显著，但 merged 仅 +26.0%，新增 PR 合并率 62.7% vs 基线 86.1%；提交到合并 +1.99 天（+56.1%）；Jira issues +13.7% 不显著。结构估计 coding 生产力 +73.7%、review −7.0%。较 10 月旧版系数已更新（LOC +44.0%）。
