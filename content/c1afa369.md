## English Summary

PHP shipped emergency fixes for two RCE flaws (CVE-2026-109618/109619) affecting every release since 5.4; Censys counts ~2.58M hosts and 54.9M web properties exposed, and European government sites took themselves offline on patch day. OpenAI co-participated in the vulnerability research and coordination, calling it one of the most impactful security issues in years; Wiz researchers note the bugs lurked for decades and manual exploit development neared the practical ceiling, while frontier AI models have significantly lowered the bar.

## 摘录（原文）

Expect to see quite a few websites serving error pages today: Nearly 70 percent of websites need to update their core software to fix a pair of vulnerabilities that allow an attacker to seize full control over affected servers. Experts say there are working exploits for the flaws, and that these critical bugs are already being exploited in the wild.

The flaws at issue are present in PHP, the programming language that powers sites running on a large number of web publishing systems, including Drupal, Magento, Joomla and WordPress.
