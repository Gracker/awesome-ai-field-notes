## English Version

Building agents with LLM (large language model) as its core controller is a cool concept. Several proof-of-concepts demos, such as AutoGPT, GPT-Engineer and BabyAGI, serve as inspiring examples.

In a LLM-powered autonomous agent system, LLM functions as the agent's brain, complemented by several key components:

### Component One: Planning

**Subgoal and decomposition**: The agent breaks down large tasks into smaller, manageable subgoals, enabling efficient handling of complex tasks.

**Reflection and refinement**: The agent can do self-criticism and self-reflection over past actions, learn from mistakes and refine them for future steps.

#### Task Decomposition

[Chain of thought](https://lilianweng.github.io/posts/2023-03-15-prompt-engineering/#chain-of-thought-cot) (CoT; Wei et al. 2022) has become a standard prompting technique for enhancing model performance on complex tasks. The model is instructed to "think step by step" to utilize more test-time computation to decompose hard tasks into smaller steps.

Tree of Thoughts (Yao et al. 2023) extends CoT by exploring multiple reasoning possibilities at each step. It first decomposes the problem into multiple thought steps and generates multiple thoughts per step, creating a tree structure.

#### Self-Reflection

Self-reflection is a vital aspect that allows autonomous agents to improve iteratively by refining past action decisions and correcting previous mistakes.

**ReAct** (Yao et al. 2023) integrates reasoning and acting within LLM by extending the action space to be a combination of task-specific discrete actions and the language space. The ReAct prompt template:

```
Thought: ...
Action: ...
Observation: ...
... (Repeated many times)
```

**Reflexion** (Shinn & Labash 2023) is a framework to equip agents with dynamic memory and self-reflection capabilities to improve reasoning skills. It has a standard RL setup with a reward model providing binary reward.

### Component Two: Memory

**Short-Term Memory**: All in-context learning utilizes short-term memory of the model.

**Long-Term Memory**: This provides the agent with the capability to retain and recall information over extended periods, often by leveraging an external vector store and fast retrieval (MIPS - Maximum Inner Product Search).

### Component Three: Tool Use

The agent learns to call external APIs for extra information that is missing from the model weights—including current information, code execution capability, access to proprietary information sources.

## 中文版

以大语言模型（LLM）作为核心控制器构建智能体是一个酷炫的概念。几个概念验证演示，如 AutoGPT、GPT-Engineer 和 BabyAGI，提供了鼓舞人心的案例。

在 LLM 驱动的自主智能体系统中，LLM 作为智能体的"大脑"，辅以几个关键组件：

### 组件一：规划

**子目标与分解**：智能体将大型任务分解为更小、更易管理的子目标，从而能够高效处理复杂任务。

**反思与改进**：智能体能够对过去的动作进行自我批评和自我反思，从错误中学习并为未来的步骤进行改进。

#### 任务分解

思维链（CoT；Wei et al. 2022）已成为增强模型在复杂任务上性能的标准提示技术。模型被指示"逐步思考"，以利用更多的测试时计算将困难任务分解为更小的步骤。

思维树（Yao et al. 2023）通过在每个步骤探索多种推理可能性来扩展 CoT。它首先将问题分解为多个思维步骤，并在每个步骤生成多个想法，创建树状结构。

#### 自我反思

自我反思是一个至关重要的方面，允许自主智能体通过优化过去的动作决策和纠正之前的错误来迭代改进。

**ReAct**（Yao et al. 2023）通过将动作空间扩展为任务特定的离散动作与语言空间的组合，将推理和行动整合到 LLM 中。ReAct 提示模板：

```
Thought: ...
Action: ...
Observation: ...
...（重复多次）
```

**Reflexion**（Shinn & Labash 2023）是一个为智能体配备动态记忆和自我反思能力以提高推理技能的框架。它具有标准的 RL 设置，奖励模型提供二元奖励。

### 组件二：记忆

**短期记忆**：所有上下文学习都利用模型的短期记忆。

**长期记忆**：这为智能体提供了在较长时间内保留和回忆信息的能力，通常通过利用外部向量存储和快速检索（MIPS——最大内积搜索）实现。

### 组件三：工具使用

智能体学习调用外部 API 以获取模型权重中缺失的额外信息——包括当前信息、代码执行能力、对专有信息源的访问等。
