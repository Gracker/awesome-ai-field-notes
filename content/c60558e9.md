## 原文摘录

**[External sandboxes for coding agents](https://blog.primeradiant.com/external-sandboxes-for-coding-agents/)**. I've been exploring new ways to sandbox code that is executed by agents, with a focus on making it safer to try out local models without worrying that a mistake or prompt injection attack might cause them to take damaging actions on a machine.

I worked on this project with Prime Radiant, the AI research lab behind Superpowers. My post on the Prime Radiant blog introduces the **external sandbox** pattern, where code executed by the agent runs inside a dedicated sandbox while the agent itself lives outside of that sandbox.

To demonstrate this pattern we've released three sandbox server implementations:

- external-sandbox-v86 runs a Node.js server which then uses v86 to run Alpine Linux inside WebAssembly.
- external-sandbox-container is a Python web server which runs the sandbox in Alpine Linux inside an Apple Containers instance.
- external-sandbox-quicksand is another Python web server, using Microsoft's Quicksand library which packages QEMU and Alpine Linux as a Python package.
