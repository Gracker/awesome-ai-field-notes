## Key claims (English)

Hacker News top-of-engine (≈399 pts / 121 comments): the Auto Mode attack post on Claude Code Opus 5. In the thread andai walks through an attack that drops a shadowing struct.py into the unpack directory; colinmarc argues this is exploiting the model's habit of falling back to python -c; kstenerud insists on sandboxing and cutting unnecessary network; mjmvisser has moved VS Code into a dev container as a result; Phemist questions responsibility around default Auto.
