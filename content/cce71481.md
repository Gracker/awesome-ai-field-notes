## 中文导读

Google 推出 Gemini Decisions API，由新模型 gemini-decision-1 驱动，专门面向封闭集决策原语：工具选择、策略检查、模型路由、上下文分级。单次请求可传一份多模态输入（文本/图像/音频/视频/PDF，最高 256K token）加最多 1000 个独立问题，覆盖是/否判断、2-255 选项多选、有序量规评分三种题型；模型不逐 token 生成答案，而是一次前向给所有候选选项打分，返回概率与 0-1 置信度，端到端延迟 150-250 ms。定价 $0.10/1M 输入 token、输出零计费，官方称在共享基准套件上比 Gemini 3.5 Flash-Lite 走 Interactions API 便宜近 5 倍，且校准误差最低；已在美国 AI Studio 开放，含免费额度与 Python/JavaScript/REST 文档。

## 为什么值得关注

决策正在从生成任务里被拆出来，做成专门端点。

生成式调用做路由/分级/合规检查，贵在"为一个布尔值生成一堆 token"。Decisions API 把这类封闭集判断压成单次前向打分：共享输入每次请求只计一次费，问题数从 1 到 100 延迟几乎持平，置信度分数可以直接驱动兜底或转人工。Google 内部已经把它当低延迟控制面用——Notebook 拿它做实时模型路由（日常查询延迟降 40%）、Search 用它给 MCP 工具做对抗行为安全层、CC 用它从 200+ 表情里瞬时选择。对做 agent 编排的人来说，这是一个新原语：分类器不用训练，把问题定义写清楚就能上线，OpenRouter/LangChain/LiteLLM 等生态集成同步铺开。

## English Summary

Google introduced the Gemini Decisions API, a new endpoint for fast, closed-set decisions powered by the Gemini Decision 1 model (gemini-decision-1), available in Google AI Studio. Purpose-built primitives target bounded choices such as tool selection, policy checks, model routing, and context grading: one multimodal input across text, images, audio, video, and PDFs (up to 256K tokens) plus up to 1,000 independent yes/no, multiple-choice (2-255 options), or ordered-rubric questions answered in a single forward pass that returns probabilities and 0-1 confidence scores in 150-250 ms end-to-end. Priced at $0.10 per 1M input tokens with zero output-token billing, Google reports it is nearly 5x cheaper than Gemini 3.5 Flash-Lite with the Interactions API across a shared benchmark suite, with the lowest calibration error. In-house uses include real-time model routing in Gemini Notebook (up to 40% lower latency on everyday queries), an MCP-tool safety layer in Search, and instant emoji selection in CC.
