## English Abstract / Summary

Simon Willison relays Paint.NET author Rick Brewster's account of using Claude to clean-room reimplement Direct2D so the editor can run on WINE; the result is 180,000 lines of "vibe-coded" C# that Brewster says he cannot review line-by-line (Paint.NET's other 700K lines he has shepherded for 20 years). Brewster documents Claude's failure modes on real Windows/C++ system code: COM AddRef reference counts need human oversight, architectural decisions need to be "slapped down," but the math inside Direct2D's built-in effect library Claude reverse-engineered on its own. The piece is the most concrete author-side account of vibe coding in a large system-level codebase.
