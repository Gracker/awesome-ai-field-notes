# BioBasicsBench: 100 wet-lab tasks test how agents read raw experimental data

- **ID**: cfd4354a
- **来源**: https://openai.com/index/measuring-how-ai-agents-handle-wet-lab-science/
- **发布**: 2026-11-06（OpenAI 与酶设计公司 Ligo 合作）
- **抓取**: 官方页 + 研究种子核对，2026-11-07

## 官方定位

Introducing BioBasicsBench, a benchmark measuring how well AI agents interpret raw experimental data across **100 routine wet-lab tasks**。数据类型覆盖台面/仪器/试剂照片（18 项：gel rig、PCR plate、liquid-handler deck 等）、凝胶图像、菌落板、流式数据等原始实验产物——考的是"读原始图"，不是复述论文摘要。

官方 evaluated seven models: GPT-5.2, GPT-5.4, GPT-5.5, GPT-5.6 Sol, GPT-6.1 Sol, GPT-6 Luna and GPT-6 Astra。

## 关键读数（发布报道口径）

- GPT-6 Astra **66.7%** vs GPT-5.6 Sol **43.8%**。
- 部分分机制下，认错菌落仍可得分 → 榜面分数约 **12%** 的高估空间。
- 官方口径：用于跟踪科学进展与 biosafety / biosecurity 含义。

## 为什么值得收

科学 agent 叙事最缺"原始证据读取"能力边界；BioBasicsBench 把湿实验日常分析拆成可复核任务，与 Rosalind 等产品 SKU 形成对照。分数含部分分高估，横向比较需看任务级明细。
