# 公众号爆款文章提示词：让AI写出有"人味"的深度长文

## 背景

对于公众号运营新手来说，好的提示词就是创作的"捷径"。但 AI 生成的内容往往有"AI 味"——生硬、套路化、缺乏真情实感。这篇文章分享一套结构化框架提示词，帮助你用 AI 写出有"人味"的深度长文。

## 核心痛点

AI 写作常见问题：
- 语言机械，句式单一
- 过度使用连接词和过渡句
- 列表式输出，缺乏流畅叙述
- 结论先行，说教感强
- 缺乏个人经历和情感共鸣

## 结构化提示词框架

### 第一部分：角色设定

```
你是一名资深公众号内容创作者，擅长创作[领域]的自媒体爆款文章。
你的主要职责是创作更有人情味儿、更自然流畅、消除机器写作痕迹的内容。
风格要求：
- 长短句结合，避免单一句式
- 减少使用列表和总结，多用叙述性表达
- 减少使用连接词，保持自然流畅
- 从语言风格、情感传递到逻辑架构，全方位贴近人类真实写作习惯
```

### 第二部分：内容要求

```
创作要求：
1. 开头要有吸引力，用故事或场景切入，不要直接抛出结论
2. 主体内容要有层次，层层递进，每个段落之间自然衔接
3. 适当融入个人经历或真实案例，增加可信度和共鸣感
4. 结尾要有升华，但不能生硬说教，要让读者自己感悟
5. 全篇保持口语化、自然、有温度的语调
```

### 第三部分：输出格式

```
请按以下结构输出：
## [吸引眼球的标题]

### 场景切入（200字左右）
用一个具体场景或故事开头，引发读者共鸣

### 问题剖析（500-800字）
层层递进分析问题，每个段落有新的视角或信息增量

### 解决方案（500-800字）
给出具体可行的建议，配合实际案例

### 升华总结（200字左右）
用金句或感悟收尾，让读者有收获感
```

## 标题生成技巧

| 技巧 | 示例 |
|------|------|
| 数字法 | "3个技巧"、"5个方法"、"7步走" |
| 痛点法 | "为什么你写的文章没人看？" |
| 对比法 | "别人月入10万，你还在为选题发愁" |
| 悬念法 | "这个公式让我多赚了5000块" |
| 蹭热点 | 结合当下热门话题或事件 |

## 降低"AI味"的技巧

1. **口语化表达**：多使用"咱们"、"说实话"、"其实"等口语词
2. **增加语气词**：适当使用"啊"、"呢"、"吧"等语气词
3. **打破完整句式**：偶尔用不完整的句子或短句增加真实感
4. **融入个人视角**：用"我觉得"、"朋友告诉我"等主观表达
5. **减少过度优化**：不要每个句子都打磨得很完美，稍有瑕疵反而更真实

## 完整提示词示例

```
请帮我写一篇关于[主题]的公众号文章。

背景信息：
- 目标受众：[用户画像：年龄、性别、地域、职业、兴趣标签等]
- 文章核心价值：[文章能给读者带来的主要价值]

创作风格：
- 要有"人味"，避免生硬的AI腔
- 长短句结合，减少列表式输出
- 多用故事和案例，少用抽象理论
- 语言自然流畅，像在和朋友聊天

标题要求：
- 20-30字之间
- 包含至少1个数字
- 融入1-2个当下热门关键词
- 诚实可信，不做标题党

请按以下结构输出完整的文章内容。
```

## 总结

AI 写作的关键不是让 AI 替你写，而是让 AI 帮你**理清思路、激发灵感、完善细节**。最终的内容质量仍然取决于你对读者需求的理解和对文章节奏的把控。

好的提示词 + 你的编辑能力 = 爆款文章
