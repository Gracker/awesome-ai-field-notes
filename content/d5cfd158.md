## ChatGPT Code Interpreter / Advanced Data Analysis 概述

ChatGPT Code Interpreter 是一项强大的功能，为 ChatGPT 提供了在沙盒环境中编写和执行 Python 代码的能力。最初作为 ChatGPT Plus 订阅功能推出，现已成为 GPT-4o 模型的默认能力。

### 核心能力与应用场景

- **数据分析、处理与可视化**：分析数据、创建图表、执行统计分析（如相关性和聚类）、处理大型数据集（支持高达 100MB 的文件上传）
- **文本处理**：包括摘要和其他文本操作
- **代码创建、调整和调试**：编写、执行和调试 Python 代码
- **数学运算**：执行复杂计算并准确解决数学问题，弥补了 LLM 之前的局限性
- **文件处理**：用户可上传多种文件类型（如 Excel、Word、文本文件、图片/PDF），下载生成的报告或修改后的文件
- **图像和音频处理**：从音乐文件生成频谱图、创建简单视频、生成分形艺术等有限功能

### 访问与使用

使用 Code Interpreter（Advanced Data Analysis）通常需要 ChatGPT Plus 订阅。在 GPT-4 模型中，Code Interpreter 功能通常会自动启用，或可在开始新对话时从模型选项中选择。
