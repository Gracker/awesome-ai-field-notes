## 中文导读

FORECAST 把失败诊断前置给修复 agent：从通过/失败测试的执行差异中推断一条 cause chain——解释失败运行在哪里分叉的短执行特征序列（条件、数据流等）——追加到 agent 收到的 issue 里。因为任何从 issue 构建 prompt 的 agent 都能受益，无需改动 agent 本身。在 SWE-bench Lite 全部 300 个 issue、5 个修复 agent、两个模型（Claude Haiku 4.5 与开源 Qwen3.5）上，所有 agent 的解决率都显著提升：Haiku 4.5 从 48.5% 升到 70.9%，Qwen3.5 从 31.2% 升到 56.1%——开源模型带诊断后反超不带诊断的商业模型。增益在重复运行间保持，对已经在运行这些测试的 agent 也依然有效。

方法便宜且通用：不碰 agent，只改 issue 输入，把找失败原因从各 agent 各自为战变成共享的执行证据。+22/+25 个百分点的提升在 SWE-bench Lite 上幅度相当大，开源模型加诊断反超商业模型裸跑的组合，对成本敏感的团队有直接参考价值。

## English Summary

FORECAST gives repair agents a failure diagnosis before they attempt a fix. From the executions of passing and failing tests it infers a cause chain, a short sequence of execution features (conditions, data flow) explaining where failing runs diverge, and appends it to the issue the agent receives, so any agent that builds its prompts from the issue benefits without modification. Evaluated on all 300 SWE-bench Lite issues with five repair agents and two models (Claude Haiku 4.5 and open-weight Qwen3.5), every agent resolves significantly more issues: 48.5% to 70.9% for Haiku 4.5 and 31.2% to 56.1% for Qwen3.5, meaning the open-weight model with the diagnosis surpasses the commercial model without it. Gains persist across repeated runs and for agents that already run the tests the diagnosis is derived from.
