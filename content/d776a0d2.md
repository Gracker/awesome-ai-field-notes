## 中文导读

OpenAIDevs 官宣（2026-11-09，帖约 4100 赞）：Codex 的 dot 现在可以连接多台本地计算机，并按任务指定用哪台执行；官方演示是一台专机 build/test 应用，笔记本继续写码。这把工作站拓扑变成产品开关，与 Claude Code remote-control 的 --settings 共享配置同属「单入口、多执行面」方向；对 iOS/Xcode 专机、构建隔离等场景直接可用。官方演示级，暂无文档页，会话归属与并发语义待核。

## 为什么值得关注

「多执行面」正在成为 coding agent 的标准形态：入口统一、执行分散到多台机器。对照 Claude remote-control 与 Hermes gateway 的单入口设计，可以开始比较各家在会话所有权、构建机隔离上的语义差异。
