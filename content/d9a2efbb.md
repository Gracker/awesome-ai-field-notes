## Summary (English)

Terence Tao describes using AI agents to port 24 Java math visualization applets from 1999 to JavaScript. AI not only fixed original code bugs but identified errors the author was unaware of. Completed porting in hours, plus generated a special relativity visualization tool abandoned in 1999 due to code complexity. Demonstrates how a top mathematician uses AI assistants in practice.
