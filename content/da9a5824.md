## English Summary

Postman desktop 12.33.4 silently installed plugins into unrelated coding agents, per user indicava's Oct 25, 2026 GitHub issue (208 reactions, open, 31 comments; ~956 HN points). After merely opening Postman on macOS, they found a user-wide Postman plugin in Codex, a Claude Code plugin, a startup instruction hook the installer tried to have trusted, a remote MCP connection, and a separately installed Postman CLI. Postman's own main.log records the automatic install: source 'auto-existing-upgrade', results 'claude-code:installed','codex:installed', and 'Main: autoInstall.plugin.existing-user finished'. The reporter frames it as a consent and trust-boundary failure: an API client should not make itself the default workflow in other tools just by being opened.
