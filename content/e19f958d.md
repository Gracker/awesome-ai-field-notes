### What Notion 3.5 Actually Shipped

Notion launched its Developer Platform — version 3.5 — on May 13, 2026. The headline feature is buried under a marketing line that's easy to gloss past: "Bring your favorite agents into Notion with the External Agents API. We've partnered with Claude, Codex, Decagon, Cursor, Warp, Cognition, Flora, Amplitude, Console, and Serval so they work out of the box."

Notion 于 2026 年 5 月 13 日发布了开发者平台 3.5 版本。其核心功能藏在一句容易被忽视的宣传语中："通过外部代理 API 将你喜欢的智能代理接入 Notion。我们已与 Claude、Codex、Decagon、Cursor、Warp、Cognition、Flora、Amplitude、Console 和 Serval 建立合作，开箱即用。"

Translation: Claude Code can now operate as a first-class agent inside a Notion workspace. Not "Notion has its own Claude integration." Not "MCP server in a sidebar." Claude Code itself can chat in Notion pages, get assigned work from Notion databases, route handoffs to Codex or Decagon, and write results back as Notion content — all orchestrated by Notion as the coordination layer.

翻译：Claude Code 现在可以作为一等公民在 Notion 工作空间中运行。不是"Notion 有自己的 Claude 集成"，也不是"侧边栏的 MCP 服务器"。Claude Code 本身可以在 Notion 页面中聊天，从 Notion 数据库获取任务，将工作交接给 Codex 或 Decagon，并将结果写回为 Notion 内容——全部由 Notion 作为协调层进行编排。

Five primitives launched together:

1. **External Agents API** — alpha, waitlist required. Lets third-party AI agents operate inside a Notion workspace.
2. **Notion Workers** — beta, open. A hosted runtime for custom JavaScript/TypeScript code.
3. **Notion CLI (ntn)** — open, all plans. Install with `curl -fsSL https://ntn.dev | bash`.
4. **Updated REST API + Markdown API** — generally available.
5. **Webhook triggers** — generally available.

5 个原语同时发布：

1. **外部代理 API** — alpha 版，需要等待名单。让第三方 AI 智能代理可以在 Notion 工作空间内运作。
2. **Notion Workers** — beta 版，开放使用。托管的 JavaScript/TypeScript 代码运行时。
3. **Notion CLI (ntn)** — 开放，所有计划可用。用 `curl -fsSL https://ntn.dev | bash` 安装。
4. **更新后的 REST API + Markdown API** — 全面可用。
5. **Webhook 触发器** — 全面可用。

### The Auth Layer — Three Connection Types

Notion's auth model has three connection types:

1. **Public connections** — for agents distributed to many users. Authenticate via OAuth 2.0 with page-level scoping.
2. **Internal connections** — for team-owned automations. Static API token, scoped to a single workspace.
3. **Personal Access Tokens (PATs)** — for trusted user-scoped scripts and CLI workflows. Best for Workers you're deploying and local agent experimentation.

认证层 — 三种连接类型

Notion 的认证模型有三种连接类型：

1. **公共连接** — 适用于分发给众多用户的智能代理。通过 OAuth 2.0 认证，采用页面级作用域。
2. **内部连接** — 适用于团队所有的自动化脚本。静态 API 令牌，作用域限定为单个工作空间。
3. **个人访问令牌（PAT）** — 适用于受信任的用户级脚本和 CLI 工作流。最适合你正在部署的 Workers 和本地智能代理实验。

One important change: as of 3.5, any workspace member can create connections, not just Workspace Owners.

一个重要变化：从 3.5 版本开始，任何工作空间成员都可以创建连接，不再仅限于工作空间所有者。

### Five-Step Setup

**Step 1: Install the Notion CLI**
```bash
curl -fsSL https://ntn.dev | bash
```
Verify with `ntn --version`.

**Step 2: Create a Personal Access Token**
Create an integration at app.notion.com/developers. Generate the Internal Integration Token (starts with `ntn_`). Set it as `NOTION_API_TOKEN`.

**Step 3: Sign in to the CLI**
Run `ntn login` for session auth. Set `NOTION_API_TOKEN` environment variable for API calls.

**Step 4: Scaffold a Worker**
```bash
ntn workers new claude-code-helper
cd claude-code-helper
```

**Step 5: Deploy the Worker**
```bash
ntn workers deploy
```

Workers are **free during beta** (May 13 to August 11, 2026).

### The August 11 Credits Trap

The most important pricing detail: Workers are free through August 11, 2026. Starting August 11, Workers will run on Notion credits. Community reports put the post-August 11 rate at $10 per 1,000 credits.

Practical recommendation: build Workers liberally during the beta to learn the runtime, but treat any Worker you intend to keep in production as a soon-to-be-metered service. Prefer Workers that bundle multiple agent actions into one invocation.

8 月 11 日积分陷阱

最重要的定价细节：2026 年 8 月 11 日之前 Workers 免费。8 月 11 日起，Workers 将按 Notion 积分计费。社区报告显示，8 月 11 日后的费率为每 1000 积分 10 美元。

实用建议：在 beta 期间积极构建 Workers 以学习运行时，但将任何打算在生产环境中保留的 Worker 视为即将开始计费的服务。优先选择将多个智能代理操作打包到一次调用中的 Workers。

### What the Integration Can't Do (Yet)

- It can't bring Notion data into Claude Code's training
- It can't trigger Notion from arbitrary external sources without a Worker in the middle
- It can't handle large file uploads through the External Agent flow
- It can't replace Notion's native agents inside the workspace
- The credits cost isn't fully knowable yet

### The Bottom Line

The External Agents API is the integration developers have wanted for two years, but the path that works today is the CLI + PAT + MCP + Workers path. Set up the CLI tonight. Generate a PAT, share three or four Notion pages with your integration. Register the Notion MCP server in Claude Code. You're 80% of the way to the workflow the headline promises, and you're not stuck on the waitlist.

当外部代理等待名单对你开放时，OAuth 流程会将 Claude Code 降级为你工作空间中的 @ 可提及智能代理，协调层会上线。到那时你将拥有一个 Workers 库，并清楚哪些工作流真正受益于智能代理编排，哪些更适合作为普通的 CLI 脚本。
