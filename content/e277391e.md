## 中文导读

Anthropic 11 月 23 日发布 Claude Ship，面向 Team/Enterprise 客户、接入 GitHub。Code Review 转正式可用；新增两个 beta：PR Steward 负责处理失败 CI、合并冲突和评审意见，并在每次 push 后说明改了什么、怎么撤回；Claude Approvals 读取仓库里提交的策略文件，决定例行变更能否由 Claude 批准、哪些路径仍需人工。按 token 计费、可设预算。Anthropic 同时给出内部自报数字：Claude Code 团队 2026 年 6–9 月合并 PR 数超翻倍、回滚比例下降约四成以上（公司自报，非公开 benchmark）。发布时点与 Harvard/Jellyfish「agent 把工程瓶颈挪到 code review」的报道同窗。

## English Summary

Anthropic launched Claude Ship on 2026-11-23 for Team and Enterprise customers using GitHub. Code Review is now generally available, and two beta capabilities were added: PR Steward handles failed CI, merge conflicts, and review comments, explaining after every push what it changed and how to revert; Claude Approvals reads policy files committed in the repository to decide which routine changes Claude may approve and which paths still require a human. The product bills by token with configurable budgets. Anthropic also shared an internal, self-reported figure: the Claude Code team more than doubled merged PRs from June to September while cutting the rollback ratio by roughly forty percent or more. The launch lands the same week as survey coverage arguing that agents have moved the engineering bottleneck to code review.
