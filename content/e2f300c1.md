## 摘要 (Summary)

OpenProver 是开源的 LLM 驱动自动定理证明（ATP）系统，集成 Lean 4 形式化验证采用 Planner-Worker-Verifier 架构（受 Aletheia 启发）：Planner 维护紧凑的 Whiteboard 暂存区与无界的 Repository 中间结论，把数学任务拆给并行 Worker；提供交互式终端界面，允许人类操作员监控并引导证明搜索，动机来自交互式代码生成中的人机协同范式系统完全开源，支持自动形式化验证生成的证明，可在 ProofNet 上进行可复现的消融实验

## English Abstract / Excerpt

We present OpenProver, an open-source system for LLM-driven automated theorem proving (ATP) with integrated Lean 4 formal verification. OpenProver integrates a Planner-Worker-Verifier architecture inspired by recent ATP agentic systems such as Aletheia. A Planner agent maintains a compact Whiteboard scratchpad and an unbounded Repository of intermediate findings, and decomposes mathematical work into parallel Workers. OpenProver is fully open-source, offers reproducible evaluation through automatic formal verification of generated proofs, and provides an interactive terminal interface for human-guided proof search, motivated by the established human-AI synergy in interactive code generation. We evaluate OpenProver on ProofNet and compare it with a simple baseline.
