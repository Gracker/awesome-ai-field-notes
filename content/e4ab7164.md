# karpathy

**Source**: [https://x.com/karpathy/status/2040572272944324650](https://x.com/karpathy/status/2040572272944324650)
**Quality Score**: 4

---

> **EN** I'm working on a personal memory artifact for myself. I maintain a wiki of my life where the LLM regularly reads and edits.
>
> **中** 我正在为自己构建一个个人记忆工具。我维护着一份「人生维基」，LLM 会定期阅读和编辑它。

---

> **EN** This is in contrast to the usual chatbot where the memory is implicit and hidden (and very lossy). The file is explicit and navigable, and can be refined over time.
>
> **中** 这与普通聊天机器人的记忆模式不同——通常记忆是隐含的、隐藏的（且极易丢失）。而这里的文件是显式的、可追溯的，并且可以随时间不断完善。

---

> **EN** The key property is that the memory is not in the weights of the model, but in a file that both the human and the model can read and write. This means the memory is persistent, versionable, and human-legible.
>
> **中** 关键特性在于：记忆不在模型的权重里，而在一份人类和模型都能读写文件中。这意味着记忆是持久的、可版本化的、人类可读的。

---

> **EN** This is also very different from a simple RAG because the LLM is not just retrieving documents, but actively editing the memory artifact. It can add new information, correct old information, and even add reflections.
>
> **中** 这也与简单的 RAG（检索增强生成）截然不同，因为 LLM 不仅在检索文档，还在主动编辑记忆工具——可以添加新信息、修正旧信息，甚至写入反思。

---

> **EN** In a way this is like an explicit memory system for the LLM, similar to how the hippocampus in the human brain is responsible for explicit memory formation.
>
> **中** 某种程度上，这相当于为 LLM 构建了一个显式记忆系统，类似于人类大脑中负责显式记忆形成的海马体。
