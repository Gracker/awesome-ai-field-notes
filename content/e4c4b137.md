## 中文摘要

Hetzner 官方上线 exploratory platform，提供实验性 open-weight LLM inference API；免费无 SLA，明确不承诺成为正式产品社区截图提到模型覆盖包括 DeepSeek v4GLM 5.2Kimi 等这是传统云/主机商首次把免费实验 API无 SLA作为试水做法，对本地/自建 Agent 的推理后端选项有直接意义，但不适合直接上生产

## English Summary

Hetzner Online announces an exploratory platform offering an experimental open-weight LLM inference API - free, no SLA, explicitly framed as 'not committing to becoming a permanent product.' Community screenshots list DeepSeek v4, GLM 5.2, and Kimi among the supported models. First time a traditional cloud / bare-metal provider uses 'free experimental API, no SLA' as a market probe; meaningful for local / self-hosted Agent backends but unsuitable for production workloads.
