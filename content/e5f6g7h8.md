# Google 推出 Gemini 3.1 Flash TTS：音频标签控制语音风格与节奏
# Gemini 3.1 Flash TTS: Audio Tags Control Speech Style and Rhythm

## 中文原文 / Chinese Original

Gemini 3.1 Flash TTS 是 Google 迄今为止**表现力最强、可控性最高**的语音合成模型。

### 核心新功能：Audio Tags（音频标签）

用自然语言命令嵌入文本来引导语音风格、节奏和表达方式。例如：

```
<effect type="excited">大家好！</effect>
<pause duration="1s"/>
<effect type="calm">这就是新发布的模型。</effect>
```

通过在文本中嵌入标签，可以精细控制：
- **情感语气**：兴奋、平静、严肃、温柔……
- **节奏停顿**：语速、停顿时长、强调位置
- **声音效果**：远近距离、回声、混响……

### 使用方式

可在 Google AI Studio 或 Vertex AI 直接调用，适合：
- 有声内容创作（播客、有声书）
- 语音助手定制
- 播客类 AI 应用
- 游戏 NPC 语音

### 核心意义

音频标签让语音合成从"调参数"变成"写指令"，大幅降低了 AI 语音定制门槛。

以往定制 TTS 需要调整多个离散参数（如 pitch、speed、breathiness），现在只需要一段自然语言描述即可精确控制。

## English Translation

Gemini 3.1 Flash TTS is Google's **most expressive and controllable** text-to-speech model to date.

### Core New Feature: Audio Tags

Natural language commands embedded in text to guide speech style, rhythm, and expression. For example:

```
<effect type="excited">Everyone, hello!</effect>
<pause duration="1s"/>
<effect type="calm">This is the newly released model.</effect>
```

By embedding tags in text, you can finely control:
- **Emotional tone**: excited, calm, serious, gentle...
- **Rhythm & pacing**: speaking speed, pause duration, emphasis position
- **Audio effects**: distance, reverb, echo...

### How to Use

Available directly via Google AI Studio or Vertex AI. Ideal for:
- Audio content creation (podcasts, audiobooks)
- Voice assistant customization
- Podcast AI applications
- Game NPC voices

### Why It Matters

Audio Tags transform voice synthesis from "tuning parameters" to "writing instructions", dramatically lowering the barrier to AI voice customization.

Previously, customizing TTS required adjusting multiple discrete parameters (pitch, speed, breathiness). Now, a simple natural language description achieves precise control.
