# Deprecation notice: Agent Builder
> 原文链接: https://community.openai.com/t/deprecation-notice-agent-builder/1382650

## 通知原文（社区帖，经搜索摘要核对）

- "OpenAI is deprecating Agent Builder. Existing users can continue using it during the transition window, and the product is scheduled to shut down on November 30, 2026. ChatKit remains available."
- "On June 3, 2026, we notified developers using Agent Builder that the product is being deprecated."
- OpenAI deprecations 页（developers.openai.com/api/docs/deprecations）列明 Agent Builder、Evals（10-31 转只读）、prompt objects 均为 2026-11-30 关停。
- 迁移分析（AgenticWire）：导出为 Agents SDK 代码"does not convert the workflow graph or guarantee unchanged behavior"；官方去向为 Agents SDK 与 ChatGPT Workspace Agents。

## Obsidian 证据摘录（Agent实践探索 2026-10-31）

同期收拢：微软 4 月把 AutoGen 与 Semantic Kernel 合成 Agent Framework 1.0，AutoGen 本体进入维护模式；ACP 并入 Linux 基金会名下的 A2A，MCP 的 server 实现超过 200 个。九框架同任务实测（agentmail）：LangGraph 1,288 输入 token、CrewAI 1,432，Claude Agent SDK 单次查询约 35,000 token（整个 harness 进上下文），smolagents 核心约 1,000 行。框架数量还多，底层共识已集中到模型循环加 MCP，拉开差距的是封装重量。
