## 中文导读

Cursor 的这条 changelog 把『离开电脑后继续盯本地 agent』做成默认能力：在 Cursor iOS 应用登录后，你账户下的电脑自动出现在列表里，在桌面端批准配对请求，本地 agent 就以列表形式显示在手机上，点开可查看它在做什么或直接发消息。功能边界写得清楚：远程控制不会把 agent 搬到别处，agent 仍在你的电脑上执行，App 只是建立连接，所以电脑必须开机联网；要防止离开时休眠，需在桌面设置里开 Keep this computer awake，前提是接通电源且不合盖。除企业组织外默认对所有用户开启，企业管理员可以在 Org settings 的 Security 部分关闭。本机长任务与云 agent 的组合方式因此多了一个默认选项。

- 默认开启（企业组织除外）；管理员可在 Org settings 关闭

## English Abstract

You can now view and reply to local agents running on your computer from the Cursor iOS app. Remote control is on by default for all users except enterprise orgs. Your agents keep running on your machine - the app only establishes a connection - so the computer must remain powered on and online. To prevent sleep while away, enable Keep this computer awake in Cursor desktop settings; the computer must be plugged in with the lid open.
