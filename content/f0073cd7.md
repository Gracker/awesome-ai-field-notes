## 中文导读

HermesAgentv0.23.1修复插件目录静默回退：11-09目录站点部署后plugin-catalog.json超过客户端2MiB上限，所有安装都静默回退到发行版自带旧目录——hermespluginsinstall找不到新插件、装到过期pin、漏掉新removed条目。本版把上限提到16MiB恢复使用线上目录（PR#151860，fixes#151856）；停在0.23.0及以下的安装继续回退。该patch汇总0.23.0以来约618个PR（2,578非合并提交、409个issue关闭），完整notes留待v0.24.0。

## 为什么值得关注

Hermes v0.23.1：插件目录 2→16 MiB，修「装到旧 pin」的静默回退

「插件装上了但一直是旧 pin」这类故障的可复用教训：客户端对远端资源加硬上限时，超限必须显式失败而不是静默回退——回退把「目录过期」伪装成「目录正常」。依赖插件目录的机器先升 0.23.1 再装插件。

## 原文摘录（GH release body，2026-11-11 gh release view 抓取）

> "since the plugin catalog's site deploy on November 9, the published `plugin-catalog.json` was larger than the 2 MiB cap clients accept, so every install silently fell back to the catalog it shipped with. `hermes plugins install <name>` could not find plugins added since your last update, installed the pin your release shipped instead of the current one, and missed newer `removed` entries. This release raises the cap to 16 MiB, so the live catalog is used again"
