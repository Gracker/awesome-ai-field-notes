## 摘要（AAIF 提取）

John Berryman 从 OpenAI 工具调用的隐式分类机制推演出了 Jev 的可能复制路径。

## 主张

Jev 是普通 LLM 的“被忽略用法”，因为 OpenAI 的工具调用从 2023 年起就用单 token 当隐式分类器：assistant 之后第一个 token 决定是否调用工具，再下一组 token 选工具名、再后面是参数，最后的 stop token 等于回答“我答完没”。

## 推演

如果 OpenAI 把这种内置分类能力 productize，可以新增一种 `<prediction>...</prediction>` 语法让模型在自己的 thinking 块里“问自己、回答自己、不离 GPU”，从而省钱、减少幻觉、做安全护栏、做模型路由。
