# The Tower Keeps Rising (Armin Ronacher)

> Source: https://lucumr.pocoo.org/2026/7/13/the-tower-keeps-rising/
> Author: Armin Ronacher
> Date: 2026-07-13

## Summary (Chinese)

以巴别塔为隐喻指出，大型软件项目的瓶颈是“共享语言”——对系统概念、边界、不变量的共同理解。AI agent 抹平了读代码、code review、争论产生的协作摩擦，让各自合理的局部修改叠加成谁都无法全局理解的新巴别塔。agent 不感受痛苦，摩擦才是人类同步理解的机制。巴别塔的崩塌是由于语言丢失，但 AI 工程中建造可以在共享理解崩塌后继续。

## Summary (English)

Using the Tower of Babel as metaphor, Armin Ronacher argues large software project bottlenecks are 'shared language': common understanding of system concepts, boundaries, and invariants. AI agents remove the friction that synchronizes human understanding, letting individually reasonable changes accumulate into a tower no one can globally understand. Agents don't feel pain; friction is the mechanism for human synchronization.
