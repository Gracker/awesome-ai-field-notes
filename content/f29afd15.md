## 中文导读

Anthropic 10 月 22 日宣布把 Agent Skills 开放标准捐给 Linux Foundation 下的 Agentic AI Foundation（AAIF）——去年它与 Block、OpenAI 共同创立该基金会，并把 MCP 也捐了进去。此番连同标准名称、logo、GitHub 组织与 agentskills.io 域名一并移交。Simon Willison 当天转述，并指出自己去年 12 月 Anthropic 首次把 skills 称为「开放标准」时就预判了这个去向（还现场用 datasette-mcp 让 Claude 从他自己的博客里检索出了那篇旧文）。

## 为什么值得关注

规模数字是这轮最值得记住的部分：ChatGPT、Cursor、GitHub Copilot、VS Code 等 70 多个 agent 平台已集成，累计发布约 100 万个 skill、安装近 2.8 亿次。把标准从单一厂商挪到基金会名下，短期不改变使用方式，意义在于「某一家改格式」的成本从此由社区摊平；AAIF 路线图里的 skill 安全指引是百万级生态眼下最缺的东西。

## 关键信息

- 移交物：SKILL.md 标准格式 + 名称 + logo + GitHub 组织 + agentskills.io 域名
- 规模：70+ agent 平台集成；约 100 万 skill；近 2.8 亿次安装
- 维护：Anthropic / Google / OpenAI 工程师以个人身份；Lead Maintainer：David Soria Parra、Mahesh Murag
- AAIF 路线图：版本化发布、正式提案流程、skill 作者与安装者安全指引
- Willison 预判时间线：2025-12-19（Anthropic 宣布开放标准当天）

## English Summary

Anthropic donated the Agent Skills open standard - the SKILL.md folder format plus its name, logo, GitHub organization, and the agentskills.io domain - to the Agentic AI Foundation under the Linux Foundation, which it co-founded with Block and OpenAI and which already hosts MCP. Simon Willison, who predicted the move last December, relays the scale numbers: 70+ agent platforms including ChatGPT, Cursor, GitHub Copilot, and VS Code have integrated the format, with roughly 1 million skills published and nearly 280 million installs. Maintenance is by engineers from Anthropic, Google, and OpenAI in their personal capacities, led by David Soria Parra and Mahesh Murag; the AAIF roadmap promises versioned releases, a formal proposal process, and security guidance for skill authors and installers - the piece most needed at million-skill scale, where installing an unvetted third-party skill rivals pip-package risk.
