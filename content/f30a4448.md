# Diffusion at Scale: Introducing Mercury 3

> Source: [https://www.inceptionlabs.ai/blog/introducing-mercury-3](https://www.inceptionlabs.ai/blog/introducing-mercury-3) · platform: blog · author: Inception Team · date: 2026-10-19

## TL;DR（中文摘要）

Inception 发布 Mercury 3，正面回答「扩散 LLM 能否规模化」：参数量较 Mercury 1 扩 40 倍以上、标准基准智能提升 3 倍，扩散的 scaling laws 成立；1,068 tokens/秒（比同级快 4–8 倍），基准超 GPT-6 Luna 与 Claude Haiku 5.5，上下文 1M（上一代 260K），定价 $0.20/M 输入、$0.70/M 输出（发布期五折、缓存输入再九折）。生产实测：Mind2Web 50 个真实导航任务完成 50%，高于 GPT-6.1-Sol，token 量与步数相同；Octen 智能眼镜端到端中位 2.2 秒。扩散架构首次以 frontier 质量进入实时 agent 场景，可直接通过 OpenRouter/Baseten/Vercel 接入。

## Summary (English)

Inception ships Mercury 3, answering whether diffusion LLMs scale: 40x larger than Mercury 1 with 3x benchmark intelligence, 1,068 tokens/second (4-8x faster), outperforming GPT-6 Luna and Claude Haiku 5.5, 1M context, $0.20/$0.70 per million tokens. In production it completes 50% of 50 live Mind2Web navigation tasks, ahead of GPT-6.1-Sol at the same token volume and agent steps. Diffusion quality now meets real-time agent latency.

## 原文要点（grounded facts）

- 自称迄今最强扩散 LLM：基准超 GPT-6 Luna 与 Claude Haiku 5.5，同时快 4–8 倍
- 1,068 tokens/秒（NVIDIA GPU）；参数量较 Mercury 1 扩 40x 以上，智能提升 3x
- 上下文 1M tokens（Mercury 2.5 为 260K）；$0.20/M 入、$0.70/M 出，发布期五折 $0.10/$0.35，缓存输入为输入价一折
- 生产实测：Mind2Web 50 个 live 导航任务完成 50%，显著高于 GPT-6.1-Sol，token 量与 agent 步数相同
- Octen 智能眼镜 Sense API 测试：生成中位 0.9 秒、端到端中位 2.2 秒
- 已上线 Inception API 与 OpenRouter、Baseten、Vercel，OpenAI API 兼容
