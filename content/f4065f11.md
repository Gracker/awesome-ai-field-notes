## English Summary

1Password announced a platform that lets personal AI agents sign in on the user's behalf without ever holding the credentials. When an agent reaches a sign-in page it stops and requests a credential from the user's vault; after the user approves, 1Password auto-fills the credential directly on the destination site, so the secret and one-time codes never pass through the agent's context. The post explicitly rejects both common workarounds - manually typing passwords into each agent session is slow, and pasting a password into a prompt grants the agent access potentially beyond the task at hand. Launch integrations cover Meta's Muse, Anthropic's Claude Duet, OpenAI ChatGPT Work and dots, SpaceXSI Grok Bot, and Town Townie, with Instinct, Browserbase, Browser Use, Dana, KERNEL, Perplexity, Ramp, Tomo, and Wajo listed as upcoming; users control what agents access and when, can disconnect integrations at any time, and the feature ships at no additional cost for Individual and Family accounts (.eu/.ca not yet supported).
