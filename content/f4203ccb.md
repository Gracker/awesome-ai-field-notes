## 中文摘要

SkillReranker 是一个推理时的重排框架：对任务和候选技能都做语义分解，得到 sub-task / 执行状态描述与 transition-state 描述，再用它们构建一个有向无环执行图（中间任务状态作节点，候选技能作边），最后判断每个状态节点是否满足 split 条件它显式处理任务难度和技能适用性的动态影响，对大规模 skill library 的"语义相似但执行效果不一"歧义有直接帮助属于 harness 端 skill routing 链路

## English Abstract

Skill usage can significantly enhance the ability of modern agent systems to complete complex tasks. However, the growing scale of skill libraries makes accurate skill selection increasingly challenging. In real-world scenarios, ambiguous semantic matching often arises between a specific task requirement and multiple generic yet semantically similar candidate skills. Moreover, existing methods tend to overlook the dynamic influence of task difficulty and skill applicability when selecting the optimal target skill set. To address these issues, we propose SkillReranker, an inference-time reranking framework for adaptive skill selection. Specifically, we first perform semantic decomposition on both the task and skill sides, yielding informative subtask and execution-state descriptions as well as transition-state descriptions that characterize each skill's functionality....
