## 摘要（AAIF 提取）

Cloudflare 的 Python Workers 经过两年预览期正式 GA：「Python is now a first-class, fully supported language on the Cloudflare Developer Platform」。运行机制：Python 经 Pyodide 编译到 WebAssembly，在 V8 基础的 workerd runtime 里跑。代价写在 limitation 文档里——WebAssembly VM 里 multiprocessing 和 threading 都不能用。开发体验上，pywrangler（PyPI 包名是 workers-py）跑的是 workerd 本地模拟，里头有一个 123MB 的 binary，本地启 Pyodide + WebAssembly + V8 三层栈。Announcement 署名 Gyeongjae Choi / Dominik Picheta / Hood Chatham 三人，前两位是 Pyodide 核心维护者——Cloudflare 对 Pyodide 生态的实质投入。

## 为什么值得关注

Cloudflare Python Workers 两年预览后正式 GA，机制是 Pyodide→WASM→workerd，本地 pywrangler 跑出 123MB binary；multiprocessing / threading 在 WASM VM 里仍不可用。

## 主要事实

- 公告日期 2026-09-21，状态从两年预览转 GA。
- 运行栈：Python → Pyodide 编译 → WebAssembly → V8 → workerd runtime。
- WASM VM 里 multiprocessing / threading 不能用（Cloudflare 自家 limitation 文档明说）。
- 本地工具：pywrangler（PyPI 包名 workers-py）启 123MB workerd binary，本地模拟 Pyodide + WebAssembly + V8 三层。
- 主要维护署名：Gyeongjae Choi、Dominik Picheta、Hood Chatham（前两位是 Pyodide 核心维护者）。
