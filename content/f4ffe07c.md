# The Problem With Vibe: When you can't trust the weekend tinkerer

> Source: https://tedium.co/2026/08/09/vibe-coding-insincerity/
> Author: Ernie Smith (Tedium)

## Summary (EN)

Ernie Smith examines the trust crisis in vibe-coded projects through the Dark Hours controversy, where an app built with Claude appeared to copy an existing open-source project. The deeper issue isn't code quality but creator authenticity: when product, email, narrative, and code all carry AI traces, users can't tell what the creator actually contributed. Smith doesn't reject AI-assisted development but argues that a project must reflect its creator's genuine interests, passions, and judgment -- otherwise trust collapses before code quality even becomes relevant.

## 摘要中文

Ernie Smith 通过 Dark Hours 争议审视 vibe coding 的信任危机：当产品、邮件、叙事和代码都带有 AI 痕迹时，用户无法判断创作者到底贡献了什么。他不反对 AI 辅助开发，但坚持项目必须反映创作者的真实兴趣和判断力，否则信任会先于代码质量崩溃。
