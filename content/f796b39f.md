## English Summary

Earendil shipped Pi 1.0, a hardened, minimal, extensible agent harness. Additions on top of its minimal coding-agent core: Codemode (native support for MCP and non-LLM models like Jev and image models), extension support for virtual models (the official demo wires Claude Opus for planning and GPT 6 Luna for implementation with Jev deciding when to switch, registered as a router/auto model), deferred tool loading, cache warming for Anthropic models, mid-conversation system messages (transcript-aware prompt and tool changes, sent as deltas only on models that support mid-conversation changes so prompt caches stay valid), a new TUI theme, and full-screen mode by default. The release philosophy: agentic tooling changes weekly but most changes do not last, so Pi adopts only proven ideas and weighs true functionality against inherent complexity. After months of hardening from community issues and pull requests, Pi serves hundreds of thousands of weekly users. An experimental sibling package, Pi Durable, targets long-running agents (see the adjacent entry). MIT licensed, docs at pi.dev, code at github.com/earendil-works/pi.

# Pi 1.0

日期：2026年10月01日周四

发件人：Earendil <[rfc@earendil.com](mailto:rfc@earendil.com)\>

收件人：您

主题：Pi 1.0

Today we are proudly shipping Pi 1.0: a hardened, minimal, extensible agent harness that you can make your own. Hundreds of thousands of people around the world use Pi every week. Many of you submit issues and pull requests. Over the course of many months, we have used that feedback to improve, harden and evolve Pi into a stable piece of software that people and businesses can depend on.

Pi is known for being minimal. We care about holding that line. While agentic tooling changes every week, many of the changes do not last. Pi does not work that way. We wait until something has proven itself, and only then do we consider adopting it; weighing its true functionality against its inherent added complexity. We spoke more about that process and how it relates to Codemode and MCP earlier this week [here](https://earendil.com/posts/you-said-no-mcp/).

The Pi 1.0 we are shipping today is a result of that process. Pi already ran the latest models from every major provider, became a daily driver coding agent for people around the world, and provided a supermalleable substrate on which to build agentic applications. With Pi 1.0 we are adding the following into Pi:

-   Codemode (native support for MCP, and non-LLM models like Jev and image models)
-   Extension support for virtual models
-   Deferred tool loading
-   Cache warming for anthropic models
-   Mid-conversation system messages (transcript-aware prompt and tool changes)
-   A new TUI theme
-   Full-screen mode by default

We have thought about many of these features for months. They were thrown up against the wall and stuck. The list of things that fell off the wall is much longer. When we use Pi with all these new features it feels like a major step forward, but it also still feels simple, like Pi.

Alongside this work of continually refining and evolving Pi, we also began to understand that there were aspects of Pi that did not fit the shape of how many people wanted to use it. At Earendil, we want to bring Pi's minimalism and the way it allows you to wield AI outside of the coding agent and outside of the terminal. It needs to be reachable from different surfaces and support longer-running conversations and tasks. In short, Pi must become more durable. Rather than stray from our minimal roots and try to make Pi something it wasn't, we combined that work into a new experimental package that we are shipping today, Pi Durable. Pi Durable is a new substrate for building long-running agentic applications that lets the builders and the users of those applications wield and steer the underlying intelligence with tremendous dexterity. It shares Pi's key principles, minimalism and supermalleability, but it extends those principles into new dimensions. Mario writes in more detail about how we crafted Pi Durable [here](https://earendil.com/posts/pi-durable/).

Earendil was formed to craft software and open protocols that strengthen human agency. Today we are shipping tools to you all to help do just that. We're eager to hear feedback from you and to harness the future out in the open together.

Pi 1.0 is available today:

```sh
curl -fsSL https://pi.dev/install.sh | sh
```

or on Windows

```powershell
powershell -c "irm https://pi.dev/install.ps1 | iex"
```

Pi Durable is available today as an experimental package:

```sh
npm install @earendil-works/pi-durable @earendil-works/pi-ai @earendil-works/chord
```

Both are MIT licensed. Documentation is at [pi.dev](https://pi.dev/). Code is at [github.com/earendil-works/pi](https://github.com/earendil-works/pi).
