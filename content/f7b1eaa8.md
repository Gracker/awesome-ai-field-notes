## English Abstract

Kimi K2.7 Code, an open-weight model, is now generally available in GitHub Copilot. This is the first open-weight model offered as a selectable option in the Copilot model picker, giving more choice and a lower-cost option for coding workflows. Hosted by GitHub on Microsoft Azure and billed at provider list pricing under usage-based billing for Copilot Pro, Business, and Enterprise users.
