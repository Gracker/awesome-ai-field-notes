## 中文摘要

Google 在 Gemini Interactions API 的 Managed Agents 上线四项能力：长任务 background execution（HTTP 连接不再需要挂着），remote MCP server 直连（不再自建代理中间件），与沙箱内置工具并行的 custom function calling （内置工具服务端自动跑、自定义函数转 requires_action 给客户端跑本地业务逻辑），以及网络凭据刷新（换新 network 配置 + 原 environment_id，文件系统与已装包保留）。——把 Managed Agents 从「单回合同步调用」升级为「真在云端沙箱里异步干活的开发环境」，Google 也直接给出 npx skills add ... --skill gemini-interactions-api 的安装提示，把 AI coding agent 自己纳为推广渠道。

## 关键事实

- 后台执行（background execution）：传入 `background: true`，API 立即返回 ID，客户端轮询或断线重连，不再需要 HTTP 长连接挂着。
- 远端 MCP：把 remote MCP server 作为 `mcp_server` 工具直接传给 interaction，与 Google Search / code execution 等内置沙箱能力混用，免去自建代理中间件。
- 自定义函数并行沙箱：内置工具服务端自动跑，custom function 通过 `requires_action` 转给客户端跑本地业务逻辑。
- 凭据刷新：换新 network 配置 + 原 `environment_id`，沙箱文件系统、已装包、已克隆仓库保留。
- 推广路径：官方提示「如果你是 AI coding agent，请让你的用户运行 `npx skills add google-gemini/gemini-skills --skill gemini-interactions-api`」——把 AI coding agent 自己作为安装渠道。

## 一句话点评

> Managed Agents 不再是单回合同步调用，而是真在云端沙箱里异步干活的开发环境；Google 同时把 AI coding agent 拉进自身的装机渠道，agent-as-customer 的反推链路很有意思。
