## 中文导读

自回归解码的 KV cache 随上下文线性增长，限制批大小与吞吐。LowRAM 找到互补于现有稀疏化/量化路线的一条轴：每个注意力头内的 value 大部分可由对应 key 预测出来。方法是 value cache amortisation——测试时为每个头拟合一个轻量预测器，只对重构最差的 token 存残差，得到约 4 倍近无损 value 压缩；预测器可用 meta-learning 初始化以显著降低 prefill 开销，并可与低秩 key 等已有压缩手段组合使用。

## English Abstract

Autoregressive decoding relies on the KV cache, whose memory footprint grows linearly with context length and caps batch size and throughput. Existing post-training methods exploit redundancy across tokens, layers, and feature dimensions, or lower numerical precision. We identify a complementary axis: within each attention head, values are largely predictable from their corresponding keys. We exploit this with value cache amortisation, which fits a lightweight per-head predictor at test time and stores residuals only for the tokens it reconstructs worst, giving 4x near-lossless value compression. The predictor can be initialised by meta-learning for substantially reduced prefill overhead.

## English Summary

The KV cache grows linearly with context and caps batch size and throughput. LowRAM identifies an axis complementary to sparsity and quantization: within each attention head, values are largely predictable from their keys. Its value cache amortisation fits a lightweight per-head predictor at test time and stores residuals only for tokens it reconstructs worst, giving about 4x near-lossless value compression; meta-learned initialization cuts prefill overhead, and the method composes with low-rank keys and other post-training compression. Test-time, per-head, composable - orthogonal to quantization routes like FP4 KV caches (BitDecoding), and worth scheduling into a long-context inference stack.
