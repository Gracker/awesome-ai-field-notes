## Summary (Chinese)
AgentX 是一个将 Hermes Agent 风格的自我进化机制从「单个 Agent」迁移到「项目级知识沉淀」的插件。核心设计：知识沉淀分两层——第一层是 Markdown（具体、排版清晰、分层组织），第二层是从 Markdown 演化出的 Skill（稳定、可复用、触发条件明确）。文章强调 Skill 必须从 Markdown 演化出来，而不是直接从对话生成，防止把一次性经验误判成长期能力。同时主张用 Bash/Hook 搭骨架（确定性部分），用 LLM 做理解和表达（语义部分）。
