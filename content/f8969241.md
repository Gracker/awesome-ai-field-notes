## 中文导读

NousResearch 11-05 发布 Hermes Agent v0.23.0，自 v0.22.0 汇总约 10,080 commits、约 1,950 merged PRs。两项核心：Webapp 把整套 Desktop 工作区开进浏览器标签页（默认关，webapp.enabled 开）；每台机器只跑一个 gateway 拥有全部会话，CLI/TUI/Desktop/编辑器/bot/cron 均作为客户端挂接，杜绝重复写与丢消息。其余：终端内联图片、/rewind 回退编辑重发或分叉、付费 MCP 工具价签与花费上限、插件目录约 600→1050+。

## 为什么值得关注

单 gateway 拥有会话加浏览器端完整 Desktop，是 Hermes 从单机工具走向常驻基础设施的一步

v0.22.0（d6a12ae8）解决了「进门」，0.23.0 把所有表面收拢到一个 gateway 拥有的会话上——多端写重/丢消息这类工程债被结构性清掉，值得作为 agent 网关设计的参考实现。

## 关键信息

## 原文摘录（release notes highlights）

> **Your Desktop workspace in a browser tab** - The new Webapp serves the full Desktop workspace from your own gateway: the same chats, Group Chats, plugins and settings, in any browser on your network or behind a public URL with sign-in.
>
> **One gateway owns every conversation** - Before, the CLI, TUI, Desktop, editors (ACP), messaging bots and cron could each run their own copy of the agent against the same chat, which is how messages got written twice or went missing between surfaces. Now each machine runs one gateway that owns every session, and every surface attaches to it as a client.

## English Summary

Hermes Agent v0.23.0 (Nov 5, 2026, The Hearth Release) rolls up ~10,080 commits, ~1,950 merged PRs and 666 contributors since v0.22.0. Two headline changes: a Webapp serves the full Desktop workspace from your own gateway in a browser tab (off by default; enabled via webapp.enabled or Settings; shipped in Docker and Nix), and each machine now runs a single gateway that owns every session - CLI, TUI, Desktop, editors, bots and cron attach as clients, ending duplicated or lost messages across surfaces. Also: inline images in the terminal, /rewind to edit-and-resend or fork from an earlier message, multi-machine Desktop connections, self-routing Group Chats, self-updating plugins, price tags and spend limits on paid MCP tools, and a plugin catalog grown from ~600 to 1,050+ entries.
