## 原文关键事实

- AlphaProof Code 是多 LLM 智能体形式化验证框架：人类专家与模型协作把 Signal 的安全目标翻译为形式化数学规约，每条规约都经人工复审。
- 由 Gemini Carbon 驱动的智能体完成证明，生成超过 600 万行 Lean 证明代码，其余部分由 Lean 自动机器校验。
- 智能体复审证明后仅标记约 1% 的代码库需要人工二次审查，专家可以把精力集中在人类判断最关键的位置。
- 验证覆盖到设备上实际执行的编译代码（如设备临时被攻破前后消息仍受保护这类性质），而大多数协议验证止步于设计层。
- 整个验证过程耗时四周；历史上这类任务需要专家团队数年。
- 把两个已修复的真实漏洞回插到隔离副本，系统均生成机器校验证明：含漏洞版本不安全。
- 验证工件开源供社区使用；Signal CTO Ehren Kret 评价把运行中的代码翻译为有效 Lean 定理是重大突破。

## English Summary

Google DeepMind introduces AlphaProof Code, an agentic formal-verification framework combining multiple LLMs, and reports a milestone: AI agents mathematically proved key security properties of the actual code underlying the Signal protocol - the first such verification of a widely deployed protocol implementation by any method. Human experts and models translated Signal's security goals into formal specifications, each human-reviewed; Gemini Carbon-powered agents generated over six million lines of Lean proofs and flagged ~1% of the codebase for human review while Lean machine-checked the rest. Verification covered compiled code down to device-executed instructions and took four weeks versus expert-team years. Reintroducing two previously fixed real bugs into an isolated copy, the system produced machine-checked proofs that both buggy versions were insecure.
