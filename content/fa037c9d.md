## 当日 DevRadar 消化

GitHub Advisory 于 11-17 20:02 UTC 披露：LLM 观测平台 Arize Phoenix 的 applyChatTemplate GraphQL 端点存在格式串注入（CVE-2026-53998，CVSS 10.0），攻击者从 API 响应可直接读服务端 os.environ——包括 phoenix.auth 里的 PHOENIX_SECRET 主密钥；该密钥既签发全部 JWT，又派生保护库内加密凭据（LLM API key、OAuth token）的 Fernet 密钥，拿到即可伪造管理员会话并解密数据库里存过的一切密钥。默认安装鉴权是关的，端点裸奔；即便开了鉴权，任意低权账号也够。受影响 arize-phoenix >=13.0.0 且 <15.7.0（13.0.0 自 2026-02-13 起），15.7.0 修复（PR #13197）。

## 当日消化判断

跑 Phoenix 的当天升到 15.7.0；暴露过公网或不可信内网的再轮换 PHOENIX_SECRET 和库里全部存储 key；观测平台天然攒着全公司的模型密钥，「运维面板变密钥出口」这类洞会再现，Phoenix 这类组件不该默认免鉴权上线。
