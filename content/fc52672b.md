## English Abstract / Summary

dotey reports that setting CLAUDE_CODE_DISABLE_1M_CONTEXT=1 in ~/.claude/settings.json's env materially extends Claude Code token budgets, with the gap widening on Fable 5.1. Mechanistically, the 1M window bills on current prompt size, raising marginal cost for long prompt engineering; disabling snaps back to the steeper 200K cost curve. Caveats: requests over 200K are truncated or errored, so long-doc summarization or full-corpus retrieval workflows need prior compatibility work.
