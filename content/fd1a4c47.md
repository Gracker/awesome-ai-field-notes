## 官方 changelog（节选）

> You can now talk with your agents in a realtime voice call. Describe a change out loud, ask what an agent is working on, and hear updates as the work moves forward.
> Voice chat works in the Agents Window, the IDE, on web, and in Cursor for iOS.
> The voice agent listens, replies, and hands coding work to the agent in your chat. While that agent runs, you can keep the conversation going.
> Voice chat runs on Grok Voice. … With Privacy Mode on, voice chat runs with zero data retention.

## 产品面

- **启动门**：agent 空闲且输入框为空时，Send 位变成波形 **Start voice chat**；旁边麦克风是听写（dictation，旧称 Voice Mode），不是通话。
- **双 agent 分工**：voice agent 听/说并 handoff；coding agent 用当前 chat 选的模型，自己播短进度与结束短答。
- **transcript**：通话记录进 chat；云 agent 通话中跨设备同步，Privacy Mode 开启时不同步。
- **语音栈**：Grok Voice；音色 Ara / Eve / Leo / Rex / Sal 等，通话中可换。
- **硬门槛**：需 Cursor 账号登录；**仅 API key 的会话不能开通话**（"Realtime voice requires sign-in"）；需麦克风权限。
- **限额**：约 10 分钟无说话且无在办工作默认挂断；另有每日上限（docs 未写数字）。
- **iOS**："Hey Siri, call Cursor"；锁屏 / Dynamic Island Live Activity 静音挂断。

## 与听写的分界

| | Voice chat | Dictation |
|--|--|--|
| 结果 | agent 口头回复 | 文本进输入框 |
| 谁发 prompt | voice agent handoff | 你审完再 Send |
| IDE 快捷键 | 无 | Cmd/Ctrl+Shift+Space |
