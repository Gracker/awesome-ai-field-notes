## English Summary

Claude Code 2.1.277 adds native AGENTS.md support: when there is no CLAUDE.md / .claude/CLAUDE.md / CLAUDE.local.md in the cwd or its parents, Claude falls back to AGENTS.md; the behavior is toggleable under /config. Codex and Claude Code can now share one AGENTS.md file, so multi-harness repositories stop needing dual documentation. Differences from Codex: Claude Code explicitly does not read AGENTS.override.md; the precedence is project CLAUDE.md > ~/.claude/CLAUDE.md (which does NOT block fallback) > AGENTS.md; Bedrock/Vertex/Foundry do not have it yet; the first session after upgrade may not pick it up — start counting from the next session.
