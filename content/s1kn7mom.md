这次，OpenAI不仅仅是发布了编码能力重回世界第一的GPT-5-Codex喔！还有更多。

工具全面升级：Codex CLI 重新设计、IDE 插件支持 VS Code 等主流环境、GitHub 集成更深，云端和本地环境无缝切换。

省流版

-   新增了写代码专用的gpt-5-codex系列模型，写代码能力大幅提升，绝对的世界第一；

-   $20美元/月的OpenAI ChatGPT Plus套餐足够大多数人用了，限额宽松。相比之下，Anthropic提供的Claude Pro套餐、Cursor Pro套餐同样都是$20美元/月，它们都很不耐用。

-   写UI界面的代码方面，审美有提升，但是仍然不如Claude Opus 4.1等Claude系列模型。（请期待未来几天马上会发布的Claude 4.5）

-   能够卷自己7小时！ （我的实测：我能让它卷自己3小时，无需要干预，交付质量优秀 ）

-   自带云端虚拟机！Codex除了在本机运行，它还可以在云端虚拟机写代码、运行代码、可以自己验收、可以截图给你确认！

-   Codex同时有支持GUI界面的VS Code插件（类似Cursor主交互）、和Codex CLI 工具(类似Claude Code的Terminal命令行交互形式）。

为什么我觉得Cursor存在的必要性再次变弱了

以前，一些从来没写过代码的朋友，也想学习vibe coding，我会建议它先从Cursor开始。因为至少Cursor有个GUI用户界面，相对有好一点。如果让新人直接面对黑漆漆一片的Terminal (Claude Code)，不符合它们的操作习惯，会劝退很多人 。

现在这件事情从根本上反正了改变—— Codex不仅有Terminal CLI，还有界面，甚至还有云端环境，连“本地配置环境”这件事可能都会省了。

请看下面，有实测！

如果现在我需要教别人Vibe Coding的话，我会毫不犹豫选择教他用Codex三件套，而不再会建议用Cursor起步。

全新CLI

OpenAI 听取了社区用户的建议，对开源的 Codex CLI 工具进行了全面升级。这次更新带来了不少实用的新功能：

**图片支持更便捷了** — 现在你可以直接在命令行里上传截图、设计草图和界面原型，团队沟通起来更直观，大家对设计想法也能快速达成一致。

**任务管理更智能** — 遇到复杂项目时，Codex 会自动帮你拆解成一个个小任务，生成清晰的待办清单，让你随时掌握进展。

**工具能力大幅增强** — 新版本集成了网页搜索、MCP 等实用工具，可以轻松对接各种外部系统。更重要的是，工具调用的准确性也提升了不少。

**界面体验更友好** — 终端显示效果经过精心优化，无论是查看工具调用信息，还是浏览代码改动对比，都变得更加清晰直观。
