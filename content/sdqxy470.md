# 关于转行编程的故事

## Jason 的基本情况
- **年龄**：36岁
- **背景**：进出口贸易行业转行编程
- **学习时间**：3个月学习基础技术栈
- **首个项目**：CC Switch (Claude Code 供应商管理工具)
- **项目成果**：GitHub 2万Star，130万下载

## 转行经历

### 入口
Jason 的转行契机是自己遇到了需要解决的问题：
- 管理多个 Claude API 供应商的需求
- 现有工具无法满足其业务需求
- 决定自己动手解决

### 学习过程
花了3个月学习基础技术栈：
- TypeScript
- React
- Node.js
- Rust

### 技术选型决策
- **第一版**：Electron (80MB)
- **第二版**：Tauri (更轻量)
- **语言迁移**：TypeScript → Rust
- **开发周期**：第一版仅用1周完成

## 项目特色

### 设计理念
- **侵入性最小**：即使卸载也不影响正常使用
- **用户体验优先**：简洁易用的界面
- **功能实用**：解决实际痛点

### 项目定位
- **目标用户**：使用 Claude Code 的开发者
- **核心功能**：供应商管理和快速切换
- **市场表现**：2万GitHub Star，130万下载

## 转行心得

### 关键成功因素
1. **真实需求驱动**：从自身需求出发
2. **快速迭代**：1周完成第一版
3. **技术栈选择合理**：Electron → Tauri的演进
4. **社区认可**：获得大量Star和下载

### 转行建议
- 找到真实的问题需求
- 快速做出最小可行产品
- 根据反馈持续优化
- 保持对新技术学习的热情

## 未来展望
Jason 表示将继续优化CC Switch，并计划推出更多开发者工具。

---

**总结**：Jason的转行故事展示了如何从实际问题出发，通过快速学习和迭代，成功进入软件开发领域。CC Switch的成功证明了找准痛点、快速响应市场需求的重要性。
