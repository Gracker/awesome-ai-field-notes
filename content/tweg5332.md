# OpenAI 携 GPT-5.5 入驻 AWS Bedrock，结束微软七年独家云托管


- **来源**：blog
- **作者**：OpenAI
- **原文链接**：https://openai.com/index/openai-on-aws/
- **日期**：2026-04-28

---

OpenAI 与 AWS 联合宣布 GPT-5.5、Codex 编程代理及 Bedrock Managed Agents 进入有限预览。此前微软与 OpenAI 重签合作协议，取消 Azure 独家许可、废除 AGI 条款。GPT-5.4 已可调用，GPT-5.5 将在未来两周内上线。AWS 客户可通过现有 Bedrock API 调用 OpenAI 模型，复用统一的安全与治理框架。云计算 AI 模型市场从"独家绑定"转向"多平台分发"。

## English Summary

OpenAI and AWS jointly announced that GPT-5.5, Codex programming agents, and Bedrock Managed Agents are entering limited preview. This follows Microsoft and OpenAI renegotiating their partnership to remove Azure exclusivity and AGI clauses. AWS customers can access OpenAI models through existing Bedrock APIs with unified security and governance frameworks.
