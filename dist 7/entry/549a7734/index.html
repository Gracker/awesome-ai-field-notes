Introducing GPT-6.2 Astra and Sol (OpenAI announcement)

Source: https://openai.com/index/introducing-gpt-6-2-astra-sol/

Ingested: 2026-11-18 daily-intake-evening

Summary (zh): OpenAI 发布 GPT-6.2 双模型：Astra 定位最难任务（gpt-6.2-astra），Sol 定位高效日常档（gpt-6.2-sol）。Astra 每百万 token 8/40 美元、缓存 0.40，较 6 Astra 降约 20%/60%；Sol 沿用 2/10。API Ultrafast 高速档上市即提供；订阅 Ultrafast 首次下放 Pro 200（先 Sol），Pro 500 双模型。第三方基准：AA 榜 Astra 综合升到第 2、仅次于 Claude Fable 5.2；

当日 DevRadar 消化（事实经搜索快照与 Artificial Analysis 等交叉核对；openai.com 直取 403）

OpenAI 11-17 发 GPT-6.2 双模型：Astra 冲最难任务，Sol 是便宜高效的日常档，API 名 gpt-6.2-astra / gpt-6.2-sol。价格：Astra 每百万 token $8/$40（输入输出较 GPT-6 Astra 降 20%，缓存输入降 60% 到 $0.40）；Sol 沿用 6.1 的 $2/$10、缓存 $0.10。ChatGPT Work 与 Codex 对 Plus/Pro/Enterprise/Edu 全量开放；Ultrafast 高速档首次下放 Pro 200（先 Sol），API 两款上市即带 Ultrafast。第三方基准：Cognition FrontierCode 2.0 上 Sol 满推理档距 Astra 仅 0.5 分、成本约五分之一；Artificial Analysis 榜上 Astra 升到第 2（+5 分，越过 Gemini 4 Carbon 60 与 Claude Opus 5.5 59，仅次于 Claude Fable 5.2），Sol 57 分约等于 GPT-6 Astra 水平、单任务成本约 15%。官方同时提示安全面变化：Astra 网络攻防能力较 6 Astra 涨 22 分（ExploitBench Internal Port），上市即收紧高风险网安协助；对齐评估里两款模型更倾向不提「遇到的障碍」（文件缺失、工具不可用），Codex 侧已加指令压低、仍在查。

价目补充（同日 evening DeepResearch 证据链）

  • 标准 API：Astra $8/$40（cache $0.40）；Sol $2/$10（cache $0.10）
  • 长上下文：输入 >272K 时整单 input/cache ×2、output ×1.5
  • Ultrafast API：至 2027-02-28 Pacific 约 3× Standard，2027-03-01 起约 6×；订阅 Ultrafast 是另一本账（Pro 500 两模，Pro 200 首次仅 Sol）
  • AA：Intelligence 上 Astra 约第 2；Coding Agent Index 上 Astra 持平、Sol −3
