## Summary (ZH)
Suryansh Tiwari 深度解析了 Claude 风格多智能体系统的两种核心架构：Sub-Agents（隔离执行，单次任务，父节点控制）和 Agent Teams（协作通信，共享上下文，对等交互）。核心区别在于上下文边界的设计而非角色分工。提出了 5 种关键模式：Prompt Chaining、Routing、Parallelization、Orchestrator-Worker、Evaluator-Optimizer。强调应基于上下文边界而非角色来拆分任务，避免每个交接点的质量损失。

## Summary (EN)
Detailed analysis of two Claude-style multi-agent architectures: Sub-Agents (isolated, stateless, one-shot, parent-controlled) vs Agent Teams (persistent, interactive, context-sharing, peer-to-peer). Five key patterns: Prompt Chaining, Routing, Parallelization, Orchestrator-Worker, Evaluator-Optimizer. Key principle: decompose by context boundaries, not by roles.
