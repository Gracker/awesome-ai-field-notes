## 中文版

### 从"预设风格"到"标签控制"

传统 TTS（文字转语音）模型通常只能选择预设的声音风格，如"专业""友好""严肃"等模糊描述。Gemini 3.1 Flash TTS 在文本中加入**音频标签（Audio Tags）**，相当于给语音生成提供了一套 API 参数。

### 核心能力

1. **多语言支持**：覆盖 70+ 种语言
2. **细粒度控制**：情感表达（平静、兴奋、悲伤）、节奏控制（快、慢、停顿）、风格调整（正式/休闲）
3. **音频标签格式**：类似 XML 标签嵌入文本
4. **SynthID 水印**：所有生成音频均带有 AI 生成标识

### 典型应用场景

- **有声书和播客**：叙述用平稳语速，对话加快节奏，悬疑段落降低音调放慢语速
- **语音助手**：根据用户情绪调整回应语气
- **游戏**：NPC 对话根据剧情情绪动态调整

### 技术意义

这是 TTS 领域的范式转变——从**选择模型**到**控制参数**，从**预设风格**到**可编程语音**。

## English Version

### From Preset Styles to Tag Control

Traditional TTS offers preset voice styles. Gemini 3.1 Flash TTS embeds Audio Tags directly into text, providing an API for speech generation.

### Core Capabilities

1. **Multi-language**: 70+ languages with fine-grained control
2. **Fine-grained Control**: Emotion (calm, excited, sad), pace (fast, slow, pauses), style (formal/casual)
3. **Audio Tag Format**: XML-like tags embedded in text
4. **SynthID Watermarking**: All audio carries AI-generation identification

### Use Cases

- **Audiobooks/Podcasts**: Adjust narration pacing, dialogue rhythm, suspenseful sections
- **Voice Assistants**: Match response tone to user emotion
- **Gaming**: NPC dialogue dynamically adjusts based on story context

### Significance

Paradigm shift in TTS: from **selecting a model** to **controlling parameters**, from **preset styles** to **programmable speech**.
