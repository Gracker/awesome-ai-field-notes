不止是翻译器的翻译工具

我为 macOS 开发了一个使用 ChatGPT API 提供全球词义翻译的 Bob 插件。然而，由于并非所有用户都能使用 macOS 来享受该插件带来的好处，我创建了此项目！

最初只是一个 Chrome 扩展程序，现已演变为我正在开发的多平台桌面应用程序。

原本只是翻译工具，意外地发展出出人意料有效的语言润色和摘要功能。

- 提供三种模式：翻译、润色和摘要
- 支持在 55 种不同语言之间进行互译、润色和摘要
- 支持流式传输模式
- 允许用户自定义翻译文本
- 一键复制功能
- 文本转语音（TTS）
- 支持所有平台（Windows、macOS 和 Linux）的浏览器和桌面版本
- 支持截图翻译
- 支持词汇本，并根据词汇本中的单词生成记忆辅助功能
- 支持 OpenAI、Azure OpenAI Service、MiniMax 等其他 LLM 提供商
