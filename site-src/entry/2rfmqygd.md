## 正文

Claude Code 的创始人 Boris Cherny 前几天分享了一批他自己在用的技巧，说是"团队里真正在用的，和入门教程完全不一样"。我看完之后整理了一下，把他分享的和我们团队平常实战下来的一些用法合在一起，写成这篇。

有些功能藏得比较深，不主动找根本不知道有。但用了之后你会觉得，这个东西怎么之前一直没发现。

## 先说最重要的一条：给 Claude 验证的机会

Boris 强调最重要的技巧是"给 Claude 一种验证输出的方式"。就像让工程师做网站但不给他用浏览器，结果大概率不行。

具体做法是装 Chrome 扩展，或者配 Playwright MCP。装完之后，Claude 会自己写代码，打开浏览器看效果，发现问题，改代码，不停迭代，直到结果对为止。Boris 说这一步能让输出质量提升 2-3 倍。

## 并行跑，才是真的快

Boris 说他们团队最大的生产力提升来自一件事：同时开 3-5 个 git worktrees，每个跑自己的 Claude 会话。做法是用 claude -w 启动一个 worktree 会话，几个窗口各管一个任务，互不干扰。

他还给每个窗口设了不同颜色（/color），一眼就能区分。启动时加 --name 参数给每个会话命名，并行多个的时候不会搞混。

除了 worktree 并行，我自己用得更多的是并行子 agent。遇到大规模任务，主动跟 Claude 说"拆解问题并并行跑子 agent"，它会自动把任务分解，同时开多个 agent 各跑各的，时间大大降低。

这个不是默认行为，不说它不会主动做，主动开口就有。

## 手机遥控，出门也能让电脑干活

这个功能叫 /remote-control，用之前有个前提：需要有 Claude 官方账号，而且得开了订阅才能用。

用法很简单，在会话里发 /remote-control，它会给你一个链接。手机上用任何浏览器打开这个链接，登录同一个账号，就能直接接入你电脑上正在跑的那个会话。

你在手机上发指令，电脑这边的终端处理，处理完了再把结果回给你手机。本质上活还是在电脑终端上干的，手机只是个遥控器。

如果你想多个终端并行的话，就同时开多个终端，生成多个链接，建议后面跟上项目的名字，方便区分。

实现随时随地 vibing coding。

/teleport 可以把云端会话搬到本地接手。在 claude.ai 开了个任务，做到一半想在本地终端继续，/teleport 一下直接接上，不用重新开始。

还有 Claude 有 iOS/Android App，Code 标签里可以直接开完整的 Claude Code 会话，手机上写代码、审代码都行。

再补充一个。

Channels 频道系统：通过 Telegram、Discord、iMessage 给正在跑的 Claude Code 会话推消息！出门了，Telegram 上发一条指令，Claude 继续干。还可以在手机上审批权限请求

## 自动化重复操作

新功能，/loop 是定时循环执行，/loop 5m 加上某个 skill，每 5 分钟自动跑一次，最长可以设到 3 天。

可以用来用来自动巡逻 PR、处理 Slack 消息。

/schedule 是持久化版本，电脑关了还在跑，云端执行，适合每天定点触发的任务。

Hooks 是在特定时刻自动触发的动作，配一次，之后一直生效。

比如PostToolUse 可以在每次改完文件后自动格式化代码。Stop 加 exit 2 可以在任务完成时自动跑 TypeScript 检查，有报错就强制继续修，不改好不能结束。

Notification 则可以在 Claude 等待输入时弹出通知提示音，不用一直盯着屏幕。

这里有一点值得注意：CLAUDE.md 里的规则是"建议性"的，AI 上下文压力大时可能跳过。Hooks 是确定性的，绕不过去。核心验证逻辑要放 Hooks，不能只放 CLAUDE.md。

配置 Hooks 不需要记命令，直接跟 Claude 描述任务，它会自己去找机制、写脚本、配好 settings.json。

## 你可能没注意到的命令

claude --enable-auto-mode 自动模式不会像传统模式那样逐个批准文件写入和 bash 命令，或者完全跳过权限检查，而是让 Claude 代表你做出权限决定。每个操作在执行前都会经过安全检查。

/model opusplan 保证质量的节省token法，写方案的时候用 opus 4.6，执行的时候用 sonnet 4.6。

/btw 是一个很好用的插队命令。Claude 正在干活的时候，用 /btw 插一个问题，它不会中断任务，不进对话历史，几乎不消耗 token。有什么突然想问的，/btw 一下就行。

/branch 可以从当前会话分出一个独立分支，原来的不受影响。想试另一个方向但不想丢掉当前进度，用这个——相当于开一个平行宇宙。

/rewind 会弹出菜单让你选，只回退代码、只回退对话、还是两个都回退。以前遇到改坏了只能 git reset，现在一个命令搞定。双击 ESC 也能回滚，而且连文件改动一起回滚，不只是撤销对话。

/insights 会生成一份 HTML 文件，分析你最近一段时间的使用情况，主要用来干什么、做得好的地方、问题在哪，并给出改进建议。相当于你的专属使用报告。

/batch 是大规模迁移任务的神器。它会把任务拆成几十个独立单元，分发给并行的 worktree agents 同时执行，最后汇总结果。Boris 叫它"AI 军团式编程"。

/simplify 它会启动三个并行 Agent，分别从代码复用、代码质量、运行效率三个角度审查改动，结果又快又全。

/export 导出对话为 Markdown：有价值的架构讨论存下来，还能丢给其他 AI 互相参照

/context 查看 token 占用：一个空会话就已经 16.8K+ tokens

## 几个快捷键和细节

Ctrl/Cmd+V 可以直接粘贴截图，不用先存文件。Ctrl+G 打开编辑器写长 prompt，不用在终端里硬搓。

直接粘贴网址，Claude 会自己去读，不用手动复制文档内容。

把另一个代码库的文件夹直接拖进来，Claude 能理解并修改那个外部项目，绕过"不支持多代码库"的限制。

遇到大规模任务，主动说"拆解并并行跑子 agent"，不说它不会主动这样做。
