# Claude Code 之父自爆：Claude Code 的终极用法

## Claude Code 之父自爆：Claude Code 的终极用法

Boris Cherny 作为 Claude Code 之父，他写了一篇非常详细的推文，分享了自己如何高效使用这款工具！

## 核心理念

Claude Code 不是一个静态工具，而是一个可以与用户配合、不断学习、共同成长的智能搭档。

## 高效使用策略

### 多会话并行处理
* 同时开启多个 Claude 会话（5-10个）
* 在终端、网页和手机上并行处理任务

### 开箱即用，无需复杂配置
* 无需复杂配置，Claude 开箱即用就很强大

### 选择最强大的模型
* 使用 Claude 的旗舰模型 Opus 4.5 并结合思维模式（"with thinking"）进行所有开发任务
* 尽管该模型可能较慢，但其理解能力和工具使用能力更强，能减少反复引导，从而节省总体时间

### 代码规划（Plan 模式）
* 在编写代码前，让 Claude 协助规划，提高成功率

### 代码生成后检查格式
* 生成代码后使用工具检查格式，避免错误

### 构建团队知识库
* 团队维护一个"知识库"，当 Claude 出现错误时，将经验添加到知识库中，以便下次避免犯类似错误

### 通过 PR 自动训练 Claude
* 让 Claude 查看 Pull Request（PR），学习新的用法或规范

### 常用命令转换为斜杠命令
* 将自己常用的命令转换为斜杠命令，使 Claude 能够自动调用，减少重复劳动

### 使用"子代理"处理固定任务
* 利用"子代理"来处理代码简化、功能验证等固定任务

### 权限管理
* 不随意跳过权限，而是设置安全的指令自动通过

### 多设备同步工作流程
* 在网页、终端和手机等多设备上同步 Claude 的工作流程

### 提供"验证机制"
* 最重要的一点是，一定要为 Claude 提供"验证机制"，使其能够确认自己编写内容的正确性
* 例如让 Claude 自动运行测试、打开浏览器测试网页或检查功能是否生效

## 总结

Boris Cherny 总结道，Claude Code 的核心理念是让 AI 像人一样合作，而不是替代人。
