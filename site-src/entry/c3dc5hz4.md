## English
Claudian is an Obsidian plugin that embeds AI coding agents (Claude Code, Codex, and more to come) in your vault. Your vault becomes the agent's working directory — file read/write, search, bash, and multi-step workflows all work out of the box.

Open the chat sidebar from the ribbon icon or command palette. Select text and use the hotkey for inline edit. Everything works like Claude Code or Codex — talk to the agent, and it reads, writes, edits, and searches files in your vault.

Key features:
- Inline editing with word-level diff preview
- Slash commands & skills for reusable prompt templates
- @mention system for files, subagents, MCP servers
- Plan mode for exploration and design before implementation
- MCP servers for connecting external tools
- Multi-tab conversations and conversation history

## 中文
Claudian是一个Obsidian插件，将AI编码智能体（Claude Code、Codex等）嵌入到您的知识库中。您的知识库成为智能体的工作目录 — 文件读写、搜索、bash和多步骤工作流都能开箱即用。

从功能区图标或命令面板打开聊天侧边栏。选择文本并使用热键进行内联编辑。一切就像Claude Code或Codex一样工作 — 与智能体对话，它会读取、写入、编辑和搜索您知识库中的文件。

主要功能：
- 内联编辑，带词级差异预览
- 斜杠命令和技能，用于可重用的提示模板
- @提及系统，用于文件、子智能体、MCP服务器
- 规划模式，在实施之前进行探索和设计
- MCP服务器，用于连接外部工具
- 多标签对话和对话历史
