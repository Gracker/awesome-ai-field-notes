## oh my codex 使用教程

群里的大佬们果然牛，给我安利的oh my codex 我用上了，真的可以长任务，亲测有效。

安装：
npm install -g @openai/codex oh-my-codex
omx setup
omx --madmax --high

相关命令：
\$deep-interview "澄清这次认证变更"
\$ralplan "批准认证方案并审查其中的权衡取舍"
\$ralph "把已批准的方案推进到最终完成"
\$team 3:executor "并行执行已批准的方案"
